# 物品价格模块

[设计索引](../../DESIGN.md) · [共用价格界面](../shared.md#24-全局物品价格)

## 数据与职责

价格模块独立管理价格、官方行情、定价选项、锁定、持久化及请求调度。其他功能页面通过 `src/price-service.js` 获取数据和执行命令，不读取内部存档结构；价格管理弹窗属于模块内部，负责价格表、偏好及导入操作。计算函数接受只读价格快照；原有估值函数的价格映射入参仅保留纯计算兼容，不用于页面获取存储。

内部纯计算入口 `valueItems(items, prices)`、`valueRewards(result, prices)` 始终使用全局价格及缺价商人兜底，不再接收已失效的估价模式参数。

按完整物品 ID 区分品质和强化，提供 `price`（用户物品价格）、`vendorPrice`（原始商人售价，不可出售为 null）、`sellPrice`（最低卖价）、`sellQuantity`（在售数量，全市场在售物品总量）、`buyPrice`（最高买价）、`buyQuantity`（求购数量，全市场求购物品总量）、`avg7d`（7天平均成交价格）、`avg30d`（30天平均成交价格）、`volume7d`（7天成交数量）、`volume30d`（30天成交数量）。八项行情字段依次来自 `lowestSell/sellQty/highestBuy/buyQty/avg7d/avg30d/vol7d/vol30d`；成交量为近 7／30 天全市场成交件数，0 是有效无成交，缺失、未读取和异常分别保留状态。挂单总量不是最优价位数量，不用于推算成交能力；成交量也不代表当前挂单价一定能成交。商人价不受市场刷新或用户锁定影响。

用户价格空值为未设置，0 为有效价格。官方报价及均价须为正的有限数值，null 为明确无单／无成交记录；数量为非负安全整数，0 为有效空挂单总量。缺失、异常、未读取和明确无单通过字段状态区分，不补 0；数量异常不抹去同份快照的有效价格。数量及其异常状态与价格按同份官方快照存储和替换，不跨快照拼接。

## 固定协议 v1

`getItem(id)` 返回一项数据；`getSnapshot()` 返回当前版本只读快照，快照的 `getItem(id)` 可读取任意合法完整 ID，指定 `getSnapshot(ids)` 时另提供对应的 `items`。同一快照的后续读取不受设价或网络结果影响。数据包括十项值、`configured`（锁定、来源、修改时间）和 `market`（官方生成时间、各字段状态）。协议版本独立于存档版本；成交量为向后兼容的可选增量，旧缓存读取为未读取。

字段状态使用 `available`（有效）、`noOrders`（价格明确无单／无成交记录）、`unread`（未读取／旧缓存无对应字段）和 `invalid`（缺失或非法官方字段）；数量及成交量为 0 时仍为 available，成交量不使用 `noOrders`。官方 API 未提供成交量字段时按未读取处理，不使整份行情或价格导入失败。

`subscribe(listener)` 通知 `prices/market/preferences` 三类变化及递增 revision；页面按依赖重估，不重跑模拟。仅存储异常变化也通知界面。`setPrice` 自动锁定，价格与锁定命令统一执行写入及保存；`setPreferences`、`resetPreferences` 执行偏好更新、受影响未锁定价格的缓存重算及原子保存。`importPrices` 更新行情并按选项导入未锁定物品价格；不再提供收藏页专用的仅刷新报价入口，所有行情读取均通过价格导入并遵循分类偏好及锁定规则。并发请求共用、超时、防倒退、打开或聚焦网站时五分钟间隔及错误保留遵循共用价格规则。

即时重算与导入共用同一候选范围：可交易基础物品、已有行情完整 ID 及已配置完整 ID，不穷举全部品质／强化组合。价格选项另有“贵重品（怪物的稀有掉落）”独立行，默认商人价，可继承全部；命中范围、优先级及迁移见[共用定价规则](../shared.md#导入策略与存储迁移)。物品筛选一级分类由原始市场定义派生，宝石归入资源，工具包含坐骑；可食用农作物按原始细分类归入食物；行情协议仍保留原细分类校验，价格表筛选与选项表共用原市场一级分类，特殊定价行不加入筛选；强化空值／0 及状态组合遵循[共用筛选规则](../shared.md#筛选与物品清单)。

## 页面采用规则

战斗、采集、制造读取物品价格，未设置时通过共用估值函数使用可出售商人价、否则 0，并保留缺价提示；宠物仍不计估值。制造另提供页面级“原料金额取值／成品金额取值”，可分别选择全局物品价格、7天平均、30天平均、卖单价、买单价或商人价；该选择只影响制造页估值与利润，不回写全局价格、锁定或导入选项。制造配方明细只读展示估值使用的单价及完整市场块，设价和锁定在全局价格弹窗操作；采集主产物明细按品质展示成交量、在售／求购、买卖价、均价及行情时间。1.0.1196 的烟花沿用贵重物品分类、完整品质 ID 与原始商人售价；火药无市场分类且不可出售，商人价为 null；保留已保存的全局价格，未设价明确标缺价。价格弹窗展示十项数据，支持两种均价定价选项，默认使用7天均价；官方行情和商人价格只读，数量表头使用“在售数量 / Quantity for sale”“求购数量 / Quantity wanted”，成交表头使用“7天成交量 / 7-day volume”“30天成交量 / 30-day volume”，均表示全市场物品数量。

强化保持三个直接价格输入及方案内覆盖；未覆盖时经协议读取全局物品价格，清空未定价、0 表示免费或已有底装。底装完整 ID 绑定及左右清空范围保持原规则，不改全局价格。精通优化器的战斗／采集收入目标读取只读价格快照，并冻结开始时价格；需估值的全部可能产出必须完整定价，零价有效，缺价时停止，不使用商人兜底，宠物仍不计估值。精通产出评分不依赖价格，手动精通预算、预报、公式与调试不参与估值。具体目标及价格变化规则见[精通优化设计](../pages/mastery.md#计算最优分配方案)。

## 兼容与验收

首领投喂按全局有效单价估算采购额，零价有效，未定价的采购额留空。供应量读取同一协议快照中的官方卖单数量。相关物品的有效单价或卖单量变化时，页面复用已有工时估算，刷新金币成本与供应量。详见[首领投喂](../pages/boss-feed.md#行情)。

沿用价格存储键，存档保持版本 7；成交量作为行情快照中的可选增量字段加入，旧缓存无成交量标记未读取，成功刷新后补齐，不改变价格、锁定或偏好结构。一级分类、默认继承、缓存即时定价及旧 v2～v5 选项统一重置遵循[共用定价规则](../shared.md#导入策略与存储迁移)。迁移保留价格与锁定，数量字段继续按行情快照保存，旧缓存无数量标记未读取，成功刷新后补齐。非法数量字段显式保留异常状态；保存失败内存可用并明确提示。

验证两种均价解析、定价、兜底、异常／空值／防倒退、旧存档选项重置、v6 增量迁移与 v7 恢复，以及十项独立数据、完整 ID、空/零/非法数量、7／30天成交量的0、缺失与异常、旧缓存往返、不可出售商人价、快照不可修改与一致性、通知类别、统一手动设价锁定、官方刷新不覆盖用户锁定、请求失败及防倒退；验证强化输入覆盖隔离、战斗采集制造只重估、价格弹窗成交列及双语桌面与390px横向滚动。

## 上游商人售价兼容

1.0.1203 的深渊之眼（基础编号 207）商人售价为 288,000 金币，按原始售价函数的特殊倍率计算，不改物品定义价值。商人估值、缺价兜底统一复用原始函数；物品编号沿用原始校验，不为材料添加不存在的品质或强化变体。验收覆盖有效编号的特殊售价、非法变体拒绝及其他可交易物品售价不变；显式全局价格仍优先。
