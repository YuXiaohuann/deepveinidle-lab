# 共用页面框架

[设计索引](../DESIGN.md) · [当前状态](status.md)

战斗、采集、制造页面统一使用“利润”称呼扣除既定成本后的金额，适用于表头、周期选项、汇总、提示与说明；英文沿用 Profit。计算口径、排序、周期折算及存储字段保持既定规则。验收要求：三个页面的应用文案不再出现“收益”，原有利润计算及交互保持一致。

战斗与采集页面的经验、金币及金额展示：绝对值达到 1,000 时使用 K（千）、M（百万）、B（十亿）、T（万亿）缩写，固定保留两位小数，负值保留负号；不足 1,000 沿用原有精度，中英文使用相同字头。适用战斗经验及分技能经验、金币、普通／稀有掉落估值、收入、食物与药剂成本、利润、明细物品价格，以及采集经验、金币、主要产物／额外掉落估值、收入和明细物品价格（含各采集点经验与金币）。战斗击杀／攻击次数、掉落及消耗数量，采集次数、尝试／被抓／回仓次数、产物及掉落数量均保持原展示；制造页面所有指标、其他页面、属性、时间、百分比、编号、种子和输入框不调整。仅在周期折算后格式化显示，不改变计算、排序或存储。验收覆盖双语字头、阈值与负值、明细一致性、次数数量及制造展示保持不变。实施验证见[当前状态与验证](status.md)。

### 2.1 导航与网址

- 右上角版本标识中英文均只显示当前包版本号（当前为 `1.3.2`），不添加“正式版”、测试版或 BETA 前缀。

- 页头（header）内部提供同级“战斗 / 采集 / 制造 / 强化 / 精通 / 预报 / 公式”导航（英文 Combat / Gather / Crafting / Enhance / Mastery / Forecast / Formulas），战斗网址为 `/combat`、采集网址为 `/gather`、制造网址为 `/craft`、强化网址为 `/enhance`、精通网址为 `/mastery`、预报网址为 `/forecast`、公式网址为 `/formulas`，首页 `/` 显示战斗；当前角色配置、角色属性与敌人利润全部归入战斗板块。公式页使用独立阅读布局，详见 [公式页面](pages/formulas.md)。
- 导航使用真实链接，普通点击通过 History API 更新网址并切换内容可见性；支持复制链接、新标签打开与浏览器前进／后退。切换板块不重置角色配置、搜索、筛选、排序、采集与制造利润周期、折叠状态或已有模拟结果，也不重新启动模拟；进行中的战斗、采集与制造模拟继续完成。语言切换保留当前板块；直接打开或刷新按网址显示相应板块，不新增板块存储字段；刷新仍按原规则重置未持久化的筛选。
- 导航位于品牌与语言控件之间；窄屏时在页头内独占一行。页头、语言控件及项目页脚为各页面共用。导航支持键盘操作，有明确选中状态，中英文与窄屏均可用。

调试页网址为 `/debug`（也支持尾斜线），不出现在导航菜单；通过网址进入，沿用语言、页脚和页面状态保留规则。调试内容网格及文件输入在中英文 390px 下不得撑宽页面。

### 2.2 语言、布局与持久化

- 右上角语言切换入口仅显示语言图标，不显示当前语言文字或下拉箭头；打开后仍使用原生下拉选项“简体中文 / English”。保留“Language / 语言”无障碍名称、悬停提示及键盘焦点。验收覆盖双语桌面与 390px 窄屏的图标显示、选项不变、鼠标／键盘切换及刷新后语言保留。
- 支持简体中文和英文；公式页面正文、目录与提示仅中文，站点语言切换不翻译公式。优先使用已保存的手动选择，否则浏览器语言列表包含中文时默认中文，其余默认英文。
- 游戏名称优先复用上游翻译字典；缺失翻译及已核验的新版说明集中补充。新增选项必须同时覆盖两种语言，中文模式不能遗漏药水、家园、精通名称或说明。
- 游戏文本核对范围为 `src/` 手写模块及 `index.html`，以本地已核验 1.0.1187 原始资源中的四组翻译为依据。相同含义的技能、属性、设施、药水、稀有度及特权名称复用原文与译文；补充字典仅作为上游缺词的回退，不能覆盖已有翻译。金币英文统一 Coins，避免与 Gold（金矿物品）混淆。复合说明保留模拟器限定语，仅统一其中的游戏术语；统计表的所需等级、采集次数及价格锁定等保留实际语义，不机械套用游戏不同上下文的译文。验收要求：逐项明细列明替换、现有复用、缺词回退和上下文保留；双语相关渲染及翻译优先级验证通过，不改变计算或保存协议。家园分组中文统一使用游戏已有“家园”（Home board 的译文）；英文 Home 保持不变，不能机械按 Home 的短译“家”缩写。实施状态：已随1.2.5发布，发布验收见 [当前状态](status.md)；明细见 [游戏文本核对报告](../reports/game-text-audit-2026-10-14.md)。
- 语言切换遵循 [导航与网址](shared.md#21-导航与网址) 的状态保留规则。所有页面的“导入游戏角色”首次打开或刷新默认展开，其它角色配置子菜单默认折叠，可独立展开或折叠；重绘与语言切换保留展开状态，不跨刷新保存。
- 战斗、采集、制造、强化、精通页在宽度大于 740px 时采用固定视口工作区：页头保持可见，左侧配置与右侧信息分别独立纵向滚动，到边界不带动外层页面；右侧属性、结果、说明与项目页脚整体滚动，表格仍可独立横向滚动。工作区高度由实际页头高度自动分配。宽度不超过 740px 时恢复上下排列与整页滚动，页脚位于全部内容末尾，不产生页面横向溢出。预报与调试布局不变。
- 上述五页切换、语言切换及配置／结果重绘保留各列滚动位置（内容变短时由浏览器裁剪）；不新增持久化字段，不改变计算或模拟流程。验收覆盖五页双语桌面、页头换行、左右滚动互不影响、页脚可达、键盘操作、重绘及页面切换保留位置、390px 上下布局。
- 使用浏览器 localStorage 自动保存语言及角色配置。旧配置按各字段的默认值和迁移规则规范化，未单列的新增字段补零或未启用；非法数据不得导致页面崩溃。
- 存储不可用时提示保存失败，计算仍应可用。

### 赞赏弹窗

- 共用页头在“物品价格”右侧提供“打赏一下”（英文 Support）按钮，带大拇指装饰图标，所有页面可用。点击打开原生 dialog，展示用户提供的微信赞赏图片；图片原样保存于 `src/assets/appreciation.jpg`，不裁剪或改写，按比例缩放以适应弹窗。
- 图片使用用户提供的 `output.jpg` 原始内容；图片上方居中显示“觉得好用？微信扫一扫打赏一下～”，英文为“Finding it useful? Scan with WeChat to leave a tip.”。其中“微信扫一扫”（英文 Scan with WeChat）使用金色加粗高亮。提示作为弹窗文字展示，不写入图片；窄屏允许自然换行，图片保持比例且完整可见。
- 每次打开弹窗，通过 `https://cdn.jsdelivr.net/gh/vikiboss/v50@main/static/v50.json` 加载字符串数组，从非空字符串中等概率随机选一条，在图片下方展示；保留换行与自动折行，按纯文本渲染，不解释 HTML，外部中文文案不翻译。每次打开先清空旧文案并调用 fetch，使用浏览器默认 HTTP 缓存规则，不设置 cache 参数、不增加应用层缓存；10 秒超时、网络／跨域错误、非成功 HTTP、非法 JSON 或无有效字符串时不增加任何文字及错误占位。关闭或重绘取消进行中的请求，迟到响应不得写入下一次弹窗。保持纯静态部署，不引入代理。验收覆盖重复打开、随机选择、关闭／重绘竞态、失败隐藏及长文窄屏布局。
- 弹窗复用物品价格的背景、边框、标题和关闭按钮样式；支持关闭按钮、Escape、点击弹窗外关闭、焦点限制在弹窗内及关闭后返回入口。打开与关闭不改变当前页面、配置或模拟状态。图片加载失败时明确提示，不展示空白成功状态。
- 验收覆盖中英文桌面及 390px 窄屏的按钮顺序、图片完整显示、无横向溢出、三种关闭方式、键盘打开与焦点返回、跨页面及语言重绘后可用。图片须纳入发行包并通过本机服务以 `image/jpeg` 提供；浏览器专项不替代发布验收。

### 2.4 全局物品价格

全局价格初版随 0.15.0 发布，分类商人价选项随 0.15.1 发布；以下规则含本地待发布的官方 API 导入变更，发布状态见 [当前状态](status.md)。共用页头提供带设置齿轮图标的“物品价格”弹窗入口，图标仅作装饰，不参与无障碍名称，所有页面可用；原生 dialog 支持关闭、Escape、点击弹窗外关闭及焦点返回，双语与窄屏可用。弹窗沿用现有面板背景、边框、字号、按钮、表头、说明文字与配置折叠风格，不引入独立配色。价格按完整物品 ID 独立设置，品质与强化不共价；空值未定价、0 为有效零价。分类复用保存上游定义；未适配的新物品明确跳过，不降级为基础物品。

- 分类、双语名称搜索、稀有度、强化（0 表示全部）和价格／锁定状态筛选；状态仅保留“全部／已定价／已锁定”，删除“未定价／未锁定”。分类、稀有度、状态均为全部，搜索去除首尾空白后为空，强化为 0 时视为未设置筛选：不生成或显示任何物品行，即使已有价格或报价缓存也保持空列表，显示“物品数量较多，请先设置筛选条件 / Many items to display; set a filter first”，提示使用现有金色并加粗，全选与批量锁定／解锁禁用、旧勾选清空。任一项为具体条件即显示匹配结果；稀有度“普通”（值 0）属于有效筛选，上方分类价格来源属于导入偏好，不激活物品列表。已筛选却无结果时仍显示“没有匹配物品”。清除所有筛选后恢复初始空状态，关闭重开及语言切换保留本页会话内的当前筛选。此规则只限制物品展示，导入与清空未锁定价格继续按原有全局范围执行，无筛选时仍可操作，成功后仍保持空列表，不删除数据。有效筛选下的基础清单继续生成所有合法品质未强化变体，保留原市场分类／可出售条件及已报价／已设置变体；选择具体强化等级时仅生成该等级的合法品质变体，不预先生成全部强化组合。验收覆盖双语空状态、五项独立条件、空白搜索、移除的状态选项、清除筛选与勾选、筛选保留、无筛选导入／清空、无报价时五种合法品质及指定强化等级。默认开窗性能须用本轮测量记录；宽泛搜索或已定价／已锁定仍可能产生大量结果，不宣称本次解决全部筛选场景的卡顿。
- 价格表格操作区提供“清空价格”：通过原生确认对话框明确提示清空所有未锁定价格、不限当前筛选、已锁定保留；取消不改变状态，确认删除未锁定价格记录（含零价），保留锁定记录、报价缓存及分类偏好。无未锁定有效价格或正在读取／导入时按钮禁用；完成显示清空数量，保存失败按既有规则明确报告，各页面立即重估、不重跑模拟。验收覆盖取消／确认、零价、筛选无关、锁定保留及报价／偏好不变。
- 单项锁定和勾选批量锁定/解锁；全选范围为当前筛选全部结果，显示数量；筛选变化清空勾选。只改锁定，不改价格来源与时间；未定价也可锁定。用户可手动改锁定价格；在物品价格面板接受合法手动输入时（含 0 与清空）自动锁定该物品，并立即勾选锁定框；非法输入不改变价格或锁定状态，用户仍可主动解锁后允许导入覆盖。弹窗双语说明手动修改自动锁定及锁定阻止导入覆盖。验收覆盖未锁定价格修改、零价、清空、已锁定改价、非法值不变及主动解锁。
- 独立本地价格存储，与角色配置和清空隔离；导入分类偏好（含分类商人兜底模式）保存。保存失败明确提示，当前内存设置仍可用，不能显示已保存。
- 市场价格仅从官方公开 API `https://deepveinidle.com/api/market/prices.json` 读取，不依赖游戏登录、市场浏览或 userscript。“市场价格导入”区仅保留现有高亮样式、折叠和分类价格选项表格，删除官方 API 链接及导入按钮。“一键导入价格”移至下方价格表操作区，紧接“清空价格”，统一状态提示紧接导入按钮。导入按钮仅文字使用现有金色并加粗，背景及边框沿用普通次要按钮，不增加内描边或整块背景高亮；读取中或全部分类不导入时仍禁用并降低透明度，键盘焦点沿用现有轮廓。验收检查双语桌面／窄屏的文字高亮、禁用和位置。中英文同步移除游戏捕获和市场脚本提示。
- 打开或重新打开价格弹窗只展示本地价格、缓存报价和已有提示，不请求官方 API、不改有效价格；语言切换、分类展开／折叠及手动操作也不触发行情读取。不新增轮询或独立读取按钮；仅点击“一键导入价格”时请求 API，成功后按分类偏好更新有效价格和报价缓存，遵循浏览器正常 HTTP 缓存。请求有 10 秒超时；HTTP、网络、超时、JSON／结构错误、空数据和全量过旧数据明确报错，失败不应用价格、不以旧缓存假装成功。提示在下次成功导入前保持，重新打开弹窗、手动改价、锁定或清空不清除行情错误。验收检查打开／重开／切换语言／折叠均零请求、点击导入恰好一次请求、处理中重复点击不新增请求及失败重试。
- API `items` 的键为完整物品 ID，按现有品质／强化校验匹配，不根据名称猜测或降级；`lowestSell` 映射 ask，`highestBuy` 映射 bid，正数为报价，null 为明确无单；缺字段与非法值标为异常，不触发兜底，未知物品跳过并统计。顶层游戏标识、`generatedAt`、正整数 `refreshSeconds` 和物品对象必须有效；`generatedAt` 转为行情时间，不以请求时间替代。当前接口声明每 300 秒生成；响应头已核验允许跨域，实际浏览器连接另记验证。
- 分类表仅显示分类、报价物品数及价格选项，不显示分类时间或预计导入数。导入按钮后的单一状态节点依次优先显示读取中、行情错误、手动输入错误、操作结果或本地行情摘要；读取中仅显示一次“正在读取官方行情…”。已有报价缓存时摘要显示“已读取 N 个物品变体 · 行情更新于 日期时间 · 距今 N 分钟”，时间仍为原行情生成时间，没有缓存时不伪造读取成功提示。导入成功替换摘要为“已更新 N 项价格 · 商人价 N · 锁定跳过 N · 缺报价 N”，无法兜底／过旧／异常仅在非零时追加；锁定／解锁／清空结果替换正常摘要。合法手动改价恢复缓存行情摘要，行情错误仍保留至下次成功导入。提示在按钮后按一段显示，空间不足及窄屏允许自然换行，不截断、不横向溢出；错误使用 role=alert，其余使用 role=status。存档读取／保存异常保留独立警告，手动改价保存失败也须即时可见。表头不悬浮，分类表完整展开，由弹窗整体滚动；下方物品价格表保留现有紧凑布局、搜索、筛选、合法品质／强化变体及卖买报价列，未读取的报价显示“未读取”。验收覆盖双语按钮顺序、API 链接移除、单一提示与状态切换、折叠后仍可导入及窄屏换行。
- 分类选项按“卖单价 / 买单价 / 买单价（商人价兜底） / 商人价 / 不导入”排列。武器、护甲、饰品、工具、坐骑默认不导入，其余默认买单价商人兜底；保留已有偏好。卖单取最低卖价，买单取最高买价；兜底取买价与商人价的最大值，相等或商人胜出时来源和统计为商人价。明确无买单可兜底；缺项／异常不伪造无买单。不可出售物品有买单则取买单，无买单计入无法兜底。vendor 选项直接为可出售基础物品及已报价／已设置变体导入商人价，不生成所有强化组合；不可出售项跳过，行情请求失败时该模式也不应用。
- 导入按点击时分类偏好、应用时最新价格和锁定状态原子执行；锁定项不覆盖，未锁定手动价可覆盖。结果报告更新、商人价、锁定跳过、缺报价、无法兜底、过旧及异常数量。缓存与有效价隔离，缺价不填 0；保留各侧行情时间及防倒退。成功的官方全量快照替换缓存，已不在新快照的物品不沿用旧报价；比当前缓存最新时间更旧的整份响应拒绝应用。
- 价格存储升级至版本 3，继续使用原存储键：接收已发布版本 2，保留有效价格、来源、锁定、更新时间和分类偏好，丢弃旧游戏报价缓存，并清空旧有效价格中的报价时间（原捕获时间不可与官方生成时间比较）；首次读取不自动写盘，随后显式更新按版本 3 保存。其他旧格式仍明确拒绝，不迁移全局兜底开关。旧 userscript GM 市场缓存不再读写，也不主动删除脚本管理器历史数据。
- 战斗与采集删除掉落估值选项，始终按全局物品价格估值；完整物品 ID 未设置价格时使用可出售商人价（不可出售为 0），展开物品明细直接显示价格，不添加“单价”或 Unit price 前缀，物品名称／品质与价格之间仅用空格，不添加“·”；价格左侧保留提示标记及说明，缺价提示统一为“部分物品未设置价格，采用商人价格计算”（英文 Some items have no configured price; vendor prices are used）。表格掉落估值、收入、战斗食物与药剂成本与利润数字左侧也直接显示 ⚠，无需展开；仅实际参与该金额的正数量物品缺价时提示，已设置零价或导入商人价不提示。收入提示汇总掉落缺价，利润提示汇总掉落、食物与药剂缺价。零价格有效，导入商人价视为已设置。价格修改只重估及排序，不重跑模拟。
- 强化碎片、卷轴和底装以直接价格输入框显示有效价，未覆盖时沿用全局价，编辑后为本方案填写、清空为未定价、填 0 可表示已有底装，不再展示来源选项；强化右侧“强化配置”面板的“清空配置”恢复沿用全局价，左侧“清空配置”保留右侧价格覆盖；旧方案的来源含义保留。不从旧价格字段推导价格模式或底装绑定，配置须包含明确模式及绑定字段，无全局价时仍未定价。本方案底装和已有底装关联完整 ID，切换物品/品质/起始强化不套用旧底装费用；材料覆盖保留。强化原计算及 1.03 预算预留口径不变；该预留不是游戏实际征收的市场税。
- 验收覆盖完整 ID、空/零/非法值、锁定批量与筛选范围、偏好/保存失败、混合分类导入、兜底及失败原子性、报价倒退、旧格式拒绝、改价不重模拟、强化覆盖隔离、双语窄屏和键盘；官方 API 真实跨域与脚本管理器安装另核验，未完成不得宣称通过。

### 2.5 共用验收

核验品牌名称、各网址直接打开/刷新/前进后退、键盘导航、状态保留和进行中模拟；核验 [语言、布局与持久化](shared.md#22-语言布局与持久化)、[项目页脚](shared.md#23-项目页脚) 的语言回退、翻译、桌面/窄屏、保存失败及页脚。所有页面均须无阻断性脚本错误，旧配置兼容，非战斗字段不虚构战斗效果。源码一致性验收见 [原始代码复用](technical.md#62-原始代码复用)、[上游更新流程](technical.md#64-上游更新流程)。
