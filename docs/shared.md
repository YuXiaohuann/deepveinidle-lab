# 共用页面框架

[设计索引](../DESIGN.md) · [当前状态](status.md)

战斗、采集、制造页面统一使用“利润”称呼扣除既定成本后的金额，适用于表头、周期选项、汇总、提示与说明；英文沿用 Profit。计算口径、排序、周期折算及存储字段保持既定规则。验收要求：三个页面的应用文案不再出现“收益”，原有利润计算及交互保持一致。

战斗与采集页面的经验、金币及金额展示：绝对值达到 1,000 时使用 K（千）、M（百万）、B（十亿）、T（万亿）缩写，固定保留两位小数，负值保留负号；不足 1,000 沿用原有精度，中英文使用相同字头。适用战斗经验及分技能经验、金币、普通／稀有掉落估值、收入、食物与药剂成本、利润、明细物品价格，以及采集经验、金币、主要产物／额外掉落估值、收入和明细物品价格（含各采集点经验与金币）。战斗击杀／攻击次数、掉落及消耗数量，采集次数、尝试／被抓／回仓次数、产物及掉落数量均保持原展示；制造页面所有指标、其他页面、属性、时间、百分比、编号、种子和输入框不调整。仅在周期折算后格式化显示，不改变计算、排序或存储。验收覆盖双语字头、阈值与负值、明细一致性、次数数量及制造展示保持不变。实施验证见[当前状态与验证](status.md)。

### 2.1 导航与网址

- 右上角版本标识中英文均只显示当前包版本号（当前为 `1.2.5`），不添加“正式版”、测试版或 BETA 前缀。

- 页头（header）内部提供同级“战斗 / 采集 / 制造 / 强化 / 精通 / 预报”导航（英文 Combat / Gather / Crafting / Enhance / Mastery / Forecast），战斗网址为 `/combat`、采集网址为 `/gather`、制造网址为 `/craft`、强化网址为 `/enhance`、精通网址为 `/mastery`、预报网址为 `/forecast`，首页 `/` 显示战斗；当前角色配置、角色属性与敌人利润全部归入战斗板块。
- 导航使用真实链接，普通点击通过 History API 更新网址并切换内容可见性；支持复制链接、新标签打开与浏览器前进／后退。切换板块不重置角色配置、搜索、筛选、排序、采集与制造利润周期、折叠状态或已有模拟结果，也不重新启动模拟；进行中的战斗、采集与制造模拟继续完成。语言切换保留当前板块；直接打开或刷新按网址显示相应板块，不新增板块存储字段；刷新仍按原规则重置未持久化的筛选。
- 导航位于品牌与语言控件之间；窄屏时在页头内独占一行。页头、语言控件及项目页脚为各页面共用。导航支持键盘操作，有明确选中状态，中英文与窄屏均可用。

调试页网址为 `/debug`（也支持尾斜线），不出现在导航菜单；通过网址进入，沿用语言、页脚和页面状态保留规则。调试内容网格及文件输入在中英文 390px 下不得撑宽页面。

### 2.2 语言、布局与持久化

- 支持简体中文和英文；优先使用已保存的手动选择，否则浏览器语言列表包含中文时默认中文，其余默认英文。
- 游戏名称优先复用上游翻译字典；缺失翻译及已核验的新版说明集中补充。新增选项必须同时覆盖两种语言，中文模式不能遗漏药水、家园、精通名称或说明。
- 游戏文本核对范围为 `src/` 手写模块及 `index.html`，以本地已核验 1.0.1187 原始资源中的四组翻译为依据。相同含义的技能、属性、设施、药水、稀有度及特权名称复用原文与译文；补充字典仅作为上游缺词的回退，不能覆盖已有翻译。金币英文统一 Coins，避免与 Gold（金矿物品）混淆。复合说明保留模拟器限定语，仅统一其中的游戏术语；统计表的所需等级、采集次数及价格锁定等保留实际语义，不机械套用游戏不同上下文的译文。验收要求：逐项明细列明替换、现有复用、缺词回退和上下文保留；双语相关渲染及翻译优先级验证通过，不改变计算或保存协议。家园分组中文统一使用游戏已有“家园”（Home board 的译文）；英文 Home 保持不变，不能机械按 Home 的短译“家”缩写。实施状态：已随1.2.5发布，发布验收见 [当前状态](status.md)；明细见 [游戏文本核对报告](../reports/game-text-audit-2026-10-14.md)。
- 语言切换遵循 [导航与网址](shared.md#21-导航与网址) 的状态保留规则。所有页面的“导入游戏角色”首次打开或刷新默认展开，其它角色配置子菜单默认折叠，可独立展开或折叠；重绘与语言切换保留展开状态，不跨刷新保存。
- 战斗、采集、制造、强化、精通页在宽度大于 740px 时采用固定视口工作区：页头保持可见，左侧配置与右侧信息分别独立纵向滚动，到边界不带动外层页面；右侧属性、结果、说明与项目页脚整体滚动，表格仍可独立横向滚动。工作区高度由实际页头高度自动分配。宽度不超过 740px 时恢复上下排列与整页滚动，页脚位于全部内容末尾，不产生页面横向溢出。预报与调试布局不变。
- 上述五页切换、语言切换及配置／结果重绘保留各列滚动位置（内容变短时由浏览器裁剪）；不新增持久化字段，不改变计算或模拟流程。验收覆盖五页双语桌面、页头换行、左右滚动互不影响、页脚可达、键盘操作、重绘及页面切换保留位置、390px 上下布局。
- 使用浏览器 localStorage 自动保存语言及角色配置。旧配置按各字段的默认值和迁移规则规范化，未单列的新增字段补零或未启用；非法数据不得导致页面崩溃。
- 存储不可用时提示保存失败，计算仍应可用。

### 2.3 项目页脚

- 项目页脚在上述五页桌面布局中位于右侧信息末尾，其余页面及窄屏位于页面底部：以“项目作者（游戏昵称）：Alice”展示作者，Alice 为普通文本；交流 QQ 群 897891232 以可选择文本展示。右侧仅保留 Deep Vein Idle 入口，使用邀请链接 https://deepveinidle.com/?ref=Alice；不展示代码快照或 DESIGN.md 链接。
- 本地页脚来源说明显示已核验完整公开资源 1.0.1187（2026-10-13），当前生成模块无混合版本；生产版本仍使用原完整资源来源说明。
- 页脚提供中英文版权与项目关系说明：Deep Vein Idle 的名称、标识、设计、代码、素材、截图、角色、世界设定及其他可识别资源归原游戏作者或相应权利人所有，其他商标归各自权利人所有；本项目为玩家制作的非官方信息与交流工具，由项目作者独立维护，不代表原游戏官方立场或认可，不声称已获得官方授权。窄屏自然换行，不产生页面横向溢出。

### 2.4 全局物品价格

实施范围已于 2026-10-12 确认，已随 0.15.0 发布；分类商人价选项随 0.15.1 发布。共用页头提供带设置齿轮图标的“物品价格”弹窗入口，图标仅作装饰，不参与无障碍名称，所有页面可用；原生 dialog 支持关闭、Escape、点击弹窗外关闭及焦点返回，双语与窄屏可用。弹窗沿用现有面板背景、边框、字号、按钮、表头、说明文字与配置折叠风格，不引入独立配色。价格按完整物品 ID 独立设置，品质与强化不共价；空值未定价、0 为有效零价。分类复用保存上游定义；未适配的新物品明确跳过，不降级为基础物品。

- 分类、双语名称搜索、品质、强化（0 表示全部）和价格/锁定状态筛选；基础清单默认生成所有合法品质的未强化变体，保留原有基础物品的市场分类及可出售条件；已报价/已设置的变体继续显示。选择具体强化等级时，仅生成该等级的合法品质变体，不预先生成全部强化组合。验收覆盖无报价时五种合法品质、排除不存在的品质、已记录强化变体保留及指定强化等级筛选。
- 价格表格操作区提供“清空价格”：通过原生确认对话框明确提示清空所有未锁定价格、不限当前筛选、已锁定保留；取消不改变状态，确认删除未锁定价格记录（含零价），保留锁定记录、报价缓存及分类偏好。无未锁定有效价格或正在读取／导入时按钮禁用；完成显示清空数量，保存失败按既有规则明确报告，各页面立即重估、不重跑模拟。验收覆盖取消／确认、零价、筛选无关、锁定保留及报价／偏好不变。
- 单项锁定和勾选批量锁定/解锁；全选范围为当前筛选全部结果，显示数量；筛选变化清空勾选。只改锁定，不改价格来源与时间；未定价也可锁定。用户可手动改锁定价格；在物品价格面板接受合法手动输入时（含 0 与清空）自动锁定该物品，并立即勾选锁定框；非法输入不改变价格或锁定状态，用户仍可主动解锁后允许导入覆盖。弹窗双语说明手动修改自动锁定及锁定阻止导入覆盖。验收覆盖未锁定价格修改、零价、清空、已锁定改价、非法值不变及主动解锁。
- 独立本地价格存储，与角色配置和清空隔离；导入分类偏好（含分类商人兜底模式）保存。保存失败明确提示，当前内存设置仍可用，不能显示已保存。
- 市场价格导入复用角色导入的高亮容器、金色标题、边框、背景、展开间距及安装链接／按钮样式；状态为空隐藏，长文本换行。保留安装链接旁的导入按钮、各分类独立价格选项和紧凑分类表格。验收检查两类导入区域的视觉一致性及原有交互。
- 先打开并绘制窗口，再异步读取报价，仅更新缓存；读取启动前关闭窗口则取消此次自动读取；不提供独立读取按钮。一键导入位于安装链接旁，执行前仍读取脚本最新缓存。分类清单采用紧凑表格，表头随内容滚动，不悬浮；全部分类完整展开，不设置内部滚动；超出视口时由整个弹窗滚动。表格仅显示分类、从游戏捕获的物品变体数量和价格选项，不显示预计可导入数量或分类时间；捕获数量提示使用“已捕获 N 个物品变体”（英文“Captured N item variants”），后接最近报价时间及距今时长，不包含多余符号；摘要放在分类表格上方，仅下方物品价格表不展示时间，不显示“非全量市场”文字；连接失败或暂无可用报价时，该位置替换为高亮提示；无报价提示为“未读取市场报价，请在游戏中打开市场，再重新打开价格窗口。”，即使有旧缓存也不以旧数量遮盖错误。提示在下次成功读取前保持，改价/锁定不清除；不在下方重复显示。导入结果及操作状态紧接行情摘要/错误提示下方、分类表格上方显示。物品价格表头随内容滚动，不悬浮；收紧单元格及输入框间距，物品列按“名称·品质 强化 id”同行排列，名称、品质与强化共用名称样式，整列不加粗，编号使用较小较淡的说明样式，可视高度上限为 65vh（窄屏 70vh）。导入区不展示报价覆盖/手动价覆盖说明及兜底边界说明段落，中英文同步删除，规则仍按本节执行。武器、护甲、饰品、工具、坐骑默认不导入（off），其余分类默认买单价商人兜底（bidVendor），已有保存偏好保留；以平铺、每分类独立的单选按钮按“卖单价 / 买单价 / 买单价（商人价兜底） / 商人价 / 不导入”顺序显示；买单价仍取最高 bid，卖单价仍取最低 ask，窄屏允许选项自然换行，支持键盘操作。一键读取脚本缓存并原子应用合法价格，明确报告更新/兜底/锁定跳过/缺报价/无法兜底/过旧/异常数量。处理期间使用点击时策略、应用时最新价格和锁定状态；未锁定的手动价允许覆盖。
- 删除全局商人价格兜底开关；每分类独立单选“卖单价 / 买单价 / 买单价（商人价兜底） / 商人价 / 不导入”，武器、护甲、饰品、工具、坐骑默认不导入，其余默认买单价（商人价兜底）。兜底模式对本分类取商人价与最高买单价的最大值，商人价胜出或相等时来源显示“商人价”并计入商人价统计；明确无买单可使用商人价。普通买单价不兜底。商人价（vendor）直接设置本分类可出售普通物品及已报价／已设置变体的商人售价，不要求该物品有报价，不生成全部品质／强化组合；不可出售物品跳过并计入无法兜底，锁定价格保留，来源为商人价、报价时间为空。仍沿用一键读取脚本缓存后原子导入的流程；行情读取失败不应用价格。验收覆盖选项顺序、商人价偏好保存、无报价导入、变体、锁定保护及不可出售跳过。未捕获、异常、锁定及时间倒退保护保持不变；不可出售物品有买单则使用买单，无买单报告无法兜底。价格存储仅接受当前版本 2，不兼容未发布的旧格式，不自动迁移全局开关。验收覆盖独立分类兜底、普通买单不兜底、旧格式明确拒绝及保存往返。

- 市场缓存与有效价隔离，更新缓存不会自动改有效价；按物品/买卖侧保存时间，显示捕获数量、最近报价时间、距今时长与分类覆盖，时间同时用于报价合并及防倒退，导入时间不冒充行情时间。旧市场数据不倒退覆盖已有导入；来源缺价不填 0。
- 战斗与采集删除掉落估值选项，始终按全局物品价格估值；完整物品 ID 未设置价格时使用可出售商人价（不可出售为 0），展开物品明细直接显示价格，不添加“单价”或 Unit price 前缀，物品名称／品质与价格之间仅用空格，不添加“·”；价格左侧保留提示标记及说明，缺价提示统一为“部分物品未设置价格，采用商人价格计算”（英文 Some items have no configured price; vendor prices are used）。表格掉落估值、收入、战斗食物与药剂成本与利润数字左侧也直接显示 ⚠，无需展开；仅实际参与该金额的正数量物品缺价时提示，已设置零价或导入商人价不提示。收入提示汇总掉落缺价，利润提示汇总掉落、食物与药剂缺价。零价格有效，导入商人价视为已设置。价格修改只重估及排序，不重跑模拟。
- 强化碎片、卷轴和底装支持全局价格或本方案填写，底装另有已有底装为 0；不从旧价格字段推导价格模式或底装绑定，配置须包含明确模式及绑定字段，无全局价时仍未定价。本方案底装和已有底装关联完整 ID，切换物品/品质/起始强化不套用旧底装费用；材料覆盖保留。强化原计算及 1.03 预算预留口径不变；该预留不是游戏实际征收的市场税。
- 验收覆盖完整 ID、空/零/非法值、锁定批量与筛选范围、偏好/保存失败、混合分类导入、兜底及失败原子性、报价倒退、旧格式拒绝、改价不重模拟、强化覆盖隔离、双语窄屏和键盘；真实行情捕获另核验，未完成不得宣称通过。

### 2.5 共用验收

核验品牌名称、各网址直接打开/刷新/前进后退、键盘导航、状态保留和进行中模拟；核验 [语言、布局与持久化](shared.md#22-语言布局与持久化)、[项目页脚](shared.md#23-项目页脚) 的语言回退、翻译、桌面/窄屏、保存失败及页脚。所有页面均须无阻断性脚本错误，旧配置兼容，非战斗字段不虚构战斗效果。源码一致性验收见 [原始代码复用](technical.md#62-原始代码复用)、[上游更新流程](technical.md#64-上游更新流程)。
