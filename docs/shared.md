# 共用页面框架

[设计索引](../DESIGN.md) · [当前状态](status.md)

战斗、采集、制造页面统一使用“利润”称呼扣除既定成本后的金额，适用于表头、周期选项、汇总、提示与说明；英文沿用 Profit。计算口径、排序、周期折算及存储字段保持既定规则。验收要求：三个页面的应用文案不再出现“收益”，原有利润计算及交互保持一致。

战斗与采集页面的经验、金币及金额展示：绝对值达到 1,000 时使用 K（千）、M（百万）、B（十亿）、T（万亿）缩写，固定保留两位小数，负值保留负号；不足 1,000 沿用原有精度，中英文使用相同字头。适用战斗经验及分技能经验、金币、普通／稀有掉落估值、收入、食物与药剂成本、利润、明细物品价格，以及采集经验、金币、主要产物／额外掉落估值、收入和明细物品价格（含各采集点经验与金币）。

战斗击杀／攻击次数、掉落及消耗数量，采集次数、尝试／被抓／回仓次数、产物及掉落数量均保持原展示；制造页面所有指标、其他页面、属性、时间、百分比、编号、种子和输入框不调整。仅在周期折算后格式化显示，不改变计算、排序或存储。验收覆盖双语字头、阈值与负值、明细一致性、次数数量及制造展示保持不变。实施验证见[当前状态与验证](status.md)。

### 2.1 导航与网址

- 右上角版本标识中英文均只显示当前包版本号，不添加“正式版”、测试版或 BETA 前缀。

- 页头（header）内部提供同级“战斗 / 采集 / 制造 / 强化 / 精通 / 预报”导航（英文 Combat / Gather / Crafting / Enhance / Mastery / Forecast），战斗网址为 `/combat`、采集网址为 `/gather`、制造网址为 `/craft`、强化网址为 `/enhance`、精通网址为 `/mastery`、预报网址为 `/forecast`，首页 `/` 显示战斗；当前角色配置、角色属性与敌人利润全部归入战斗板块。

  公式页不出现在导航菜单，通过 `/formulas`（支持尾斜线）直接访问，使用独立阅读布局，详见 [公式页面](pages/formulas.md)。
- 未匹配任何页面的 URL 路径临时重定向（302）到 `/combat`，地址栏同步变为战斗页地址，不在原错误路径下直接展示战斗。已知页面、尾斜线及首页 `/` 的行为不变；前端处理历史导航中的未知路径时使用替换当前历史记录的方式归一到 `/combat`，避免后退反复回到错误地址。未知路径的查询参数与片段保留，与 Cloudflare Pages 重定向行为一致。托管规则在通配重定向前为首页、HTML 入口及 `src/`、`vendor/` 静态资源保留 200 映射，避免资源被重定向。本地服务继续拒绝受保护的文件路径。验收覆盖未知单层／多层路径、全部已知路由、静态资源正常访问和前端历史导航兜底。
- 导航使用真实链接，普通点击通过 History API 更新网址并切换内容可见性；支持复制链接、新标签打开与浏览器前进／后退。切换板块不重置角色配置、搜索、筛选、排序、折叠状态或已有模拟结果，也不重新启动模拟；进行中的战斗、采集与制造模拟继续完成。语言切换保留当前板块；直接打开或刷新按网址显示相应板块，不新增板块存储字段；刷新仍按原规则重置未持久化的筛选。
- 导航位于品牌与语言控件之间；窄屏时在页头内独占一行。页头、语言控件及项目页脚为各页面共用。导航支持键盘操作，有明确选中状态，中英文与窄屏均可用。

收藏页已移除。`/collection` 与 `/collection/` 按未知路径规则跳转到 `/combat`，客户端历史导航兜底保留查询参数与锚点；不加载收藏页面、计划或自动更新控制器，不读写旧收藏专用存档。精通页继续使用游戏收藏数据计算点数。验收覆盖两个旧地址的 HTTP 跳转及客户端历史导航、页面无收藏容器／资源请求，以及精通共用功能回归。

调试页网址为 `/debug`（也支持尾斜线），不出现在导航菜单；通过网址进入，沿用语言、页脚和页面状态保留规则。调试内容网格及文件输入在中英文 390px 下不得撑宽页面。

### 2.2 语言、布局与持久化

- 右上角语言切换入口仅显示语言图标，不显示当前语言文字或下拉箭头；打开后仍使用原生下拉选项“简体中文 / English”。保留“Language / 语言”无障碍名称、悬停提示及键盘焦点。验收覆盖双语桌面与 390px 窄屏的图标显示、选项不变、鼠标／键盘切换及刷新后语言保留。
- 支持简体中文和英文；公式页面正文、目录与提示仅中文，站点语言切换不翻译公式。优先使用已保存的手动选择，否则浏览器语言列表包含中文时默认中文，其余默认英文。
- 游戏名称优先复用上游翻译字典；缺失翻译及已核验的新版说明集中补充。新增选项必须同时覆盖两种语言，中文模式不能遗漏药水、家园、精通名称或说明。
- 游戏文本核对范围为 `src/` 手写模块及 `index.html`，以本地已核验原始资源中的四组翻译为依据。相同含义的技能、属性、设施、药水、稀有度及特权名称复用原文与译文；补充字典仅作为上游缺词的回退，不能覆盖已有翻译。金币英文统一 Coins，避免与 Gold（金矿物品）混淆。复合说明保留模拟器限定语，仅统一其中的游戏术语；统计表的所需等级、采集次数及价格锁定等保留实际语义，不机械套用游戏不同上下文的译文。

  验收要求：逐项明细列明替换、现有复用、缺词回退和上下文保留；双语相关渲染及翻译优先级验证通过，不改变计算或保存协议。家园分组中文统一使用游戏已有“家园”（Home board 的译文）；英文 Home 保持不变，不能机械按 Home 的短译“家”缩写。术语核对明细见 [游戏文本核对报告](../reports/game-text-audit-2026-10-14.md)。
- 语言切换遵循 [导航与网址](shared.md#21-导航与网址) 的状态保留规则。所有页面的“导入游戏角色”首次打开或刷新默认展开，其它角色配置子菜单默认折叠，可独立展开或折叠；重绘与语言切换保留展开状态，不跨刷新保存。
- 战斗、采集、制造、强化、精通页在宽度大于 740px 时采用固定视口工作区：页头保持可见，左侧配置与右侧信息分别独立纵向滚动，到边界不带动外层页面；右侧属性、结果、说明与项目页脚整体滚动，表格仍可独立横向滚动。工作区高度由实际页头高度自动分配。宽度不超过 740px 时恢复上下排列与整页滚动，页脚位于全部内容末尾，不产生页面横向溢出。预报与调试布局不变。
- 上述五页切换、语言切换及配置／结果重绘保留各列滚动位置（内容变短时由浏览器裁剪）；不新增持久化字段，不改变计算或模拟流程。验收覆盖五页双语桌面、页头换行、左右滚动互不影响、页脚可达、键盘操作、重绘及页面切换保留位置、390px 上下布局。
- 使用浏览器 localStorage 自动保存语言及角色配置。旧配置按各字段的默认值和迁移规则规范化，未单列的新增字段补零或未启用；非法数据不得导致页面崩溃。
- 存储不可用时提示保存失败，计算仍应可用。

桌面 1401–1480px 页头导航减小水平内边距，保证英文导航和右侧控件不溢出；窄屏右侧控件区限制在页头可用宽度内并自然换行。

#### 任务表格模拟状态

战斗敌人列表、采集任务、制造配方选择的模拟状态统一放在各自标题栏最右侧，包括进行中、进度、等待及失败信息；保留已有状态文案、更新时机与完成后的隐藏规则。采用小字、右对齐，长文及窄屏可自然换行，不截断失败原因，不占用搜索工具栏下方的独立提示行。配置、价格及行级不可用原因保持各自原位置。验收覆盖三页双语桌面／390px、进行中进度更新、失败及完成隐藏，保证页面无横向溢出。

### 导入游戏角色与自动更新

“导入游戏角色”共用模块负责战斗、采集、制造、强化和精通的自动更新设置、读取调度和状态。每页只提供“自动更新角色配置”（Automatically update character configuration），默认关闭。开关按页面独立保存在 `dvi-character-auto-import-<页面>-v1`，清空页面配置不清开关。旧制造设置保留config并忽略inventory，后续保存删除库存字段。坏设置明确提示并停止自动读取，不覆盖原存档，用户重新选择后恢复保存。

勾选后立即更新；进入页面、刷新恢复及该页活跃时窗口聚焦触发，不轮询，语言及结果重绘不触发。手动导入和自动更新共享忙碌状态，进行中的重复触发合并。离页、关闭／改变开关、重置或编辑期间的旧响应不得覆盖新状态；未提交输入暂缓自动更新，下一次触发重试。失败保留已有数据和开关，显示错误，后续触发可重试。

配置更新只使用各页既有角色映射，保留模拟时长，不导入不相关字段或另一页配置。制造不读取真实库存，也不校验库存；完整捕获与战斗选食所需仓库数据继续保留。

验收覆盖五页开关／独立保存和默认值、旧制造开关兼容、设置损坏保护、手动互斥、进入／焦点／返回与无轮询、编辑及迟到响应隔离、失败保留／重试，以及双语桌面／390px布局。

### 2.4 全局物品价格

独立模块的数据、访问协议及各页面定价见[物品价格模块](modules/item-prices.md)。所有页面通过公开服务获取价格，不直接读取存档；本节维护弹窗交互及导入规则。

共用页头提供带设置齿轮图标的“物品价格”弹窗入口，图标仅作装饰，不参与无障碍名称，所有页面可用；原生 dialog 支持关闭、Escape、点击弹窗外关闭及焦点返回，双语与窄屏可用。弹窗沿用现有面板背景、边框、字号、按钮、表头、说明文字与配置折叠风格，不引入独立配色。价格按完整物品 ID 独立设置，品质与强化不共价；空值未定价、0 为有效零价。分类复用保存上游定义；未适配的新物品明确跳过，不降级为基础物品。

#### 筛选与物品清单

分类、双语名称搜索、稀有度、强化和状态组合筛选。分类与上方价格选项表的原市场一级分类一致，使用“全部、资源、消耗品、装备、工具、贵重品”，复用同一原始分类定义，宝石归资源。强化默认值为 0，仅显示未强化物品；清空表示不限制强化等级，已有价格／报价的各强化变体均可匹配，填写正整数时只显示对应等级。清空强化属于主动筛选，可以单独激活清单；不因此穷举全部未报价、未配置的强化组合。状态按“全部／已锁定／未定价”排列：未定价包含未设置或显式空值，已设置 0 不属于未定价，已锁定空值可同时匹配已锁定和未定价。

分类、稀有度、状态均为全部，搜索去除首尾空白后为空，强化保持默认 0 时视为初始筛选：不生成或显示任何物品行，即使已有价格或报价缓存也保持空列表，显示“物品数量较多，请先设置筛选条件 / Many items to display; set a filter first”，提示使用现有金色并加粗，全选与批量锁定／解锁禁用、旧勾选清空。

任一非默认条件即显示匹配结果；稀有度“普通”（值 0）属于有效筛选，上方价格来源偏好不激活物品列表。已筛选却无结果时显示“没有匹配物品”。恢复所有默认条件后回到初始空状态，筛选变化清空勾选，关闭重开及语言切换保留会话内筛选；刷新恢复默认。筛选不请求行情、不修改价格或偏好，也不限制全局导入与清空未锁定价格的范围。

有效筛选下的基础清单生成所有合法品质未强化变体，保留原市场可出售条件及匹配筛选的已报价／已设置完整 ID；指定正强化等级时补齐该等级的合法品质，不预先生成全部强化组合。

验收覆盖一级分类与上表一致及宝石／坐骑归属、强化空值／0／正值、已锁定／未定价与零价／锁定空值、组合筛选、双语空状态、空白搜索、合法品质、勾选清空、会话保留及无筛选导入／清空。开窗性能结论须有对应候选的实际测量；宽泛搜索或未定价／已锁定仍可能产生大量结果，不保证所有筛选场景流畅。

#### 手动价格与锁定

价格表格操作区提供“清空价格”：通过原生确认对话框明确提示清空所有未锁定价格、不限当前筛选、已锁定保留；取消不改变状态，确认删除未锁定价格记录（含零价），保留锁定记录、报价缓存及分类偏好。无未锁定有效价格或正在读取／导入时按钮禁用；完成显示清空数量，保存失败按既有规则明确报告，各页面立即重估、不重跑模拟。验收覆盖取消／确认、零价、筛选无关、锁定保留及报价／偏好不变。

单项锁定和勾选批量锁定/解锁；全选范围为当前筛选全部结果，显示数量；筛选变化清空勾选。只改锁定，不改价格来源与时间；未定价也可锁定。用户可手动改锁定价格；在物品价格面板接受合法手动输入时（含 0 与清空）自动锁定该物品，并立即勾选锁定框；非法输入不改变价格或锁定状态，用户仍可主动解锁后允许导入覆盖。弹窗双语说明手动修改自动锁定及锁定阻止导入覆盖。验收覆盖未锁定价格修改、零价、清空、已锁定改价、非法值不变及主动解锁。

独立本地价格存储，与角色配置和清空隔离；导入分类偏好及各分类独立商人价兜底勾选状态保存。保存失败明确提示，当前内存设置仍可用，不能显示已保存。

#### 官方市场价格读取与提示

市场价格仅从官方公开 API `https://deepveinidle.com/api/market/prices.json` 读取，不依赖游戏登录、市场浏览或 userscript。“市场价格导入”区使用共用高亮样式、折叠和分类价格选项表格，不显示官方 API 链接。首次打开或刷新后默认折叠；用户展开／折叠状态在弹窗关闭重开、重绘、站内切页及语言切换时保留，不跨刷新保存。展开／折叠不请求行情、不改变价格或模拟状态。“更新价格”（Update prices）位于该区域顶部、“自动更新价格”选项左侧；统一状态提示在按钮下一行独占一段。导入按钮仅文字使用现有金色并加粗，背景及边框沿用普通次要按钮，不增加内描边或整块背景高亮；读取中或全部分类不导入时仍禁用并降低透明度，键盘焦点沿用现有轮廓。

导入提示统一使用“官方市场价格”：请求失败、请求超时、接口返回错误、早于当前缓存、数据格式异常及接口暂无物品报价均使用该称呼。英文文案保持不变。验收检查双语桌面／窄屏的文字高亮、禁用和位置。中英文均不显示游戏捕获和市场脚本提示。

打开或重新打开价格弹窗只展示本地价格、缓存报价和已有提示，不请求官方 API、不改有效价格；语言切换、分类展开／折叠及手动操作也不触发行情读取。不新增轮询或独立读取按钮；除打开或聚焦网站时按 5 分钟间隔判断的后台自动导入外，价格弹窗仅点击“更新价格”时请求 API，成功后按分类偏好更新有效价格和报价缓存，遵循浏览器正常 HTTP 缓存。请求有 10 秒超时；HTTP、网络、超时、JSON／结构错误、空数据和全量过旧数据明确报错，失败不应用价格、不以旧缓存假装成功。提示在下次成功导入前保持，重新打开弹窗、手动改价、锁定或清空不清除行情错误。验收检查打开／重开／切换语言／折叠均零请求、点击导入恰好一次请求、处理中重复点击不新增请求及失败重试。

API 完整物品 ID、六项行情字段及空值／非法值语义见[物品价格模块](modules/item-prices.md#数据与职责)；未知物品跳过并统计，不按名称猜测或降级。顶层游戏标识、`generatedAt`、正整数 `refreshSeconds` 和物品对象必须有效；行情时间取 `generatedAt`，不以请求时间替代。接口生成间隔及真实跨域状态须按对应候选的实际验证记录判断。

分类表按内容收紧列宽，不铺满弹窗；分类列仅保留内容所需空间，缩小单元格和选项间距，窄屏允许选项换行。分类表仅显示“分类”和“价格选项”两列，价格选项内保留独立商人价兜底勾选项；不显示报价物品数、分类时间或预计导入数。导入按钮下一行的单一状态节点依次优先显示读取中、行情错误、手动输入错误、操作结果或本地行情摘要；读取中仅显示一次“正在读取官方市场价格…”。已有报价缓存时摘要显示“已读取 N 个物品变体 · 行情更新于 日期时间 · 距今 N 分钟”，时间仍为原行情生成时间，没有缓存时不伪造读取成功提示。导入成功替换摘要为“已更新 N 项价格 · 商人价 N · 锁定跳过 N · 缺报价 N”，无法兜底／过旧／异常仅在非零时追加；锁定／解锁／清空结果替换正常摘要。

合法手动改价恢复缓存行情摘要，行情错误仍保留至下次成功导入。提示文本复用共用 `.micro` 默认字号、颜色与行高，错误仍使用共用警告高亮。提示外边距为 0，顶部 `.price-import-options` 不设置底部外边距，区块间距由父容器 `.import-body` 的 `gap` 统一控制；顶部内部 `gap` 仅控制按钮与选项间距。提示在按钮下一行按一段显示，空间不足及窄屏允许自然换行，不截断、不横向溢出；错误使用 role=alert，其余使用 role=status。存档读取／保存异常保留独立警告，手动改价保存失败也须即时可见。表头不悬浮，展开面板后分类表完整显示，由弹窗整体滚动；下方物品价格表保留现有紧凑布局、搜索、筛选、合法品质／强化变体及商人价格、卖买报价、7／30天平均成交价格及“在售数量 / Quantity for sale”“求购数量 / Quantity wanted”列，未读取的报价显示“未读取”。验收覆盖分类表双语两列表头及各行两列、按钮顺序、API 链接不显示、单一提示与状态切换、默认折叠、关闭重开／重绘／语言切换保留状态、刷新恢复折叠、展开后可导入、折叠不触发请求及窄屏换行。

#### 导入策略与存储迁移

价格选项表按游戏市场一级分类显示“全部、资源、消耗品、装备、工具、贵重品”，剔除独立宝石行，宝石沿用游戏归属计入资源。一级分类名称、顺序及细分类归属从已核验游戏市场分类提取，上游更新时同步核对，不另维护一套静态分类映射。下方物品表的分类筛选使用相同原市场一级分类，不包含特殊定价行。

价格选项表在“贵重品”下方增加独立行“贵重品（怪物的稀有掉落） / Valuables (monster rare drops)”，默认商人价，提供“继承全部”及相同六项价格来源、独立商人价兜底；不提供继承贵重品。适用物品从怪物专属稀有掉落 `bonus.itemId` 与原市场贵重品分类的交集派生（当前 13 种），按基础编号识别、按合法完整 ID 分别定价。该行覆盖这些物品的贵重品分类策略，独立于“贵重品”的来源及不导入设置；继承时直接使用“全部”的来源及兜底。物品列表筛选仍仅使用原一级分类，不增加子项。锁定、空值、零价、即时重算、不导入保留及请求迟到规则与其他行一致；重置恢复本行商人价。上游新增怪物掉落按相同交集自动纳入，宠物、坐骑、虚空碎片及烟花等未命中物品不受此行影响。

“全部”必须选择“7天平均成交价格 / 30天平均成交价格 / 卖单价 / 买单价 / 商人价 / 不导入”之一，新设置默认7天平均成交价格。其他原市场分类提供“继承全部”及上述六项，默认继承，可随时恢复继承；继承时价格来源和商人价兜底均取“全部”，本分类兜底控件禁用但保留自己的设置。指定独立价格来源后使用本分类独立兜底；兜底默认不勾选，仅均价及卖／买单模式可编辑。卖单取最低卖价，买单取最高买价；兜底取市场价与可出售商人价的最大值，相等或商人胜出时来源为商人价，明确无单／无成交记录可兜底，未读取／异常不可伪造无单。不可出售物品无单不能兜底。

修改价格来源、继承或兜底立即基于本地已缓存行情重算受影响分类的未锁定价格，保存并一次通知表格和对外协议消费者，不发送网络请求、不重跑模拟。缺少所选侧有效报价时清除未锁定旧价并显示未定价，避免旧来源残留；商人模式直接使用原始可出售售价。不导入模式保留已有价格并跳过后续更新。锁定价格（含空、零及手动设价）始终保留。重置恢复“全部”7天平均成交价格、怪物稀有掉落贵重品商人价、其他分类继承、兜底未勾选和自动更新勾选，并按相同规则立即重新定价；不改锁定或行情缓存。仅切换自动更新开关不重算价格。进行中的网络请求返回时，如果偏好已变化，按最新偏好应用，不能用旧选项覆盖当前结果。修改前取得的只读价格快照保持原值，新快照及接口同步返回新值，价格变化通知包含 prices。

“重置价格选项”（Reset price options）紧接“自动更新价格”右侧，与更新价格按钮共用操作行；窄屏空间不足时自然换行，不增加两侧自动留白。价格选项使用统一列布局，“全部”行在继承选项所在列保留不可交互、对辅助技术隐藏的空位，使两种均价、卖单、买单、商人、不导入及兜底与下方分类逐列对齐。桌面同行展示，窄屏按统一两列、四行排列，空位保留相同位置；验收覆盖一级分类与原始映射一致、宝石归资源、必选默认与独立覆盖／恢复继承、兜底继承、缺报价清除、零价与锁定、同次价格／偏好通知、旧快照隔离、修改期间请求迟到、旧存档选项重置、版本 6 增量迁移及版本 7 选择恢复、双语桌面／390px 与刷新恢复。

“市场价格导入”区域提供默认勾选并持久保存的“自动更新价格”选项（英文 Automatically update prices）。关闭时不请求、不更新自动导入记录；重新勾选后下次打开或聚焦按间隔规则判断。开启时打开任意网站页面或浏览器窗口获得焦点，若没有上次自动导入尝试记录，或距上次尝试已满 5 分钟（300000ms，含边界），则后台自动导入一次，使用当时保存的分类与兜底偏好；不自动打开价格弹窗，不阻塞页面和模拟。请求发起前将尝试时间戳保存至独立本地存储，5 分钟内刷新、开新标签不重复触发；跨标签并发使用浏览器 Web Locks（可用时）协调。失败同样计入 5 分钟间隔，可立即手动重试；全分类不导入时跳过且无完成提示。打开／刷新及每次窗口聚焦触发判断，站内切换不触发，不设置后台轮询；持续停留网站不会每 5 分钟自动导入。完成后右上角显示双语通知，成功及失败提示均在显示 30 秒后自动关闭；不显示关闭按钮，点击整条提示可立即关闭，键盘聚焦后按 Enter 或空格同样关闭，手动关闭时清理自动关闭计时器。成功提示“物品价格自动导入完成，已更新 N 项价格。”，失败以“物品价格自动导入失败：”开头并明确原因、保留原价格；保存失败不能显示已保存。原存档损坏／读取失败时跳过自动导入并提示，避免覆盖原数据；尝试时间戳无法读取或保存时明确报错并跳过请求。网络请求与手动导入复用；锁定价格保持不变。

验收另覆盖 13 种掉落识别与深渊之眼原始特殊售价、非命中贵重品不变、独立子项与贵重品不导入隔离、继承全部及独立兜底、锁定空／零价、切换即时重算、旧快照、存档迁移与刷新恢复。验收覆盖全部默认7天平均成交价格、其他分类继承及兜底未勾选、卖／买两侧兜底与独立保存、旧偏好迁移、自动导入勾选保存与关闭跳过、重置及即时定价、首次打开／聚焦触发／5 分钟内跳过／恰满 5 分钟触发／跨标签去重、后台导入成功／失败／保存异常、锁定保留、全分类跳过、双语桌面及窄屏通知、无关闭按钮、点击／键盘关闭与 30 秒自动关闭。

多个入口并发时共享同一网络请求；价格面板导入按应用时有效偏好、最新价格和锁定状态原子执行；锁定项不覆盖，未锁定手动价可覆盖。结果报告更新、商人价、锁定跳过、缺报价、无法兜底、过旧及异常数量。缓存与有效价隔离，缺价不填 0；保留各侧行情时间及防倒退。成功的官方全量快照替换缓存，已不在新快照的物品不沿用旧报价；比当前缓存最新时间更旧的整份响应拒绝应用。

价格存储使用版本 7 和原存储键，接收版本 2～6 时先校验原存档，非法格式明确拒绝。旧版本 2～5 升级为版本 7 时统一重置价格来源：“全部”使用7天平均成交价格，怪物稀有掉落贵重品使用商人价，其他分类继承，商人价兜底关闭，清除旧分类待确认标记；保留自动更新开关（旧版无此字段则默认开启）、已有价格、行情和锁定。首次读取不主动写盘或改价，下次导入按新选项更新未锁定价格；后续保存为版本 7。版本 6 升级保留已有分类选择、兜底、待确认标记及自动更新开关，仅新增怪物稀有掉落贵重品默认商人价及关闭的独立兜底；同样不在首次读取时写盘或改价。版本 7 保存后的用户选择正常恢复，不重复重置。

版本 2 另丢弃旧游戏报价缓存并清空有效价格中的报价时间；版本 3～5 保留官方缓存，旧缓存未包含均价时显示未读取。独立尝试时间戳键为 `dvi-price-auto-import-at-v1`，不改变角色配置存档。旧 userscript GM 市场缓存不再读写，也不主动删除脚本管理器历史数据。

#### 页面估值与强化覆盖

战斗与采集不提供掉落估值选项，始终按全局物品价格估值；完整物品 ID 未设置价格时使用可出售商人价（不可出售为 0），展开物品明细直接显示价格，不添加“单价”或 Unit price 前缀，物品名称／品质与价格之间仅用空格，不添加“·”；价格左侧保留提示标记及说明，缺价提示统一为“部分物品未设置价格，采用商人价格计算”（英文 Some items have no configured price; vendor prices are used）。

旧估价字段仍由配置规范化固定为全局价格模式，保留现有存档结构；页面不再保留仅数量、仅商人价、隐藏收入列的显示分支。验收检查旧字段不能改变列数、金额、缺价提示或价格变更不重跑模拟的行为。

表格掉落估值、收入、战斗食物与药剂成本与利润数字左侧也直接显示 ⚠，无需展开；仅实际参与该金额的正数量物品缺价时提示，已设置零价或导入商人价不提示。收入提示汇总掉落缺价，利润提示汇总掉落、食物与药剂缺价。零价格有效，导入商人价视为已设置。价格修改只重估及排序，不重跑模拟。

强化通过价格模块读取全局价格，允许方案内覆盖且不改全局价格；三项输入、完整 ID 绑定、左右清空范围、旧方案校验及缺价规则统一见[强化价格设置](pages/enhancement.md#42-装备保护与价格设置)，成本与收费展示见[强化结果](pages/enhancement.md#44-结果展示与范围边界)。

#### 价格验收

验收覆盖完整 ID、空/零/非法值、锁定批量与筛选范围、偏好/保存失败、混合分类导入、兜底及失败原子性、报价倒退、旧格式拒绝、改价不重模拟、强化覆盖隔离、双语窄屏和键盘；官方 API 真实跨域与脚本管理器安装另核验，未完成不得宣称通过。

资源适配边界：既有配装、工具与角色导入仍保留 +0–+100 的物品强化值；新强化任务目标限制由强化页单独处理。物品及配方候选使用原始有效列表，保留上游对未开放炖菜、腌鱼、便当及材料的排除；不增加农耕或便当增益配置。

### 2.5 共用验收

核验品牌名称、各网址直接打开/刷新/前进后退、键盘导航、状态保留和进行中模拟；核验 [语言、布局与持久化](shared.md#22-语言布局与持久化)、[项目页脚](shared.md#23-项目页脚) 的语言回退、翻译、桌面/窄屏、保存失败及页脚。所有页面均须无阻断性脚本错误，旧配置兼容，非战斗字段不虚构战斗效果。源码一致性验收见 [原始代码复用](technical.md#62-原始代码复用)、[上游更新流程](technical.md#64-上游更新流程)。

## 上游等级上限

游戏 1.0.1208 起，全部精通等级为 0–200，全部家园建筑（含符文书台）等级为 0–50；原始成本与加成公式不变。各页面输入上限、配置规范化、角色导入和精通搜索共用已核验的原始上限。战斗／采集／制造沿用规范化规则，将旧本地配置越界值限制到上限；角色导入沿用逐字段警告：战斗的越界家园／精通字段回到默认零，采集／制造保留对应当前值。强化与精通页沿用严格校验，越界旧存档或导入明确报错，不静默调整投入或预算；旧存档读取失败时展示默认配置并保留原存储，直到用户主动修改保存。精通只读取当前激活的 player.masteries，不提供第二套精通管理。

验收覆盖 199／200／201 精通、49／50／51 家园，输入 max、旧配置恢复、逐字段警告及严格导入原子拒绝、精通 MAX／搜索候选不越界，以及现有战斗、采集、制造和强化原始计算对照。
