# 调试页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

- 仅通过 `/debug` 进入，不增加菜单链接；提供中英文界面。页面标题下按“导出为文件”“从文件导入”顺序纵向排列两个独立 panel，桌面及窄屏均保持分离。
- 导出面板提供普通角色 userscript 安装／更新链接和“导出角色配置”。读取最近捕获数据，沿用配置导入校验，将配置捕获对象（含读取时间及世界增益）下载为 JSON；无需打开战斗预测，可用于战斗／强化导入配置，不修改当前配置。读取或校验失败明确提示，不下载替代数据。
- 选择 JSON 配置文件后，分别提供“导入战斗配置”“导入强化配置”，复用对应页面导入流程；战斗配置自动保存并保留模拟选项，强化配置独立保存并更新临时装备候选。文件导入无需连接 userscript。
- 文件与结果提示在页面／语言切换时保留，刷新清除；文件格式或对应导入校验失败保留原配置。保存失败按对应页面现有提示显示。
- 删除完整角色快照的游戏读取、文件导入、导出、捕获脚本及专用桥接；旧完整快照不再有模拟入口。普通角色配置桥接的数据字段及存储键保持兼容，不因内部名称包含 snapshot 而删除。
- 验收：导航无调试链接，网址直接打开／刷新／前进后退正确；JSON 配置导出再导入保留配置捕获字段；两个入口与原入口效果一致；非法 JSON 和无效角色数据明确失败且不覆盖现有状态；两种语言均无快照操作和调试脚本安装入口，窄屏可用。
