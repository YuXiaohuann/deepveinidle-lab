# 收藏性价比页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

## 入口与范围

隐藏页面 `/collection`（含尾斜线）仅通过 URL 进入，不列入菜单，沿用共用语言、页脚、物品价格和历史导航。页面比较亲自产出至收藏里程碑所需的时间与材料成本，不操作游戏或分配精通点。

支持采矿、钓鱼、伐木、偷窃及烹饪、锻造、箭矢、炼药、制作九种技能的普通主产物配方。结果仅生成受支持路线；战斗、农耕、宠物、随机副产物、即时升级和强化录不提供成本计算。合法收藏目录中的这些进度仍可导入保存。同物品的多条来源独立比较，不能相加为全局最优计划。

收藏目录、数量门槛及奖励复用原始提取器。普通门槛为 1/10/100/1千/1万/10万/100万/1千万，本档基础奖励为 1/1/3/10/35/120/420/1500，五品质倍率为 1/3/10/30/100；宠物仅 1 个门槛、固定 1000 点。购买成品不增加数量收藏，即时升级只更新发现标记，retired 配方不作生产路线。

游戏 1.0.1194 只使用原始有效配方及物品表，未开放的炖菜、腌鱼和便当不作为收藏候选。材料采购及缺价规则不变，不增加锻造录计划或农耕候选。验收覆盖未开放物品不展示与既有原始目标事件对照。

## 进度、配置与导入

首次打开须导入或明确选择“手动场景（从零开始）”，不把尚未导入视为零进度。通过共用角色桥接协议 2 的读取动作导入 collections 和角色配置，不要求 forgeLog。合法稀疏数量的缺项为 0。逐条导入收藏记录：ID 须为可解析且无强化等级的基础物品／品质编码，数量须为非负安全整数；错误记录（含带强化等级、未知 ID、非法键或数量）跳过，不归并到其他 ID，保留其余合法记录，并显示中英文警告及跳过条数。合法但不在本页收藏目录内的记录仍忽略，不计为错误。警告随配置保存，刷新后保留，下次完整合法导入清除。缺整个 collections、必要角色属性或仓库数据错误时仍原子失败，保留有效状态。

只保存初始化标记、最小角色配置、收藏数量、仓库数量、捕获时间、导入警告及材料采购价格模式；使用 `dvi-collection-v1` 的首版结构，角色存档不保存完整快照、计划目标、筛选或模拟结果（筛选单独保存），不提供开发期存档迁移。收藏进度通过角色导入更新；清空配置恢复未初始化，不清除全局价格。非法输入不覆盖有效保存，存储读写错误可见。

左侧配置面板标题为“角色配置”（Character build），与其他页面一致。角色配置只有一份，按以下主题组织折叠项，共享字段只出现一次：

| 主题 | 配置及作用 |
| --- | --- |
| 技能 | 九种技能等级，显示当前工作速度加成 |
| 工具与装备 | 九种工具、护符与坐骑的品质及强化；工具影响工作，幸运影响采集品质，坐骑影响行程 |
| 药水与祝福 | 采集经验、猎人酿剂、矿脉灵药、疾行药剂及矿脉祝福；制造只使用通用药剂 |
| 家园、精通、天赋 | 相关工作／幸运设施；采集、制造、经验、移动、稀有精通；大口袋、快手、稳手，显示原始说明与当前加成 |
| 公会、世界与热门 | 小数公会经验、世界经验及世界稀有发现；热门可选沿用游戏、按当前时间、不计入 |
| 行程 | 初始仓库、采集铁人模式；显示容量和移动速度 |

经验只影响模拟中的成长，移动只影响行程，口袋只影响容量及回仓；稀有发现只影响采集，普通制造按指定品质产出。两类计算共用经验／移动精通、坐骑、通用药剂和相关加成，采集／制造速度各自作用于对应任务。药剂与祝福保留属性作用，不估算其消耗量或费用。

导入保留有效药剂品质、祝福、小数公会经验及捕获时全部有效世界增益。缺完整世界增益能力标记或数据格式错误时，世界经验与稀有发现清零并显示共用警告；提示针对捕获数据，当前手动配置以表单为准。其余必要字段错误时整体导入失败。

## 执行计划

目标行提供“加入计划”按钮，按钮独占结果摘要最右列，不增加配方展开内容。计划以完整物品ID＋配方ID分组，同组只保留最高目标档，低档显示“已包含在目标…中”且不可重复添加；重复添加幂等。取消最高档移除整个方案，不恢复隐藏低档选择历史；独立计划表显示“物品、稀有度、数量、完成进度、操作”五列，数量为所选收藏目标数量（不是剩余产量），完成进度按当前收藏数量／所选目标数量显示，并附百分比（向下取整到整数，上限100%）；达到目标保留当前数量／目标数量并显示“已完成”，不再显示“ · 100%”；未初始化显示 —。导入或配置重置后同步更新。“操作”列按“增加、减少、移除”顺序显示可点击文字，始终横向单行排列并与其他单元格文字使用相同行高和基线，不使用原生按钮的最小高度。文字操作提供按钮语义、焦点样式及Enter／空格激活；禁用项显示淡化，不进入Tab序列且不可触发。增加／减少每次切换到相邻的原生收藏档位，首档禁用减少、末档禁用增加；允许切换到已完成档。文字操作保留包含物品名与操作的无障碍名称，调整后立即保存并重算数量、进度和材料需求；“移除”移除该物品方案，不恢复隐藏低档历史，也不影响角色或其他方案。结果列表仍可移出后重选。每个物品＋品质仅保留一条来源，切换来源替换原方案。

计划面板的“隐藏已完成”（Hide completed）复选框默认勾选，位于“已选方案 · 已完成 · 所选目标奖励 · 期望材料成本”汇总同行右侧，窄屏空间不足时换行。仅隐藏计划表中已完成的方案，不移除计划、不改变汇总、材料计算、存档或候选列表；未初始化及不可计算方案仍显示。取消勾选可查看并操作已完成方案；全部已完成且勾选时表内提示“所有方案均已完成”。选项在同次会话的配置、导入、排序、语言及切页重绘时保留，刷新恢复默认勾选，不写入角色或计划存档。

计划表仅在完成进度中标记“已完成”，不另列计算状态；异常信息由面板汇总及结果列表保留。计划面板提供方案数、所选目标奖励、期望材料成本、方案状态和材料需求表。选择不受搜索、筛选、分页、排序或语言影响，列表旁始终提供已选数及计划定位入口，右侧提供“将当前筛选的XX个方案加入计划”。数量及加入范围为全部筛选结果中可加入的目标行（不受分页限制，排除已完成及不可计算行）；同物品不同档位合并至最高目标，保留已有更高目标，重复加入幂等。无可加入行、筛选无效、未初始化或计划读取失败时禁用；批量操作一次保存并重算，不清除原计划。材料按完整ID归并，保留不同品质，以表格依次显示“物品、稀有度、需要采购、库存 / 需求、单价、总价”，不展示或保存来源方案信息。计划及材料表格采用内容自适应列宽，取消固定最低表宽及逐列固定宽度，单元格左右留白缩至4px。两个表格的表头均垂直居中，可排序按钮取消全局按钮的最小高度，行高继承表头，使排序与非排序标题对齐；表头、物品名称及完成进度允许换行，稀有度与独立数值列保持完整，不截断、不缩写、不拆开数字；物品列至少保留60px，完成进度列至少保留80px。空间不足时各表内部横向滚动，不撑宽页面；两个表格的第一列（物品）表头及数据单元格均固定在各自滚动容器左侧，横向滚动时保持可见，使用不透明背景避免与其他列文字重叠。先全精度累计，再按同种材料向上取整；不对各来源方案分别取整，不把期望值称为保底备料。复用现有配方、烧焦及采购价格规则，只抵扣已导入仓库，不抵扣其他方案产物，不合并药剂，不推导全计划联合时间或跨路线最优执行。

两个表格的物品名称与稀有度分列显示。计划表的物品、稀有度、数量，以及材料表的物品、稀有度、需要采购、单价、总价支持点击表头排序，首次点击升序，再次点击切换降序，并显示方向箭头及无障碍排序状态。物品按当前语言的基础名称排序，稀有度按普通至传说排序，数值按未格式化原值排序；未知值在升降序均置后，相同值按完整物品ID升序稳定排列。两个表格独立保存会话内排序，配置、报价及语言重绘保留，刷新恢复默认物品ID顺序；排序不改变计划存档、计算或候选列表。

材料表“库存 / 需求”列位于“需要采购”后，合并显示“库存 / 需求 · 百分比”，数量使用计划取整值；百分比为库存覆盖需求的比例，向下取整到整数，上限100%，已知库存且需求为0时显示100%。未知库存或需求保留对应的 —，百分比显示 —。该列仅展示，不支持排序；不再提供独立需求／库存列表头。合并内容允许在数字之间换行，各个数字及百分比不拆分，不改变采购计算或汇总。

仓库数量取成功导入角色时的 `player.bank`，按完整物品ID匹配（品质独立），不计背包、溢出或装备。所有方案材料先按全精度汇总，同种材料的预计需求向上取整到个位；库存数量也向上取整到个位（导入库存本身须为整数）。每种材料仅扣减一次库存：需要采购=ceil(max(0,取整后的预计需求−取整后的库存数量))，总价=取整后的需要采购×当前采购单价。预计需求、库存数量、需要采购均显示整数；单价、总价仍四舍五入显示到个位，原始报价保持精度。库存充足时需要采购及总价为0，即使没有报价也不计作材料缺价；库存不足时缺价仍显示未知成本。计划汇总的期望材料成本及有效部分已知价格小计均使用取整后的采购总价；候选方案的材料成本／每点指标仍为原始配方消耗，不受库存及计划取整影响。

仓库随手动／自动角色导入更新并独立于执行计划保存，导入缺整个bank或数量非法时原子拒绝；失败保留之前收藏、配置及库存。尚无仓库数据时库存、需要采购及总价显示 —，计划提示重新导入，不能把未知库存当0；已有角色配置可以保留。手动从零场景明确采用空仓库，清空配置清除已导入库存；无材料需求时不要求库存。已初始化的仓库缺某物品视为0。采购数量或金额超限沿用现有提示，不截断、不用库存掩盖未知需求。

当前进度9的普通青铜锭，同时加入10/100/1000档只保留1000档：铜、锡各991份，所选目标奖励14点，而不是材料1083份／19点。普通与罕见独立计算，同材料跨方案合并。采集多品质同时产出，但当前采集无材料输入；仅汇总所选目标奖励，不计未选品质或副产物奖励，不将独立采集耗时相加为联合期望。

角色配置或收藏更新后重新评估计划，价格变化仅重估费用。已达目标保留完成状态、剩余需求与奖励为0；等级不足、零概率等方案保留并说明，整体明确“未完整计算”，有效部分材料可查看，不将无效方案当0需求。需要采购的材料缺价不影响数量，金额显示 — 并注明已知价格小计；需求累加或金额超限独立提示，不丢弃、不截断。

计划独立保存在 `dvi-collection-plan-v1`：版本1及 `{itemId,jobId,target}` 列表，读取严格校验并规范化同组最高档，坏计划可见且原存储不覆盖，须明确清空后重新选择。“清空计划”只清计划；“清空配置”保留计划，并在按钮说明注明，清空后因角色未初始化将计划标记不可计算。导入角色保留计划及目标，按新进度计算，不保存金额或材料快照。

## 持续自动导入

“导入游戏角色”内提供单条选项“自动导入（聚焦时及每60秒）”，不另列说明段落，自动导入设置错误区仅有内容时显示，不留空占位；默认不勾选，独立保存在 `dvi-collection-auto-import-v1`，不更改既有角色结构。勾选立即导入一次；收藏板块启用期间，每60秒及浏览器窗口获得焦点时导入，后台窗口仍保留定时尝试（受浏览器节流影响，不承诺精确60秒）。切换其他板块暂停，返回收藏板块或刷新后勾选状态有效则立即恢复。关闭选项停止后续自动读取；手动导入始终可用。

复用现有只读桥接和完整导入校验。每次成功接受角色导入后（含手动及自动），立即刷新官方市场数据，仅更新官方报价缓存并重算列表及计划金额；角色失败或被判定过期的响应不触发行情。角色与市场状态分别提示，行情失败保留已有报价及已导入角色，后续成功导入继续重试。全局市场请求共享并发，同一时刻只发起一次；请求返回时保留全局有效价格记录不变。页面打开仍不单独请求行情。自动读取替换本页收藏及角色配置，保留执行计划。手动／自动共享忙碌状态，任一导入进行中不启动另一请求；相近焦点与定时触发合并。自动导入期间关闭选项、离开板块、重置或修改角色／存在未提交输入时，旧响应不得覆盖新的状态；自动导入会暂缓未提交输入，下一触发重试。失败保留有效配置和计划，显示现有导入错误且保留选项，后续触发仍可重试。定时器与焦点监听仅注册一份，语言重绘不重复启动或清除原有展开状态。

## 目标与时间

每个物品、品质和来源枚举全部未来未完成档，各档都从当前进度独立计算，目标标识包含物品、来源和目标档。完成物品仅在“含已完成”开启时保留一条记录。列表不保存目标选择。

默认估算固定当前属性的纯动作时间，不含移动、取材、回仓和升级。tick 为 0.6 秒，缺口 D、每次产量 y 时，所需成功次数 K=ceil(D/y)。

- 制造烧焦概率 b：预计执行次数 K/(1−b)，耗时为次数乘原始每 tick 工作概率的倒数与 tick 时长。
- 采集目标品质概率 q、被捕概率 c：预计执行次数 K/((1−c)q)，耗时为次数×(0.6/p+c×max(stunTicks−1,0)×0.6)。原始引擎在 stunUntil 当刻恢复，不能多算一个停顿 tick。

品质概率、工作速度、烧焦及被捕复用原始机制。动作估算冻结所选时刻的热门；“沿用游戏”使用预测起点，“按当前时间”使用当前时刻，“不计入”抵消热门。世界增益、药剂与祝福假设全程有效。只对已核验固定批量和成功事件使用上述到达期望；概率为零、等级不足、无合法地点有明确状态。

页面提供纯动作估算，不提供逐路线模拟入口。独立目标事件模拟模块保留用于离线计算回归，按原始 produced 事件停止，验证行程、成长、随机品质／烧焦及实际消耗口径；它不在配方展开区展示。

## 材料成本

通过[物品价格模块](../modules/item-prices.md)读取价格。新建及清空配置默认全局价；旧存档保留原明确选择的 ask/bid/vendor。

新增点数 P=原始累计奖励(有效产出终点)−原始累计奖励(当前)。批量产出越过门槛时计入全部新增奖励，不计其他物品的副奖励点数。只有 P>0 才计算每点指标。

候选方案材料总成本 G=配方材料数量×采购单价之和，不抵扣库存、不假定材料自采；执行计划材料表按上节仓库抵扣后的采购数量计算总价。时间／点为耗时/P，材料金币／点为G/P。页面不计算产物回收、药剂消耗及费用、总投入、净投入或利润；药剂、祝福的属性加成仍按配置全程有效。设备购置、交易等待／费用不计入材料成本。

材料成本可选全局物品价格 global（默认）、官方市场卖单 ask、买单 bid、商人价格 vendor，选择独立保存并同时作用于结果列表及计划材料汇总。市场模式只读取API对应侧报价，无单／异常／未报价显示缺价，不自动兜底。商人价格使用原始游戏商人售价作材料估值，不代表材料可向商人购买；不可出售材料无商人估值。全局模式读取用户物品价格（含手动锁定）；其他模式只读取对应来源，不受全局价格与分类偏好影响。明细显示对应来源，API来源附生成时间，商人估值不伪造时间。已删除的回收配置忽略，角色和计划保持。

角色导入触发的市场刷新仅更新官方报价缓存，不改全局有效价格记录或偏好；与价格弹窗共享网络请求，价格弹窗自己的导入仍遵循原规则。全局价格弹窗刷新相同API缓存时，本页会随报价变化重估，全局模式也随物品价格修改重估，分类选项本身不直接改变现有价格。

缺材料价使G和材料金币／点不可计算，不影响时间。材料金额超过安全范围时，仅材料金额及其每点指标显示 —，保留其他有效值；行与汇总明确区分超限和缺价，清单逐项标记，不清空整表、不截断或填零。报价更新即时重估并清除失效提示。

## 界面与筛选

左配置右结果，窄屏垂直排列。结果面板标题为“精通性价比”（Mastery efficiency），候选方案每页固定显示10条，仅在清单下方提供上一页、页码／总页数及下一页；不足两页时隐藏翻页控件。手动翻页定位到清单顶部；筛选、排序和材料成本模式变化回到第一页，角色导入、配置与语言重绘保留页码，结果减少时收敛到最后一页。汇总及计划计算使用全部结果，详情按需生成。正常可计算结果不显示“纯动作估算”等状态文字；已完成、等级不足及其他异常状态仍显示。结果列依次为：

1. 名称 · 品质（中点两侧各一个空格，同字号和字重），技能来源另行显示。
2. 当前 → 目标。
3. 新增精通点。
4. 总材料成本，即 G，缺价／超限显示 —，合法零成本显示 0。
5. 总时间：从当前进度到所选目标的预计动作耗时，按秒／分钟／小时显示，沿用固定配置估算口径；不可计算显示 —。
6. 秒／点。
7. 材料金币／点。
8. 计划操作：加入计划、移出计划或已包含目标。窄屏换行后仍位于最后，靠右显示。

候选方案总材料成本、材料金币／点四舍五入显示到个位，总时间（当前显示单位）、秒／点四舍五入保留1位小数；仅调整展示，不影响原始计算、筛选与排序，缺失值仍显示 —。

物品名称统一按基础物品 ID 复用共用翻译，覆盖列表、装备／药剂选项与材料／产物详情；不直接翻译带品质前缀的英文名称。搜索同时匹配原始英文名和基础物品中文名，任意品质均支持中文查询。

筛选与键盘顺序一致，桌面分三行，窄屏各行内自动换行，无横向溢出。不另展示比较规则说明或市场／商人价格说明段落，比较符号、分钟单位及“不限”直接由标签和占位提示表达：

| 行 | 顺序与默认值 |
| --- | --- |
| 第一行 | 类型（制造）、技能（全部，仅九种支持技能）、品质（全部）、物品搜索（空） |
| 第二行 | 材料成本（global）、排序（材料成本升序）、仅显示等级达标（勾选）、包含已完成（不勾选） |
| 第三行 | 新增精通点 ≥、总材料成本 ≤、总时间 ≤（分钟）、秒/点 ≤、材料金币/点 ≤（均留空不限） |

类型可选全部／采集／制造；各筛选取交集。“仅显示等级达标”只比较当前技能等级和配方要求，不依据概率、地点或报价筛选，与“含已完成”独立。

第三行按用户约定使用包含等号的比较，各条件取交集：新增精通点大于等于输入值，其余指标小于等于输入值，允许恰好等于。所有输入支持非负有限小数（不超过安全整数上限），留空不限、0有效；负数、非数或超范围时提示并隐藏结果，修正后恢复。总时间按分钟比较未舍入耗时，其他指标也使用原始未舍入值。启用某项上限时，缺价／溢出／不可计算导致该指标未知的结果不匹配；未启用则保留原有缺价提示。筛选不改变执行计划及其汇总。

排序选项为时间升序、材料成本升序，均按每点新增精通计算，缺失金额及不可计算项置后。汇总显示支持路线的未完成／匹配目标数、材料缺价及金额超限数。

筛选与排序独立保存于 `dvi-collection-filters-v1`，包括类型、技能、品质、搜索、排序、等级达标／包含已完成及五项阈值，修改后自动保存并在刷新时恢复；阈值保留原输入文字，无效输入刷新后仍显示校验提示。材料成本模式继续随角色配置保存。页码和展开状态不持久化，刷新回到第一页并收起详情；同次语言及页面切换仍保留。筛选读取失败显示提示并使用默认值，写入失败显示提示且内存筛选可用；不覆盖角色或执行计划。配方展开区只包含“材料采购”标题及物品清单，保留数量、价格、来源、时点及缺价标记；不展示累计数量编辑、目标说明、概率／时间解释、药剂明细、祝福说明、模拟按钮或样本。列表列、全局缺价／超限提示和计算口径不变。
