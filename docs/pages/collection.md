# 收藏性价比页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

## 入口与范围

隐藏页面 `/collection`（含尾斜线）仅通过 URL 进入，不列入菜单，沿用共用语言、页脚、物品价格和历史导航。页面比较亲自产出至收藏里程碑所需的时间、材料成本及利润，不操作游戏或分配精通点。

支持采矿、钓鱼、伐木、偷窃及烹饪、锻造、箭矢、炼药、制作九种技能的普通主产物配方。结果仅生成受支持路线；战斗、农耕、宠物、随机副产物、即时升级和强化录不提供成本计算。合法收藏目录中的这些进度仍可导入保存。同物品的多条来源独立比较，不能相加为全局最优计划。

收藏目录、数量门槛及奖励复用原始提取器。普通门槛为 1/10/100/1千/1万/10万/100万/1千万，本档基础奖励为 1/1/3/10/35/120/420/1500，五品质倍率为 1/3/10/30/100；宠物仅 1 个门槛、固定 1000 点。购买成品不增加数量收藏，即时升级只更新发现标记，retired 配方不作生产路线。

## 进度、配置与导入

首次打开须导入或明确选择“手动场景（从零开始）”，不把尚未导入视为零进度。通过共用角色桥接协议 2 的读取动作导入 collections 和角色配置，不要求 forgeLog。合法稀疏数量的缺项为 0；缺整个 collections、非法数量或必要角色属性错误时原子失败，保留有效状态。

只保存初始化标记、最小角色配置、收藏数量、捕获时间、导入警告及材料／回收价格模式；使用 `dvi-collection-v1` 的首版结构，角色存档不保存完整快照、计划目标、筛选或模拟结果，不提供开发期存档迁移。收藏进度通过角色导入更新；清空配置恢复未初始化，不清除全局价格。非法输入不覆盖有效保存，存储读写错误可见。

角色配置只有一份，按以下主题组织折叠项，共享字段只出现一次：

| 主题 | 配置及作用 |
| --- | --- |
| 技能 | 九种技能等级，显示当前工作速度加成 |
| 工具与装备 | 九种工具、护符与坐骑的品质及强化；工具影响工作，幸运影响采集品质，坐骑影响行程 |
| 药水与祝福 | 采集经验、猎人酿剂、矿脉灵药、疾行药剂及矿脉祝福；制造只使用通用药剂 |
| 家园、精通、天赋 | 相关工作／幸运设施；采集、制造、经验、移动、稀有精通；大口袋、快手、稳手，显示原始说明与当前加成 |
| 公会、世界与热门 | 小数公会经验、世界经验及世界稀有发现；热门可选沿用游戏、按当前时间、不计入 |
| 行程 | 初始仓库、采集铁人模式；显示容量和移动速度 |

经验只影响模拟中的成长，移动只影响行程，口袋只影响容量及回仓；稀有发现只影响采集，普通制造按指定品质产出。两类计算共用经验／移动精通、坐骑、通用药剂和相关加成，采集／制造速度各自作用于对应任务。制造不计采集专用药剂费用。

导入保留有效药剂品质、祝福、小数公会经验及捕获时全部有效世界增益。缺完整世界增益能力标记或数据格式错误时，世界经验与稀有发现清零并显示共用警告；提示针对捕获数据，当前手动配置以表单为准。其余必要字段错误时整体导入失败。

## 执行计划与材料需求

目标行提供“加入计划”按钮，按钮独占结果摘要最左列，位于物品名称左侧，不增加配方展开内容。计划以完整物品ID＋配方ID分组，同组只保留最高目标档，低档显示“已包含在目标…中”且不可重复添加；重复添加幂等。取消最高档移除整个方案，不恢复隐藏低档选择历史；在独立计划面板可明确下调目标或移除方案。每个物品＋品质仅保留一条来源，切换来源替换原方案。

计划面板正常可计算方案也不显示估算状态文字；异常和完成状态保留。计划面板提供方案数、所选目标奖励、期望材料成本、方案状态和材料需求表。选择不受搜索、筛选、分页、排序或语言影响，列表旁始终提供已选数及计划定位入口。材料按完整ID归并，保留不同品质，显示预计需求（期望）、采购单价、期望材料成本和贡献方案。先全精度累计再展示；不逐行取整、不把期望值称为保底备料。复用现有配方、烧焦及采购价格规则，不抵扣库存或其他方案产物，不合并药剂，不推导全计划联合时间、利润或跨路线最优执行。

当前进度9的普通青铜锭，同时加入10/100/1000档只保留1000档：铜、锡各991份，所选目标奖励14点，而不是材料1083份／19点。普通与罕见独立计算，同材料跨方案合并。采集多品质同时产出，但当前采集无材料输入；仅汇总所选目标奖励，不计未选品质或副产物奖励，不将独立采集耗时相加为联合期望。

角色配置或收藏更新后重新评估计划，价格变化仅重估费用。已达目标保留完成状态、剩余需求与奖励为0；等级不足、零概率等方案保留并说明，整体明确“未完整计算”，有效部分材料可查看，不将无效方案当0需求。缺价不影响数量，金额显示 — 并注明已知价格小计；需求累加或金额超限独立提示，不丢弃、不截断。

计划独立保存在 `dvi-collection-plan-v1`：版本1及 `{itemId,jobId,target}` 列表，读取严格校验并规范化同组最高档，坏计划可见且原存储不覆盖，须明确清空后重新选择。“清空计划”只清计划；“清空配置”保留计划，并在按钮说明注明，清空后因角色未初始化将计划标记不可计算。导入角色保留计划及目标，按新进度计算，不保存金额或材料快照。

## 持续自动导入

“导入游戏角色”内提供单条选项“自动导入（聚焦时及每60秒）”，不另列说明段落，自动导入设置错误区仅有内容时显示，不留空占位；默认不勾选，独立保存在 `dvi-collection-auto-import-v1`，不更改既有角色结构。勾选立即导入一次；收藏板块启用期间，每60秒及浏览器窗口获得焦点时导入，后台窗口仍保留定时尝试（受浏览器节流影响，不承诺精确60秒）。切换其他板块暂停，返回收藏板块或刷新后勾选状态有效则立即恢复。关闭选项停止后续自动读取；手动导入始终可用。

复用现有只读桥接和完整导入校验，不请求行情。界面说明自动读取会替换本页收藏及角色配置，保留执行计划。手动／自动共享忙碌状态，任一导入进行中不启动另一请求；相近焦点与定时触发合并。自动导入期间关闭选项、离开板块、重置或修改角色／存在未提交输入时，旧响应不得覆盖新的状态；自动导入会暂缓未提交输入，下一触发重试。失败保留有效配置和计划，显示现有导入错误且保留选项，后续触发仍可重试。定时器与焦点监听仅注册一份，语言重绘不重复启动或清除原有展开状态。

## 目标与时间

每个物品、品质和来源枚举全部未来未完成档，各档都从当前进度独立计算，目标标识包含物品、来源和目标档。完成物品仅在“含已完成”开启时保留一条记录。列表不保存目标选择。

默认估算固定当前属性的纯动作时间，不含移动、取材、回仓和升级。tick 为 0.6 秒，缺口 D、每次产量 y 时，所需成功次数 K=ceil(D/y)。

- 制造烧焦概率 b：预计执行次数 K/(1−b)，耗时为次数乘原始每 tick 工作概率的倒数与 tick 时长；烧焦产物回收另计。
- 采集目标品质概率 q、被捕概率 c：预计执行次数 K/((1−c)q)，耗时为次数×(0.6/p+c×max(stunTicks−1,0)×0.6)。原始引擎在 stunUntil 当刻恢复，不能多算一个停顿 tick。

品质概率、工作速度、烧焦及被捕复用原始机制。动作估算冻结所选时刻的热门；“沿用游戏”使用预测起点，“按当前时间”使用当前时刻，“不计入”抵消热门。世界增益、药剂与祝福假设全程有效。只对已核验固定批量和成功事件使用上述到达期望；概率为零、等级不足、无合法地点有明确状态。

页面提供纯动作估算，不提供逐路线模拟入口。独立目标事件模拟模块保留用于离线计算回归，按原始 produced 事件停止，验证行程、成长、随机品质／烧焦及实际消耗口径；它不在配方展开区展示。

## 成本与利润

新增点数 P=原始累计奖励(有效产出终点)−原始累计奖励(当前)。批量产出越过门槛时计入全部新增奖励，不计其他物品的副奖励点数。只有 P>0 才计算每点指标。

| 金额／指标 | 口径 |
| --- | --- |
| 材料总投入 G | 配方材料数量×采购单价之和，不抵扣库存，不假定材料自采 |
| 产物回收 V | 主产物（采集含各品质）及烧焦产物数量×卖出单价 |
| 药剂投入 B | 启用药剂按耗时÷原始单瓶时长折算持续消耗，允许小数；原始 6000 tick 即一小时 |
| 净投入 L | G+B−V，可为负，用于计算利润 |
| 时间／点、材料金币／点、利润／点 | 耗时/P、G/P、−L/P；正利润盈利，负利润亏损 |

祝福没有对应金币报价，不计购置费用；设备购置、整瓶库存、交易等待／费用均不计。负净投入或正利润不保证实际成交。

材料成本来源可选市场卖单 ask（默认）、市场买单 bid、商人价，产物回收可选 bid（默认）或商人价；两项独立保存。均优先使用全局明确手动价（含零），不隐式借用其他来源。商人材料价仅为估值，不代表可以买到；不可出售材料没有商人估值，不可出售产物回收为 0。材料和产物详情显示来源、时间与缺价，通过共用物品价格入口更新行情，开页不静默请求。

缺材料价使 G 及依赖它的利润不可计算，只缺回收价不影响 G，只缺药剂价不影响材料和时间。金额超过安全范围时，仅该金额与依赖指标显示 —，保留其他有效值；行与汇总明确区分超限和缺价，清单逐项标记缺价，不清空整表、不截断或填零。改价即时重估所有目标，清除失效提示。

## 界面与筛选

左配置右结果，窄屏垂直排列。结果面板标题为“精通性价比”（Mastery efficiency），每批显示 40 条，详情按需生成。正常可计算结果不显示“纯动作估算”等状态文字；已完成、等级不足及其他异常状态仍显示。结果列依次为：

1. 计划操作：加入计划、移出计划或已包含目标。
2. 名称 · 品质（中点两侧各一个空格，同字号和字重），技能来源另行显示。
3. 当前 → 目标。
4. 新增精通点。
5. 总材料成本，即 G，缺价／超限显示 —，合法零成本显示 0。
6. 秒／点。
7. 材料金币／点。
8. 利润／点。

物品名称统一按基础物品 ID 复用共用翻译，覆盖列表、装备／药剂选项与材料／产物详情；不直接翻译带品质前缀的英文名称。搜索同时匹配原始英文名和基础物品中文名，任意品质均支持中文查询。

筛选与键盘顺序一致，桌面分两行，窄屏各行内自动换行，无横向溢出：

| 行 | 顺序与默认值 |
| --- | --- |
| 第一行 | 类型（制造）、技能（全部，仅九种支持技能）、品质（全部）、搜索（空）、材料成本价格（ask）、产物回收（bid） |
| 第二行 | 排序（材料成本升序）、新增精通点最小值／最大值（空）、仅显示等级达标（勾选）、含已完成（不勾选） |

类型可选全部／采集／制造；各筛选取交集。“仅显示等级达标”只比较当前技能等级和配方要求，不依据概率、地点或报价筛选，与“含已完成”独立。

点数上下界为非负安全整数闭区间，空为不限、0 有效、相同端点可精确匹配；负数、小数、非数或最小值大于最大值时提示并隐藏结果，修正后恢复。排序选项为时间升序、材料成本升序、利润降序，均按每点新增精通计算，缺失金额及不可计算项置后。汇总显示支持路线的未完成／匹配目标数、材料／药剂缺价及金额超限数。

筛选、排序和展开状态随本次语言及页面切换保留，刷新恢复默认；价格模式和角色进度独立保存。配方展开区只包含“材料采购”和“产物回收”两个标题及物品清单，保留数量、价格、来源、时点及缺价标记；不展示累计数量编辑、目标说明、概率／时间解释、药剂明细、祝福说明、模拟按钮或样本。列表列、全局缺价／超限提示和计算口径不变。

## 验收与限制

计划验收覆盖最高档去重／幂等、下调／取消、品质独立、跨方案同材料合并、烧焦小数、进度更新与完成、筛选隐藏保留选择、无效方案／缺价／溢出、存储错误和双语窄屏；自动导入覆盖默认关闭、勾选／刷新恢复、60秒／焦点触发、切页暂停、重绘不重复注册、并发合并、晚到响应隔离、输入保护、失败保留和持续重试。

验证范围包括原始奖励差与全部未来档、品质、批量跨档、烧焦／被捕、等级／地点／零概率、独立价格来源、缺价／零价／溢出、利润方向；单份配置与加成导入、失败原子性、保存错误；URL／历史导航、双语桌面／390px、中文名称搜索、列序及默认筛选；展开区仅两部分且无编辑／模拟操作；离线显式目标与独立原始事件对照、上限未完成状态。

仅执行本次影响范围验证，发布前按[发布流程](../release.md)完整验收。受控桥接和报价不代表真实账号、脚本管理器或实际成交验证；模拟从导入等级的最低经验开始，不保留等级内进度。长期性能、所有配置的到达时间分布及多路线最优求解未验证。
