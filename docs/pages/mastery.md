# 精通页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

独立页面 `/mastery`，导航位于强化与预报之间，中英文、键盘、窄屏及路由遵循[共用页面规则](../shared.md)。

### 页面与配置

卡片调整已随 1.7.0-preview.2 部署到 Preview，发布与验证见[卡片调整报告](../../reports/mastery-cards-preview-2026-10-23.md)。

角色导入区域提供默认关闭的“自动更新角色配置”，使用[共用角色自动更新](../shared.md#导入游戏角色与自动更新)；更新范围沿用本页手动角色导入，不新增库存自动更新。

- 桌面采用左侧角色配置 panel、右侧精通分配与结果；窄屏按左侧配置、右侧结果顺序垂直排列。左侧顶部为与其他页面共用的金色高亮“导入游戏角色”折叠面板，提供安装／更新 userscript 和导入配置按钮；其下按模式、总点数顺序排列，两项在两种模式下始终显示；可用点数为计算结果，不提供输入框；采用共用 number-field 标签／输入样式；另提供“所有等级归零”“撤回本次分配”和保存提示，清空配置位于左侧标题旁。

  “所有等级归零”将全部当前与目标等级设为 0，保留模式和总点数，重新计算可用点数并自动保存；不同于恢复默认的清空配置。导入及其它折叠状态在重绘／语言切换后保留，刷新时导入默认展开，其它默认折叠。
- 展示全部 10 项原始精通，依次为经验获取、采集速度、制作速度、离线时长、移动速度、生命上限、最大伤害、命中、寻宝、强化成功率。电脑与手机共用卡片呈现，不使用宽表格或页面横向滚动：桌面右侧按容器宽度排列：不足 580px 时单列，580px 起两列，880px 起三列，1180px 起四列；页面最大宽度放宽至 1800px，以容纳四列紧凑卡片。手机（视口不超过 740px）始终单列。全部精通按原顺序直接显示，不增加折叠或弹窗。每张卡片以只读文本显示当前整数等级，提供可编辑的目标整数等级，并展示目标加成、本次成本与下一级成本；目标初始等于当前，不再显示当前加成。目标加成位于当前等级右侧，操作区左下角显示“下一级：x 点”，右下角显示预算不足提示“还缺 x 点”。

  当前等级不提供手动输入，仅随导入、清空／归零及重置方案应用更新；主动填写低于当前的目标则明确提示，不截断。
- 卡片标题为精通名称，说明采用次要文字；右上角为本次成本。当前或目标等级任一非零时标题金色高亮；目标不等于当前时边框与成本文字金色高亮，并在当前等级数值右侧显示“+N 级”或“−N 级”，相等时不显示差值。目标低于当前的无效草稿同样显示减少级数和边框高亮，但仍提示无效且不保存，不改变既有等级校验。预算不足或满级原因在对应卡片显示。目标输入框占剩余宽度，按钮至少 44px 高。卡片使用紧凑布局：内边距 12px、卡片间距 10px、主要内容区间距 8px，标题 14px、说明 11px；当前等级标签、只读数值与增减级数同行，以减少卡片高度，提高单屏展示数量，保留所有字段与提示，长文字自然换行。顶部汇总始终三列紧凑排列，标签自然换行。
- 支持“限定精通点”和“不限制精通点”两模式，默认限定、总点数 0、当前与目标全 0。可用点数自动计算为总点数减去当前已分配等级的原始累计成本，作为本次预算；修改总点数或导入更新当前等级即重新计算。目标等级只影响本次投入及剩余点数，不改变当前可用点数。两模式切换保留等级与总点数。
- 限定模式显示预算、本次投入及剩余点数；每张卡片目标控件从左到右排列为等级输入框、+1、−1、MAX；MAX 表示升到可负担最高等级，同一行展示，下方显示下一级成本及上限提示。最高等级按其他项目占用后的预算计算。目标不低于当前，撤回模拟投入可退还本次预算；已有精通不可退还。预算不足或已满级禁用升级按钮。
- 直接填写目标、降低总点数造成超支时保留方案，明确显示缺口；总点数不足以覆盖当前已分配成本时，两种模式均提示当前已分配等级超出总点数，并显示缺口；限定模式禁用追加升级；不截断、不重新分配其他项目。不限制模式保留全部左侧配置项，但不按预算限制升级，显示本次所需点数、当前已投入与目标从零总投入。
- 独立 localStorage 保存模式、总点数、当前与目标；预算为计算结果，不作为独立配置保存；有效编辑自动保存，非法输入保留并明确提示，不覆盖最后有效保存；异常存档提示并恢复默认。切换页面及语言保留未完成输入。存储失败提示但计算可用。撤回本次分配仅将目标恢复当前；所有等级归零将当前与目标全部设为 0，保留模式和总点数；清空恢复默认。
- 支持手动试配和角色精通配置导入。导入复用普通角色桥接 2.4 及现有安装入口、读取中／连接／失败／捕获时间双语提示。导入读取 10 项已分配精通等级（缺省项视为 0），通过原始总点数函数从角色 collections 与 forgeLog 计算总精通点数，再减去已分配精通的原始累计成本得到可用点数。锻造录仅 +1–+15 奖励点数，+16–+30 的记录仍接受但不计点，锻造录点数总上限 15,662。两类来源必须存在且格式有效；不猜测缺失来源为零。精通对象缺失、已知项不是范围内整数、协议／捕获时间不合法时整体失败并保留已有配置。

  导入成功替换总点数与当前等级，目标重置为当前，并将模拟模式重置为限定精通点；可用点数统一根据总点数和当前等级重新计算。总点数在左侧可编辑并保存，默认 0；无效输入明确提示且不保存。旧存档总点数缺失或为 null 时，先用当前精通成本加旧可用点数恢复总点数；已有总点数时忽略旧预算，以总点数和当前等级重新计算。不改变已有模式、当前与目标等级。手动修改等级不自动改变总点数；手动总点数不足时保留方案并提示，而导入总点数小于已分配成本或来源／结果无效时整体失败并保留已有方案。自动保存；保存失败单独提示且内存计算可用。

  不持久化完整角色、库存或捕获时间。
- 中英文均不显示左侧可用点数计算说明和右侧当前等级／撤回／离线时长说明段落；计算及精通加成单位保持既定规则。
- 不包含洗点费用、点数获取时间或应用到其他页面，不改变战斗、采集、强化配置或触发其重新模拟。重置分配计算见下节。

### 计算最优分配方案

计算功能自 1.7.0-preview.1 起部署到 Preview，生产尚未包含；发布状态与证据见[当前状态](../status.md)及[精通分配 Preview 报告](../../reports/mastery-allocation-preview-2026-10-23.md)。

#### 入口与配置

- 面板位于右侧标题下方、点数汇总与手动卡片上方，使用原生 details／summary，初次进入和刷新默认折叠。重绘、语言切换、计算进度／完成及应用保留折叠状态；折叠不取消计算，完成不展开，不新增折叠存档。
- 顶部金色加粗提示为“计算结果仅针对所选目标，应用于其他目标时效果可能更差。结果仅供参考，请自行评估分配方案。”，英文同步。保留配装、时长、冻结价格／增益及收入口径说明，不展示每配置模拟次数或预计等待时长说明。
- “计算模式”默认“保留当前加点，分配剩余点数”，另有“重置全部精通”；选择在页面会话中保留，刷新恢复默认。优化目标预留战斗收入、采集收入、经验获取和强化成本，当前仅战斗收入可选，其他禁用并标注暂未支持。
- 怪物按等级降序排列，同级保持原顺序；默认深渊恐魔，重绘／语言切换保留选择。角色摘要分三行：流派／等级／防御／生命／模拟时间，总精通点／当前投入／本模式可分配点数，按原顺序的装备品质／名称／强化。配装警告另起一行，所有数值动态读取。

#### 预算与计算

- 启动时冻结精通页总点数与全部当前等级、战斗页内存配置、所选怪物、时长、增益、价格和时刻。手动目标草稿不参与输入，非法目标不阻止独立计算；不读取实际库存或未来角色成长，不计算洗点费用、点数获取时间和世界首领。
- 保留模式以全部十项当前等级为下限，扣除全部累计投入后分配剩余点数；只追加经验、移动、生命、最大伤害、命中、寻宝，其他四项固定保留。只能回收候选中新追加的点数，不能降低已有等级。零余点、不足升级或满级时可保留当前方案；当前投入超过总点数时明确拒绝。
- 重置模式按总点数从零分配，六项之外为零。原配置超预算时仍可计算，但只作为参考，不展示同预算增收。等级范围、原始累计成本及强化封顶沿用下节，不将其他精通截断在 200 级。
- 目标为完整时长内的金币＋普通／稀有掉落估值，未扣食物药剂成本；宠物按现有规则估值为 0。开始前检查怪物各品质掉落、额外掉落、碎片和非铁人坐骑的全部可能产出价格；零价有效，缺价列明物品并停止，不用商人回退值冒充已定价。
- 多起点、递减步长、跨项回收的六维有限搜索，标准／深入最多筛查 240／720 个不同配置，每配置两个固定种子；小预算可在限额内完整枚举。缓存同配置与种子，前五候选用另外五个固定种子独立复核，输出前三名；完整模拟所选时长，不用短窗口外推。
- 原配置用匹配复核种子比较收入差异；差异不超过两倍配对标准误时提示接近波动，不展开独立统计数值。保留模式保留筛查及复核安全的“不追加”候选，防止筛查前五挤掉表现更好的原配置。死亡／提前停止候选均排除，异常或无可用候选明确报错。

#### 结果与应用

- 每张卡片仅展示名称／最佳标记、收入、投入、相对计算前原配置的收入差异及标题右侧“应用”按钮；保留模式投入栏补充新增投入。无法比较时说明原配置超预算或模拟未完成，不重复展示十项等级、加成、余点或 JSON 复制入口。
- 完成后自动应用一次最佳，也可应用备选。保留模式只将推荐写入十项目标等级；重置模式先把当前等级归零，再写推荐目标。保留左侧手动预算模式和总点数，校验目标不低于当前、等级合法及总投入不超预算后原子更新并保存。校验失败不修改配置；保存失败保留内存应用和结果并提示。只修改本精通页，不写入战斗等其他页面。
- 应用不使候选清单失效，差异仍以计算开始前原配置为基准。与下方配置一致时按钮显示“已应用”并禁用；编辑目标后可重新应用，不重算或再次自动应用。价格、语言与重绘不重复应用，取消／失败／迟到任务均不得应用。

#### 运行状态

- 开始／取消复用一个 secondary 按钮，与角色配置按钮配色／字体一致，宽度随文字、不占整行，至少 44px 高。空闲显示“开始计算”，运行中显示“取消计算”且可点击；英文为 Start calculation／Cancel calculation。完成、失败、取消或输入失效后恢复开始。
- 专用 Worker 显示搜索／独立复核阶段及候选／实际模拟次数。取消立即终止 Worker，不保留半成品；任务代际和实例隔离迟到消息。修改计算模式、总点数、当前等级、目标类型、怪物、搜索强度或战斗配置会取消并清除结果；手动目标、左侧预算模式和语言不影响冻结输入。导入更新当前等级时取消运行并清除旧结果，重绘期间不得因控件尚未装配而抛错。离开精通页取消运行，完成结果仅在本次会话保留。
- 有效价格变化只提示本次计算及已有结果仍使用开始时价格，不终止、不移除或重新估值；提示跨进度、完成、语言与重绘保留，重算时清除并读取最新价格。结果是有限搜索参考，不保证全局最优。

### 计算规则与实现

- 调用当前已核验快照的原始逐级成本、累计成本与精通总投入函数，通过提取器增加语义导出，禁止手工修改生成模块。
- 每项等级 0–20,000。升到第 n 级成本为 38 + 2n，0 到 r 累计成本等价于 r² + 39r；本次成本为目标与当前累计成本之差，跨项相加。最高可负担等级在原始累计成本函数上二分查找，不逐点枚举配置。
- 加成复用原始定义与现有换算：命中每级 +1 个百分点，其他一般百分比每级 +0.5 个百分点；强化每级 +0.25 个百分点，只有强化实际加成最多 +50%，超过 200 级保留等级与原始成本但不增加强化效果。其他精通不按 200 级封顶；离线时长基于 24 小时，每级额外 +0.12 小时，显示额外时长并保留精度。
- 等级与总点数输入仅接受范围内非负安全整数；自动计算的可用点数可为负数，用于表示当前已分配成本超过总点数；空值、非数、负数、小数及越界明确报错，无效输入不显示旧计算为新结果。手动预算与升级成本为确定值，不涉及随机模拟或 Worker；最优分配搜索另按上节使用战斗模拟和专用 Worker。
