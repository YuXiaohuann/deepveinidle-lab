# 制造页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

本页描述当前制造功能；发布与本地变更状态见 [当前状态](../status.md)。中文导航“制造”、英文“Crafting”，网址 `/craft`（含尾斜线）。沿用[共用页面规则](../shared.md)的语言、导航、页脚、状态保留及窄屏规则。桌面左侧角色配置、右侧属性和结果，配色、面板、输入框、图标按钮、表格、排序与展开明细均与采集一致。

**模拟与期望统计**

制造次数、经验、耗时、回仓、成功／烧焦诊断次数与实际材料消耗保留原始模拟；指定品质主产物直接计算，烹饪按每次执行前烧焦概率累计正常／烧焦产物期望，宠物与坐骑按实际成功分支机会累计期望。活动礼盒保留原始模拟，未完成计划不外推为完成；期望产物估值减实际消耗成本得到利润。材料需求、购买预算及即时升级仍是确定性直接计算。配方表下提供双语说明，金色加粗原始模拟／数学期望，并明确礼盒例外、材料预算和即时升级。

期望输出支持有限非负小数及安全上限校验，计划／库存／材料仍要求安全整数；汇总与输出数量明细兼容小数；制造期望产物展开明细限定在汇总卡片内，名称自然换行、数量保留可读宽度，避免与相邻卡片重叠。验收覆盖烧焦概率采样、成功后奖励、原始过程一致性、未完成状态、小数估值／汇总／精度及双语说明。验证记录见[混合计算实施报告](../../reports/work-expectation-implementation-2026-10-13.md)；计算依据见[混合计算调研](../../reports/work-expectation-research-2026-10-13.md)。

**范围与配置**

- 五技能为烹饪 cooking、锻造 smithing、制箭 fletching、草药学 herblore、制作 crafting；当前有效配方（含即时升级）分别为 8、66、38、8、69 个，共 189 个；其中普通制造 172 个、即时升级 17 个。配方、分类、材料、等级、产量及经验来自原始定义；不含农耕、跨配方队列、自动抵扣上游产物或多随机种子期望。
- 默认烹饪、各技能等级 1、无工具／增益、次数为 0、已有材料为 0、初始仓库自动、热门沿用游戏。配置顺序为导入、技能按钮、技能、工具与装备、药水、家园、精通、天赋、其它、模拟配置；只展示实际有效配置。工具为各技能对应工具及坐骑；随机品质幸运不改变制造的指定品质，不显示护符或猎手药剂。药水为矿脉灵药和疾行；家园为当前技能制造速度设施；精通为制造、经验、移动，天赋为口袋、快手及烹饪稳手。稳手说明采用当前游戏的相对概率口径，见采集章节。其它提供公会经验、世界增益经验、祝福；模拟配置依次提供初始仓库、利润周期与热门策略。

  利润周期默认每天，清空恢复每天；已保存的有效每小时／每天选择保留，缺失或无效值使用每天。
- 属性卡依次为技能等级、制造速度加成、经验加成（不含品质与动态热门）、移动速度、背包容量，复用原始加成函数，不把速度加成当作产量增幅。
- 制造独立保存角色配置、按配方（含升级命名空间）＋品质记录的次数、按完整物品 ID 记录的已有数量；切换技能／语言／页面保留输入及有效结果。角色导入沿用现有协议，按钮发送 `read` 动作（与其它页面一致，脚本只接受 `probe`／`read`），验收覆盖制造按钮经真实 DOM 桥接读取角色配置；仅更新可映射角色字段、恢复模拟配置默认值，保留计划和已有数量；异常字段明确提示、整体失败不改配置。各导入区域首次展开，其余配置首次折叠。

**配方表与计划数量**

- 每个当前技能配方的五种品质各占一行，无品质选择器；搜索框同行提供普通、罕见、稀有、史诗、传说五个平铺品质多选按钮，按钮紧贴排列、间隔为 0，默认仅普通选中，允许全部取消（显示空结果）。选中态及 `aria-pressed` 明确，每次点击仅切换该品质；窄屏自然换行。品质筛选与搜索／分类／只看已填写取交集，只影响表格显示，不影响全计划材料汇总、库存、计划和模拟缓存；语言／技能／页面切换保留本次筛选，刷新恢复仅普通。默认等级降序、同配方品质升序，保持原有按配方＋品质保存的计划。
- 配方表下方展示上述双语混合计算口径说明，完整计算规则在本文件维护，README 仅提供入口。
- 列顺序：配方、所需等级、品质、单次材料成本、单次产物价值、制造次数/天、经验/天、利润/天、计划制造次数；每小时模式后三项单位改为 /小时。材料和产物数量展示在成本／价值明细中。单次产物为配方名义产量，烧焦和额外奖励按混合计算规则计入时间窗口利润。成本／价值展开复用采集页紧凑明细：名称与品质、数量两端排列，宽度随内容，不设置制造价格行的 230px 最小宽度；配方成本／价值展开仅展示数量与单价，不提供价格填写框；改价通过材料需求表或全局物品价格面板，继续同步全局自动锁定。
- 普通制造速率采用各组合从相同角色配置独立模拟 24 小时的混合统计，次数和经验来自实际过程，利润结合产物期望与实际材料消耗，包含升级、烧焦、移动与回仓；每小时为窗口结果除以 24，每天为窗口总量。小时／每天切换只改变后三项速率的显示和标题，不重跑；计划次数为 0 仍计算速率，等级不足明确提示。即时升级计划直接核验计算，不依赖 Worker、速率缓存或随机种子；升级行的小时指标不与普通制造速率混合排序，单次成本与价值仍可排序。普通制造计划模拟与速率缓存独立，修改计划不使速率失效；切换技能按需计算本技能，已填写跨技能计划继续模拟。
- 计算状态在配方标题旁固定尺寸位置展示，空闲时保留布局但隐藏文字，长进度单行截断并提供完整提示；开始／完成计算不得在表格上方增删提示行，填写次数与异步重绘保持表格位置、滚动及输入焦点。
- 计划制造次数为非负安全整数，含烧焦次数；最后一列填写，默认 0、清空为 0、非法值不写入。等级不足仍可填写并汇总材料。材料表和计划汇总仍以计划次数而非速率计算。
- 工具栏顺序：分类、搜索、品质多选、只看已填写按钮、清空计划。小时／每天单位位于左侧模拟配置；切换只重绘速率列，不影响计划、筛选及缓存。只看已填写为可切换按钮，使用 `aria-pressed` 与选中样式；窄屏自然换行。不提供批量设置制造次数入口；配方工具栏与材料需求标题旁均提供“清空计划”（Clear plan），两个入口执行相同操作：清空全部技能、全部品质的计划制造次数、全部材料已有数量及旧计划迁移提示，保留左侧角色配置、搜索、分类、品质筛选与排序。旧保存配置保留全部品质计划。

**装备升级**

- 不新增独立升级表。现有配方表排除 retired 的十项持续制造配方，加入原始十项替代与七项新增，共 17 种升级配方，分类为“升级 / Upgrades”，沿用技能、搜索、品质筛选、排序和计划数量。升级与普通配方原始数字编号有重叠，保存键使用 `upgrade-编号:品质` 区分。
- 升级仅按无强化底装（+0）估算，不提供底装强化输入；底装、产物和额外材料按原始函数映射完整品质编号。升级配方名称及展开详情不追加“即时升级 · 底装 +0”说明；制造次数/小时或天栏显示“即时升级”，经验／利润显示数值与“/次”单位，明确不属于对应小时／天速率。原游戏仍可保留强化，本页不模拟此类升级。
- 1.0.1190 巨像六件升级（271–276）仅消耗同品质 +0 陨铁底装与巨像碎片，不再消耗陨铁锭；其余升级材料、等级、固定经验与产物保持原始定义。已存计划次数、品质和已有材料数量原样保留，当前需求按新配方重算，无需求的库存继续隐藏保存。独立验收：两次传说巨像之剑需两把 4114 与四份 4252，不需 4044，经验为 3800；覆盖六件五品质和预算／库存兼容。
- 共用材料需求和汇总纳入 +0 底装及额外材料，已有数量仅扣购买预算，底装仍计入消耗价值。复用原始升级函数核验单次转换后，按计划次数累计固定经验和确定性产物，耗时 0；不套用制造速度、热门或经验倍率。等级不足仍计入计划需求，但不视为已完成。
- 旧十项制造计划按目标物品迁移为对应升级保存键，保留品质和次数，已有同键次数安全合并；显示“旧巨像／幼龙计划已按 +0 底装迁移，请核对材料需求”，用户确认后消除提示，右侧“清空计划”也清除。角色导入保留全部计划与已有数量。各行独立，不自动抵扣其他计划产物。
- 固定品质行独立供给，不新增混合库存“优先好材料”模式。验收覆盖 17 种升级、五品质、固定经验／零耗时、底装完整编号估值、材料合并、旧计划迁移与幂等／合并安全、等级不足、双语和窄屏，并核验普通制造与新版 offline 对照。

**原始制造与统计**

- 合成模拟角色不参与每日／每周任务；1.0.1190 自动领奖不计入经验、金币或利润。每次原始 tick 前按原始日／周函数同步空任务的周期编号，避免重置时生成账号任务；不改原始引擎。验收覆盖自动领奖机会与跨日／跨周边界，独立原始离线对照以相同空任务条件分段执行。

- 普通制造复用原始品质材料映射、工作完成概率、经验、烧焦、路线与回仓逻辑；原始 route.limit 按执行次数减少，成功和烧焦各减一次。每行从相同初始角色独立开始，以对应等级最低经验为起点，正常升级，不连续执行多行。初始背包为空、材料按计划供给、仓库容量无限、药水和祝福全程有效。
- 原始输入映射会让部分材料跟随品质，部分保持基础品质，不统一转换所有材料。产物使用指定制造品质，非随机采集品质。经验按成功制造事件逐次取整；品质经验倍率为原始 1 / 1.5 / 3 / 8 / 25；烹饪先消耗材料，烧焦没有本次制造经验，保留烧焦产物。热门按所选技能和实际模拟时刻作用。
- 完成次数达到计划后停止计时，不追加最后存仓时间；计时包含初始移动、取材料、工作与中途回仓。默认自动仓库从仓库 1 初始化后，按原始客户端距离选择最近合法制造点；手动仓库从该仓库初始化。首版不增加地点选择器或全点平均。
- 制造每轮生成一个 32 位无符号随机种子，同轮全部配方、品质、24 小时速率及计划模拟共用，通过原始 context 传入；热门默认仍为“沿用游戏设置”。工具栏提供紧凑的“重新模拟”按钮，取消旧任务并清空速率／计划缓存，更新本轮时间与种子后重新计算当前技能及已填写跨技能计划；配方展开明细显示本轮种子。角色计算配置变化与刷新开启新轮；技能切换、筛选、搜索、排序、语言、周期、价格与已有数量变化不重新抽样，计划次数调整沿用本轮种子及速率缓存。程序接口默认 seed 0，可显式传入复现；随机源失败明确提示，不回退。
- 大数量安全边界：单行最多计算 30 个游戏日，Worker 提供进度并可由配置变化中止；达到边界时保留实际完成次数、经验、已执行机会的产物期望、实际消耗、耗时及明确的未完成提示。显示全额计划材料成本，实际消耗仅用于利润计算、不单列汇总卡片；不把部分结果当作完成。材料按计划需求一次供给；超过时长边界可完成上限的计划，仅供给至每刻最多完成一次的理论上限，保持原始取材批量和回仓行为，不人为增加取材次数。数量／金额溢出明确报错。
- 材料总成本 = Σ计划需求×单价；利润 = 产物期望价值−实际消耗成本（活动礼盒数量保留模拟）。完整结果两者一致；药水成本、市场手续费及最终售卖耗时不计入，不套用强化 1.03 系数。非主要物品奖励单列在产物明细，不漏计或重复计价。

**材料表、价格与汇总**

- 配方表下提供材料需求表，按全部技能已填写计划汇总，各配方搜索与筛选不改变汇总范围。按完整 ID 合并，同名不同品质分行。列为材料、总需求数量、已有数量、仍需购买数量、材料单价、购买所需金币。
- 总需求 = Σ制造次数×原始单次材料数量；仍需购买 = max(总需求−已有, 0)；购买所需金币 = 仍需购买×单价。已有数量为非负安全整数，默认 0，输入／保存规则与次数一致，不自动从角色导入覆盖；暂时无需求时隐藏但保存，恢复需求时恢复。右侧“清空计划”同时清除计划次数与已有数量；左侧“清空配置”仅恢复左侧全部技能配置及模拟配置默认值，保留计划、已有数量、旧计划迁移提示及右侧搜索／分类／品质筛选／只看已填写／排序。若恢复默认技能后原分类不属于该技能，仍显示并保留该分类选择，结果按筛选交集展示。两种清空均保留全局价格。
- 材料与产物单价复用[全局物品价格](../shared.md#24-全局物品价格)全局价格，表内合法改价（含 0／清空）同步全局并自动锁定，同一 ID 共用单价；缺价采用商人价兜底并显示 ⚠，材料兜底只是估值，不承诺可以买到。购买金币仅正购买数量缺价时提示；清空与未设置不混同有效零价。价格更新仅重估金额和排序，失败明确报告。
- 材料表底部只汇总购买所需金币，不把不同物品数量相加。其后计划汇总按技能列经验、显示计划材料成本、产物期望价值（支持展开数量明细）与利润；等级不足／失败／未完成时明确结果覆盖，完整总利润不发布。耗时仅独立估算合计，不代表跨配方顺序执行。已有材料不按零成本计利润，购买预算与材料消耗价值分开。

**验收与状态**

验收覆盖左右清空范围隔离、两个“清空计划”入口一致、跨技能／品质及隐藏库存清除、迁移提示保留／清除、双语按钮与刷新保存；五技能配方／品质映射、单材料／多材料／多产量、单次取整／增益／升级／烧焦、原始限次停止与回仓、热点边界、零值／非法／等级不足／提前停止／溢出；与独立原始 offline 结果对照；工具栏排序／品质和已填写按钮交集／清空全部；跨技能材料合并／品质隔离／已有充足和超额／隐藏恢复；全局价格锁定／零价／兜底／改价不重跑；导入失败原子性、保存错误、双语窄屏、键盘、焦点、导航／刷新及旧 Worker 隔离。

仅运行相关测试与验证，发布前才执行全量。随机种子验收覆盖同轮速率与计划一致、不同配方及品质共用、原始引擎指定种子对照、同种子复现及不同种子样本差异、计划调整保留速率缓存、重新模拟与计算配置变化使旧缓存失效、旧消息隔离及随机源失败。
