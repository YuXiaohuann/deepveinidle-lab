# 采集页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

原始数据初步核对基于 [原始代码复用](../technical.md#62-原始代码复用) 保存的快照；已静态核对原始工作路线、工作完成概率、品质与被抓分支；数值与浏览器验证状态见[当前状态与验证](../status.md)。用户说明游戏内随机选择采集点；当前保存的公开客户端采集菜单 nearestSiteFor 实际按角色当前位置距离选点，服务端随机机制未核验。产品仍按已确认要求默认采用全部任务对应采集点的等权平均，默认不选择最近点或利润最高点，另可主动选择最近采集点。等权为本页明确的统计口径，不声称复现账号单次地点选择。

**模拟与期望统计**

采集次数、移动占比、经验、回仓及偷窃被抓／停顿保留原始模拟；金币按实际成功次数与固定产量计算，主要产物品质和普通额外奖励按本次模拟有效机会累计数学期望。原始库存、品质抽样及升级继续执行，不写入小数期望状态。bonus 保留原始触发率、品质及背包门槛，坐骑使用成功分支加经验后的完成概率，铁人禁用，宠物不估值；活动礼盒保留原始模拟并在说明中明确例外。各点独立累计后等权平均，仍非跨全部随机路径的总体期望。表下注释显示模拟条件与双语计算口径，使用战斗同款金色加粗“原始模拟”“数学期望”；掉落明细复用战斗自适应数量精度。

验收覆盖公式、容量限制、奖励机会、状态与原始引擎对照、全点平均及双语说明。验证记录见[混合计算实施报告](../../reports/work-expectation-implementation-2026-10-13.md)。依据见[混合计算调研](../../reports/work-expectation-research-2026-10-13.md)。

**范围与页面**

- 提供同级“采集 / Gather”导航与 `/gather` 页面，导航顺序见 [导航与网址](../shared.md#21-导航与网址)。沿用共用语言、网址、状态保留、页脚与响应式规则；左侧配置，右侧依次为当前技能属性概览和任务利润列表。
- 技能选择按钮采用与战斗页一致的图标加文字形式：采矿为镐、钓鱼为鱼、伐木为斧、偷窃为钱袋；使用随代码提供的同色线条 SVG，图标为装饰且不重复读屏名称，中英文保留完整技能文字与选中状态。
- 当前包含采矿、钓鱼、伐木、偷窃；当前快照分别为 8、8、6、8 个任务，合计 30 个，由原始定义生成。默认仅模拟当前技能，可选择该技能全部任务或一个任务。农耕、制作、任务队列、并行工作、自动切换高级任务、市场净利润和多随机种子统计不在当前采集范围。
- 每个任务与每个采集点使用相同初始配置的独立角色副本和相同模拟时间窗口；模拟期间正常获得经验和升级，持续执行所选任务，不把各点结果相加当作一个角色的产出。
- 首次与清空默认为采矿、技能等级 1、无工具或额外增益、自动仓库、所有采集点平均、24 小时、沿用游戏热门设置。保存各技能配置；页面、语言、排序、搜索和利润单位变化只重绘，技能切换保留已填配置并启动新一轮模拟。

**角色与模拟配置**

- 菜单顺序为技能、工具与装备、药水、家园、精通、天赋、其它、模拟配置。仅展示对采集有效的选项，所有名称复用原始翻译并覆盖中英文。
- 技能只编辑等级，以对应等级最低经验开始；工具为当前技能对应的镐、鱼竿、斧或手套，同时提供护符和坐骑，各自设置品种、五种品质与强化，资格及实际加成调用原始函数。顶部以与战斗属性相同的独立卡片依次展示等级、采集速度加成、幸运加成、移动速度和背包容量，复用卡片背景、边框、间距和标签／数值上下布局；五张卡片单行排列，窄屏在属性行内横向滚动；任务详情展示起始完成概率或理论平均工作耗时，明确不含移动、回仓或被抓停顿。
- 顶部不单独展示工具速度加成，工具加成仍纳入综合采集速度并保留在工具配置说明中。幸运加成展示原始品质判定的角色综合增幅，公式为 `(1 + 工具品质幸运 + 护符幸运) × (1 + 猎手药剂加成 + 祝福品质加成 + 幸运神龛加成 + 寻宝精通加成) − 1`，以百分比显示两位小数；基础幸运、药水／祝福、家园与精通均复用原始函数和合并规则。空工具／护符按 0，工具强化不增加品质幸运，护符品质与强化沿用原始装备计算。热门品质窗口随实际模拟时段变化，逐刻加入品质判定，不并入这项固定角色面板；综合幸运是各品质基础判定阈值的增幅，不等于某种品质的绝对掉落概率。
- 工具速度加成为当前工具品种、品质与强化的有效加成；采集速度加成为原始 `workModifiers.combined - 1`，公式为 `(1 + 工具加成) × (1 + 家园速度加成 + 快手加成) × (1 + 采集精通加成) − 1`。两项不能再次相加。技能等级的工作效率另行进入完成概率，完成概率上限为 100%；移动、回仓和被抓停顿不计入速度面板，不把综合加成标为每小时产量增幅。
- 药水提供采集者药剂、猎手药剂、矿脉灵药、疾行药剂；家园提供当前技能速度设施与幸运神龛；每项下方采用战斗页的加成说明形式，显示加成类型、每级加成与当前等级加成，百分比由原始 `houseBonus` 计算；有效等级输入后立即更新，中英文同步，不再每项重复配置条件说明；精通提供采集速度、经验获取、移动速度、寻宝并按实际有效加成编辑；天赋提供口袋、快手，偷窃另提供稳手。稳手说明须明确每级按原概率降低 3%，如 20% 变为 19.4%，不是降低 3 个百分点。具体适用性、品质及强化效果必须按原始实现核验，不另写经验公式。
- 其它提供公会经验、世界增益经验、世界增益稀有发现、矿脉祝福、初始仓库、丢弃采集物与铁人模式。手动启用的药水与祝福全程有效；家园表示已生效设施，初始背包为空，仓库容量无限，不模拟建设和升级。储藏室在无限仓库场景无效，不展示；当前不提供食物配置，偷窃被抓造成停顿的行为以原始工作分支核验为准。
- 模拟配置提供任务、采集点、1 小时／24 小时／自定义时长与沿用游戏设置／按照当前时间／不计入热门加成。时间按小时输入，支持小数，最短 1 分钟（1/60 小时），按整数分钟规范化，默认 24 小时；左侧模拟配置在时长后提供利润周期，默认每天、刷新和清空恢复每天，不足 24 小时回退每小时；始终提供总量和每小时，仅模拟时长达到 24 小时时提供每天；每小时 = 窗口累计值 ÷所选小时数，每天 = 每小时 ×24，总量 = 窗口累计值，表格工具栏不再提供周期控件，切换只重绘。热门按采集技能映射。
- 世界增益参照战斗页：经验使用 `weeklyXp`，稀有发现使用 `worldRarity`，默认0%，支持小数，增减步进0.1%，手动输入及导入的小数不限制到一位，范围0–10000000%。旧配置缺稀有度时为0，已有小数经验保存往返不截断。两项位于“其它”的公会经验之后、祝福之前，名称为“世界增益经验 (%)”“世界增益稀有发现 (%)”（World buff XP (%), World buff rare finds (%)）；各自下方显示“导入捕获时生效的世界增益，整个模拟周期保持生效。”及对应英文。替换原经验输入下方的内置预测说明。
- 角色导入复用战斗页全部世界窗口校验和汇总：`worldBuffsVersion: 1` 必须存在；按捕获时 `fromTick <= worldTick <= toTick` 汇总全部有效窗口，不按名称筛选或去重，省略倍率按1，经验与稀有度分别累加 `(mult - 1) ×100`。起止为非负安全整数、结束不早于开始，倍率为1–100001的有限数，汇总不得超过输入范围。有效空列表两项清零；异常数据两项清零并明确说明；旧捕获缺能力标记时清零并提示更新userscript至2.8.0或更新版本、刷新游戏重新捕获。其它有效角色字段仍正常导入，不错误提示世界增益“保留原值”。制造页不据此改变导入规则。
- 两项世界增益通过原始context窗口从初始化至模拟结束全程生效，与热门加成独立叠加；经验影响原始经验和升级，稀有度进入主产物与适用品质奖励的原始抽样和机会期望。属性面板的固定幸运加成仍不包含context世界窗口，与热门品质窗口处理一致。改值保存、取消旧Worker并重算；语言、价格及周期变化仅重绘。
- “其它”在初始仓库后提供“丢弃采集物”开关（英文 Drop what I gather），默认关闭，开关下方显示“满包时才会丢弃，模拟结束时背包可能仍有剩余产物。”及对应英文说明；旧存储缺字段按关闭处理，清空和成功导入角色配置恢复关闭，技能切换保留。开启后调用原始 `onFull: drop`：满包时清理当前任务主产物和配方额外产物的全部品质，再继续工作；不是每次完成立即丢弃。经验和金币正常获得，坐骑、宠物与活动礼盒不因该开关取消；背包被其他物品占满且无可丢物品时仍可能回仓。切换开关保存配置并取消旧 Worker，重新模拟；属性面板公式不变。
- 丢弃模式的主要产物和配方额外产物以原始丢弃／存放事件分段结转机会期望：每次丢弃清空尚在背包的该段期望，存放时转入保留账本，结束时计入未丢弃的期末残留；其他奖励继续累计。表格产物与收入只包含保留账本，已丢弃部分不估值；表下注明仍为实际随机路径下的机会期望，期末残留也纳入收入。原始抽样库存和事件保持原样，不能以离线报告的累计产出代替最终保留量。
- 采集配置独立保存，不因修改采集配置改变战斗或强化配置。支持手动填写与角色配置导入；复用现有角色读取协议，适配采集字段并核验完整性。配置导入恢复默认任务范围、采集点策略、24 小时和沿用游戏热门设置。不提供完整采集角色快照入口。

**采集点、仓库与平均口径**

- 1.0.1190 适配完整原始地图、路线和回仓依赖，仍只提供四种既有技能；新增隐藏农田不加入采集任务或点位平均。验收覆盖四技能全部现有点位、自动／指定仓库与最近点选择，不能用任务定义未变替代新地图计算对照。

- 默认“所有采集点平均”：从原始世界数据和任务对应关系生成全部有效候选点，每点独立逐刻模拟，固定该点执行该任务。候选资格、可达性和随机策略须核验，不以距离或利润筛掉远点。
- 自动仓库逐点调用已核验的原始最近仓库规则；手动指定仓库时所有点均使用该仓库。仓库选择与采集点选择分开，不能通过挑选最近的仓库—采集点组合替代全点平均。
- 采集点选项依次为“所有采集点平均”“最近采集点”，单个任务模式另提供具体点。默认仍为平均；最近模式适用于单个或全部任务，保存为 `siteSelection: nearest`。最近以所选初始仓库经原始预测初始化后的角色起点为基准，自动仓库时先以仓库 1 初始化；使用原始客户端距离规则，同距保留原始点位顺序，不按利润选择。点位确定后仍沿用原始仓库与回仓规则。切换任务或技能保留最近策略，具体点选择则回到平均；旧配置、清空及导入默认平均。
- 选项下方提供“游戏内模拟默认最近采集点，实际随机选择。”及英文对应说明；这是用户提供的游戏实际行为说明，服务端随机权重仍未独立核验。默认满包回仓存放，开启丢弃采集物时按上述原始丢弃规则；固定点与单任务场景沿用相同策略。
- 设有效候选点数为 N，任一累计数量指标的平均值为各点该指标之和除以 N，包括完成次数、经验、金币、各品质主产物、逐物品额外奖励、回仓次数及偷窃被抓次数。先对未舍入总量取平均，再按所选时长换算每小时／每天，最后格式化。不得直接平均各点已格式化数据。
- 提前停止的点保留截至停止时的过程统计与机会期望，利润仍以所选时长为分母；平均明细展示提前停止情况。移动占比按全部点 movingTicks 合计除以 elapsedTicks 合计计算，分母为零时显示无有效数据。平均结束等级不作为角色等级展示，逐点显示或展示结束等级范围。
- 候选点模拟失败、不可达或候选集合异常时明确报告原因，整行不发布完整平均值；不得静默剔除失败点后仍标为所有采集点平均。合法候选排除须明确原始依据和原因。
- 主表每任务一行，地点明细显示平均口径、候选点数及逐点编号、坐标、仓库、利润和状态。均值只消除本次统计中点位选择的差异，不代表多随机种子的长期利润期望，也不保证与账号单次结果一致。

**结果与交互**

- 主表为任务、所需等级、采集次数、移动占比、经验、金币、主要产物、额外掉落、收入；沿用战斗表格搜索、排序、明细、进度和失败显示规则，默认所需等级降序。等级不足显示原因且不模拟，不以零利润表示未解锁；搜索仅影响展示。
- 主要产物按品质展开；物品名称按基础编号取原始名称再翻译，品质标签独立显示，不直接翻译带英文品质前缀的组合名，也不重复品质。额外掉落使用同一名称规则。高品质主产物与配方额外掉落分别统计。经验列仅显示数值并保留排序，不提供展开明细；采集次数列只显示完成次数；移动占比列的展开详情显示实际模拟、工作、移动耗时、回仓次数以及地点信息。偷窃另显示尝试次数、被抓次数和累计停顿；宠物、坐骑及其他特殊奖励在逐项核验事件归属后纳入额外掉落，不漏计或重复计数。
- 采集移动占比沿用全部点移动刻数合计除以实际模拟刻数合计，最多两位小数，零分母显示“—”；支持未舍入比例排序，不随利润周期换算。双语主表为 9 列，等待、失败、等级不足和空结果列数保持一致；地点明细始终从移动占比列展开。
- 表格下方保留统一的模拟条件与限制说明，不再显示随采集点选项变化的策略说明；采集点选项下方的固定说明保留。
- 估值与收入规则见 [全局物品价格](../shared.md#24-全局物品价格) 与 [战斗页的收入及明细约定](combat.md#34-属性利润与列表交互)。模拟配置不再提供估值选项。
- 采集每轮启动时生成 32 位无符号随机种子，同轮全部任务及采集点共用，通过原始 context 传入；热门默认仍为“沿用游戏设置”。搜索框旁提供紧凑的“重新模拟”按钮，取消旧轮后重新抽样；移动占比明细显示种子。排序、搜索、语言、周期与价格变化只重绘，不重新抽样。程序接口默认 seed 0，可显式传入种子复现；随机源失败明确提示，不回退固定值。
- Worker 按任务与采集点执行并提供进度，任务各点完整后发布该行均值；修改计算配置终止旧任务，旧结果不得混入。默认仅计算当前技能，本轮结果按完整计算输入管理；计算配置变化或重新模拟时废弃旧结果，不从旧轮缓存恢复。

**实施与验收**

- 合成模拟角色不参与每日／每周任务；1.0.1190 自动领奖不计入经验、金币或利润。每次原始 tick 前按原始日／周函数同步空任务的周期编号，避免重置时生成账号任务；不改原始引擎。验收覆盖自动领奖机会与跨日／跨周边界，独立原始离线对照以相同空任务条件分段执行。

- 使用采集配置／模型、逐刻模拟及控件模块；复用现有选择框、翻译、导入桥接、时间换算、商人估价与 Worker 模式。通过提取器增加工作路线、速度、资格及被抓概率等语义导出，再生成 upstream 模块，不手工修改生成文件。
- 先核验采集点选择与原始工作机制，再进行四技能独立预测对照，最后接入页面和导入；模拟必须包含升级、品质、回仓、移动和偷窃停顿，不能用理论工作次数替代原始过程；产物和奖励按已确认的机会期望规则统计。
