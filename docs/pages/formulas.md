# 公式页面

[设计索引](../../DESIGN.md) · [当前状态](../status.md)

## 页面与内容

- 共用页头提供“公式 / Formulas”导航，网址为 `/formulas`，支持尾斜线、直接打开、刷新、前进后退及章节链接。沿用语言选择和共用页脚。
- 第一期开设装备、角色属性、战斗判定、战斗经验、食物增益与移动、金币与掉落、世界首领理论输出七章。公式以文本块展示，不使用数学排版库；世界首领明确保留理论估算限制。
- 页面仅支持中文，正文、目录与加载提示在站点切换英文后仍保持中文，阅读区域标记中文语言。正文由专用公开目录 `src/content/formulas/` 中的中文 Markdown 文件维护，注明适用游戏版本；适用版本与 [已核验资源](../technical.md#62-原始代码复用) 一致，伤害公式不因上游拆出明细函数而改变。`reports/` 中的筹备稿不作为线上正文，也不开放整个文档或报告目录。
- 标题、列表、表格、文本公式块由本地固定版本 markdown-it 渲染，关闭原始 HTML，不依赖外部 CDN。首次进入才加载正文，成功结果在当前页面会话缓存；加载失败明确显示原因及重试入口，不以空白冒充成功。

## 阅读交互与布局

- 独立阅读布局，桌面为章节目录与正文两列，正文采用整页纵向滚动；目录可在视口内独立滚动。不采用模拟页的配置／结果工作区。
- 目录由正文二、三级标题自动生成，锚点使用带命名空间的稳定顺序编号，避免重复标题与现有控件 ID 冲突。
- 点击目录使用真实片段链接，支持复制、新标签、前进后退；异步正文就绪后处理初始章节链接。应用内切入其他板块不由过期加载覆盖当前页面，已加载正文不因无关角色重绘重复请求。
- 目录可折叠，首次渲染时桌面默认展开、窄屏默认折叠，避免长目录遮住正文；站点语言重绘保留展开状态。窄屏目录位于正文上方；表格和长公式各自在容器中横向滚动，不撑宽页面。采用现有主题、字号与颜色，正文左对齐，保留公式的空白及换行；键盘可访问目录和溢出内容。
- 中等宽度页头的导航独占一行，避免挤压品牌文字；保持其他页面的导航可用。
- 站点语言切换保留章节定位；刷新不额外持久化阅读状态。页面切换不重置已有模拟结果或重新启动模拟。

## 资源与发布

- Markdown 仅允许来自专用公开目录；本机服务继续限制 `docs/`、`reports/` 等内部目录。
- Markdown、渲染器及必要许可证随发布包分发，纳入资源摘要和 HTTP 验收；公式路由纳入重写规则与路由检查。markdown-it 在 `package.json` 中作为固定版本开发依赖管理，`pnpm-lock.yaml` 锁定包与依赖；通过 `vendor:markdown` 从安装包同步浏览器发行文件、源码映射、许可证和来源摘要，`--check` 验证本地发行文件与安装版本一致。不手写 Markdown 解析器。
- 用户正文与设计文档职责分离；规则更新时同步设计及中文正文。README 同步页面入口和内容维护入口。

## 验收

- 验证中文正文、路由和尾斜线、目录与重复标题、初始章节链接、前进后退及站点语言切换后仍显示中文。
- 验证首次进入加载、缓存复用、失败与重试、跨页面／重绘异步结果隔离、HTML 禁用及危险链接过滤。
- 验证桌面与 390px 下正文、表格和公式块可读且无页面横向溢出；切换页面与语言不重跑既有模拟。
- 验证本机公开路径、私有目录限制、发布包 Markdown 收录与公式路由；专项与完整发布验证分别遵循 [协作流程](../../AGENTS.md#工作流程) 和 [发布流程](../release.md#发布验证)。
