# 当前状态与验证入口

更新日期：2026-10-22。本文件维护生产基线、本地候选及仍有效的限制；功能规则由 [设计索引](../DESIGN.md) 指向的文件维护，历史版本从[报告索引](../reports/README.md)查阅。

## 已发布基线

- 生产版本 1.5.2，游戏资源 1.0.1196；角色 userscript 2.9.0，桥接 2.4，数据协议 2。此前生产验收见[1.5.2 发布报告](../reports/v1.5.2-release-2026-10-21.md)，不作为本轮重跑结果。
- 角色脚本支持官方中英文游戏站的同源捕获。安装／更新脚本后须刷新游戏与实验室；导入世界增益须使用完整捕获数据，缺能力标记时提示更新。市场价格由实验室直接读取官方公开 API。

## 本地变更与已知限制

独立 patch 候选为 1.5.3，仅包含游戏 1.0.1198 适配：强化每次 30 秒、分段成功率、六档碎片／经验倍率，书台退役及旧存档兼容；世界首领原始数据同步。设计见[强化页面](pages/enhancement.md)，来源及初次专项见[适配报告](../reports/upstream-update-2026-10-22.md)。本轮发布检查、提交、部署与正式域名验收状态统一见[1.5.3 发布报告](../reports/v1.5.3-release-2026-10-22.md)。

制造订单重构继续保留在原工作区及 1.6.0-preview.1 预览站，不进入本次提交或生产包。生产候选从 1.5.2 基线独立建立，保留原制造计划及其存储协议；调研资料不进入部署包。

仍有效的限制：

- 真实脚本管理器安装升级、真实账号操作、长时性能及打赏微信扫码支付未验证。
- 宽泛搜索或大量已定价／已锁定结果仍可能较慢，见[价格弹窗性能调查](../reports/price-dialog-performance-2026-10-16.md)；历史数值不是当前版本测量。
- [早期真实环境验证](../reports/userscript-worker-live-2026-10-14.md)只覆盖当时的角色／报价保存与只读桥接，不能据此认定当前卡顿或断连已解决。
