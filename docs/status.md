## 分支功能

- 制造采用多配方订单、整单执行选择、固定／比例／时间加工费、合并配方与材料采购计划；订单管理与编辑合并，自动建单、数量自动加入及批量修改。规则见[制造页面](pages/crafting.md)。
- 制造计划库存只读，按完整物品 ID 合并游戏仓库与背包。库存解析由 `src/character-inventory.js` 供收藏、制造共用；未知库存不当作零，失败及过旧响应保留有效数据。
- 六页共用“自动更新角色配置”，收藏、制造另提供“自动更新角色库存”。开关按页保存，手动与自动读取统一调度，两个选项紧凑同行并按需换行；规则集中于[共用角色自动更新](shared.md#导入游戏角色与自动更新)。
