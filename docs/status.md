## 1.6.0 发布候选

制造分支合并至 main，保留 1.5.4 的游戏 1.0.1199 适配，包括书台、原强化成功率、统一碎片及经验、30 秒尝试与强化宠物机会；不恢复已撤销的 1198 规则。来源见[1199 回退适配](../reports/upstream-rollback-2026-10-22.md)。

本次 minor 候选为 1.6.0，范围为：

- 制造多配方订单、整单执行、固定／比例／时间加工费、合并配方与材料计划、自动建单和批量数量。旧制造存档直接清除；规则见[制造页面](pages/crafting.md)。
- 收藏与制造共用独立库存解析，按完整物品 ID 合并仓库＋背包。制造库存只读，未知、失败及过旧响应保留规则继续生效。
- 六页共用“自动更新角色配置”，收藏、制造另有“自动更新角色库存”。开关按页独立保存，读取统一调度，选项紧凑同行并按需换行；见[共用角色自动更新](shared.md#导入游戏角色与自动更新)。

本次完整检查、专项、打包及生产验收尚待执行，状态与证据见[1.6.0 发布报告](../reports/v1.6.0-release-2026-10-22.md)。此前的[分支清理](../reports/crafting-branch-cleanup-2026-10-22.md)、[库存读取](../reports/crafting-inventory-2026-10-22.md)和[共用角色更新](../reports/character-auto-import-2026-10-22.md)仅作历史证据。

## 已知限制

- 真实脚本管理器安装升级、真实账号操作、长时性能及打赏微信扫码支付未验证；安装／更新角色脚本后须刷新游戏和实验室，导入世界增益须使用完整捕获数据。
- 宽泛搜索或大量已定价／已锁定结果仍可能较慢，见[价格弹窗性能调查](../reports/price-dialog-performance-2026-10-16.md)；历史数值不是当前测量。
- [早期真实环境验证](../reports/userscript-worker-live-2026-10-14.md)只覆盖当时的角色／报价保存与只读桥接，不能据此认定当前卡顿或断连已解决。
