# 后续范围

以下内容不属于当前版本已完成功能，实施前应细化需求与验收标准。

- 在现有可配置时长连续模拟基础上，研究更长周期与增益续用。
- 扩展增益续杯和连续任务场景。
- 增加 A/B 配装比较、击杀时间分布与多随机种子风险分析，展示长期利润估计误差；不将面板 DPS 直接换算为挂机利润。
- 世界首领仅支持客户端基础属性的静态估算；服务端动态机制未完整核验，实际团战模拟、总血量、排名与击杀时间不在当前范围。
- 增加公开资源版本检测，更新仍须经过差异审阅与回归验证。
- 强化的动态等级、有限预算、概率分位数与核心策略需另行设计与验证。



范围确认、设计与实现流程见 [AGENTS.md](../AGENTS.md)。当前功能规则从 [DESIGN.md](../DESIGN.md) 查阅。
