# 后续范围

以下内容不属于当前版本已完成功能，实施前应细化需求与验收标准。

- 精通自动分配的采集收入、经验获取、强化成本及多活动权重目标尚未实现，仅在 UI 中预留禁用选项；当前版本支持指定怪物的战斗总收入有限搜索，见[精通页面](pages/mastery.md#计算最优分配方案)，发布状态见[当前状态](status.md)。

- 收藏页跨方案库存流转、产物抵扣、执行顺序与联合时间／利润优化尚未实现；单方案最高目标去重及材料需求汇总已随1.4.1上线，导入仓库抵扣采购需求已随1.4.4上线，见[收藏页面](pages/collection.md)。
- 收藏性价比页面后续可扩展战斗、农耕、宠物、随机副产物与强化录来源，以及跨路线连续计划；当前1.4.0已实现范围见[收藏页面](pages/collection.md)。
- 在现有可配置时长连续模拟基础上，研究更长周期、有限时增益续用和连续任务场景；当前手动启用增益仍全程有效。
- 增加 A/B 配装比较、击杀时间分布与多随机种子风险分析，展示长期利润估计误差；不将面板 DPS 直接换算为挂机利润。
- 世界首领仅支持客户端基础属性的静态估算；服务端动态机制未完整核验，实际团战模拟、总血量、排名与击杀时间不在当前范围。
- 增加公开资源版本检测，更新仍须经过差异审阅与回归验证。
- 强化的动态等级、有限库存、任意报价保本概率输入与核心策略需另行设计与验证；80%／90%／95% 成本分位数已在本地实现，精确计算资源边界见[强化页面](pages/enhancement.md)。

范围确认、设计与实现流程见 [AGENTS.md](../AGENTS.md)。当前功能规则从 [DESIGN.md](../DESIGN.md) 查阅。
