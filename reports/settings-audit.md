# 设置参数影响核验

当前界面已进一步简化：手动技能进度固定为 0，取消累计经验覆盖；手动启用增益永久生效；家园按等级生效且无待完成升级。下表关于这些参数的影响分析仍是原始机制说明，不表示当前提供对应输入。

范围：当前保存的游戏资源 index-CEociSeB.js；静态战斗面板与独立目标一小时模拟。无采集、制作、农田、任务队列或并行强化。源码分析结合单变量差分，不以某次随机结果恰好相同判断参数无效。

## 已移除的设置

| 参数 | 原始实现依据 |
| --- | --- |
| 采集者药剂及其剩余时间 | `_1` 的采集经验分支使用；战斗经验 `eM` 不读取 gatherer |
| 采集、制作精通 | `Kx` 计算工作速度，普通战斗不经过此工作速度分支 |
| 离线时长精通 | `RC` 的离线刻上限使用；本页逐刻运行固定 6000 刻。原预测也将基础上限重置为两小时，不会限制一小时预测 |
| 强化成功率精通 | 强化分支使用；原预测 `mi` 清空并行强化 |
| 矿井、锯木坊、池塘、菜园、锻炉、开锁台、灶台、制弓架、药草架、织布机、符文书台的等级、放置和升级时间 | 前十项通过 `Bx` 影响采集制作速度，符文书台通过 `b9` 影响强化；不参与本页战斗 |
| 稳手、快手天赋 | `nI`/`Vx` 影响烧焦或被抓概率，`Kx` 影响工作速度，不影响战斗攻击间隔 |
| 持有金币 | `Ni` 更新余额；当前战斗不花费余额，金币列统计 killed 事件奖励，不读取初始余额 |
| 储藏室已放置开关 | `p9` 仅按储藏室等级增加格数，不检查 houseFurniture；保留等级和升级倒计时 |

仅过滤界面，原始数据、旧存档字段及快照内容仍保留；不修改生成的游戏代码。

## 保留的设置及影响范围

| 设置 | 实际作用或生效条件 |
| --- | --- |
| 技能等级、累计经验、级内进度 | 属性、装备穿戴门槛及模拟中的升级；累计经验启用时覆盖等级与百分比。非当前攻击技能可能影响混穿装备资格，不能整体删除 |
| 装备、品质、强化、坐骑 | 伤害、命中、防御、掉落品质及移动；空装备对应附加输入已禁用。全部装备开关用于选择混穿配置 |
| 食物、品质、初始食物增益 | 治疗、自动续增益、伤害与减伤；食物选择与初始增益可独立配置 |
| 其余七种药水及时间 | 移动、稀有品质、治疗、伤害/命中、攻速、经验、金币；倒计时仅在该药水启用时有作用 |
| 经验、移动、生命、伤害、命中、寻宝精通 | 面板或逐刻收益；保留原始取整规则 |
| 训练场、盔甲架 | 战斗经验与防御经验；可能进一步影响升级 |
| 练武木桩、箭靶、祭坛 | 相应攻击流派伤害；切换流派后生效，保留各流派配置 |
| 幸运神龛 | 掉落品质概率；单次样本可能恰好未变 |
| 储藏室等级、升级时间、购买格数、无限仓库 | `pu`/`ei`/`nl` 控制存库容量，库存接近上限时影响补给；祝福也能提供无限容量 |
| 口袋、丰盛餐食、休息天赋 | 背包容量、食物治疗、泉水恢复间隔；例如无需泉水的场景不体现休息天赋 |
| 食物优先级、品质上限、携带量、自动进食阈值 | 原始取食与进食策略；实际库存开关关闭时使用充足所选食物 |
| 仓库、背包、溢出区库存 | 食物供应、占格及银行操作；仅实际库存模式使用录入值 |
| 起始仓库 | 原地图路线和移动耗时 |
| 铁人模式 | `iu` 禁止坐骑掉落，影响稀有掉落列；未发生坐骑事件的试验可能相同 |
| 公会、祝福、全服与热门活动 | 经验或稀有倍率、容量，以及对应时间窗口 |
| 相关家园放置与升级时间 | 除储藏室外，相关加成检查是否放置；模拟内升级会改变有效等级 |
| 角色编号、seed、角色时间刻 | 随机序列、起点邻格或计时；当前刻影响增益与活动和固定预测起始刻的关系 |

条件生效项保留，避免当前没有开启药水、没有缺食物或恰好没有稀有掉落时被误删。搜索、排序、语言、展示周期等为界面功能，不属于待移除的模拟参数。
