# Deep Vein Idle · Lab

玩家制作的非官方 Deep Vein Idle 实验室，提供战斗利润比较、采集与制造模拟、强化期望成本、精通点数规划、收藏性价比、热门加成预报及战斗公式查阅。支持简体中文和英文（公式页面仅中文），计算在浏览器本地执行，无需登录游戏；可手动配置，也可通过角色 userscript 导入配置；市场报价直接从官方公开 API 导入，无需安装脚本或在游戏中浏览市场。默认打开网站时后台导入价格，两次自动导入尝试至少间隔 5 分钟，可在“物品价格 → 市场价格导入”取消“打开网站时自动导入”；完成后右上角提示。

[打开线上实验室](https://dvi-lab.pages.dev/) · [功能与设计](DESIGN.md) · [当前版本与待发布变更](docs/status.md)

## 快速启动

需要 Node.js 20+。运行网页无需安装开发依赖：

```sh
node scripts/serve.mjs
```

打开 [本机页面](http://127.0.0.1:4173)。安装依赖、测试、原始代码提取与本机服务边界见 [本地开发](docs/development.md)。

1.7.0-preview.2 的精通页 `/mastery` 增加“计算最优分配方案”：在战斗页配好角色，填写总精通点、选择怪物和计算模式后开始搜索，可取消并查看精简方案清单；完成后自动把最佳方案应用到下方目标等级，也可点击“应用”切换备选。当前等级为只读文本，目标可编辑，卡片显示增减级数及升级点数缺口。默认保留当前加点、仅分配剩余点数，也可选择重置全部精通；保留模式不会降低任何已有等级，并显示本次新增投入。界面预留多种目标，目前仅支持战斗总收入，不保证全局最优；仅修改精通页，不改写战斗等其他页面。此功能已部署到 [Preview](https://preview.dvi-lab.pages.dev/mastery)，生产尚未包含；线上完整验收存在统计服务跨域错误，详见[当前状态](docs/status.md)。规则见[精通页面](docs/pages/mastery.md#计算最优分配方案)。本地修复使两种方案均只更新目标并保留当前等级；低于当前的目标可保存，成本按累计差计算，此修复尚未发布。

隐藏收藏性价比页 `/collection`，只通过 URL 进入，不列入菜单。支持导入未完成收藏，比较获取精通点的动作耗时与材料成本；范围见[收藏页面设计](docs/pages/collection.md)。基础页面随1.4.0上线，1.4.1增加执行计划材料汇总、完成进度及自动导入；1.4.2简化为时间与材料成本比较，支持商人估值及角色导入联动市场报价。1.4.3增加候选分页、筛选保存与批量加入计划，并支持计划目标调整及材料表。1.4.4增加执行计划仓库库存抵扣、采购数量及采购成本。生产状态见[当前状态](docs/status.md)。

“公式”页入口为 `/formulas`，支持章节目录和链接定位。正文维护于 [中文 Markdown](src/content/formulas/combat.zh.md)，浏览器使用随站点发布的 markdown-it 渲染；页面范围与验收见 [公式页面设计](docs/pages/formulas.md)。

发布使用 `release:check`、`release:package`、`release:verify` 三个入口，完整日志落盘、终端只返回摘要；依赖安装、参数和部署步骤见 [发布流程](docs/release.md)。
