## 简介

玩家制作的非官方 Deep Vein Idle 实验室，提供战斗收益比较、强化成功率与期望成本、热门加成预报。同时提供采矿、钓鱼、伐木、偷窃的采集模拟：默认逐个模拟任务的全部采集点并取等权平均，另支持最近采集点、指定单点及角色配置导入。0.13.0 新增 `/mastery` 精通模拟页：填写当前与目标等级，可限定本次可用点数试配，或不限制点数计算升级成本；可通过左侧高亮导入区读取角色总点数、可用点数和已分配精通等级，导入后恢复限定点数模式；左侧仅配置模式和总点数，可用点数自动由总点数减去当前已分配等级的累计成本计算；修改总点数或当前等级后立即重算，总点数不足时明确提示；左侧“所有等级归零”可清零当前与目标等级，保留模式和总点数；电脑与手机均使用紧凑精通卡片，桌面按可用宽度显示两至四列、手机单列，目标操作按等级、+1、−1、MAX 排列；方案独立保存，已发布。支持简体中文和英文，计算在浏览器本地执行，无需登录游戏。战斗与采集统一按物品价格估值，未设置时使用商人价并提示。各页面的“导入游戏角色”默认展开；战斗页导入角色配置保留现有“模拟配置”全部选项。

当前线上版本 0.15.0：新增全局物品价格与分类市场导入，战斗与采集统一估值及缺价提示；战斗收入列位于食物列左侧，食物显示费用，收益扣除食物和药剂成本。市场导入需安装／更新角色 userscript 2.5.1。

## 物品价格

所有页面页头的“物品价格”打开共用弹窗，手动单价自动保存在此浏览器；品质与强化分别定价，空值未定价，0 有效。勾选物品或全选当前筛选结果，可批量锁定/解锁；锁定阻止市场导入覆盖，仍可手动修改。

安装/更新弹窗内的角色 userscript 2.5.1，刷新游戏及实验室，自行浏览游戏市场分类与变体后打开价格窗口，窗口会异步读取报价。脚本首次成功保存市场报价后显示双语捕获提示，15 秒后隐藏。分类表仅显示捕获数量和价格选项；武器、护甲、饰品、工具、坐骑默认不导入，其余分类默认买单价（商人价兜底），已有偏好保留，平铺单选项按“买单价（商人价兜底） / 买单价 / 卖单价 / 不导入”排列，按所选分类策略取价或跳过，再点击安装链接旁的“一键导入价格”。表格操作区的“清空价格”需确认后执行，清除所有未锁定价格（不限当前筛选），锁定价格、报价缓存和导入选项保留。报价覆盖只限游戏实际请求的物品；读取报价不会自动改价。各分类可独立选择“买单价（商人价兜底）”，可出售物品取商人价与最高买单价的最大值；商人价胜出或相等显示为商人价，明确无买单也使用商人价。未捕获、异常及锁定物品不覆盖，卖单导入不受影响。

战斗/采集始终使用全局单价；未设置时使用商人价并在表格估值数字及展开价格左侧标记 ⚠，改价只重估金额与收益。收入包含金币与掉落；食物与药剂列显示两者合计成本，展开分别查看成本及物品明细，战斗收益扣除实际食物消耗及每种已启用药剂每小时 1 个的费用。强化材料和底装可用全局价格或本方案填写，底装另可选已有底装为 0。完整规则与验证见 [DESIGN.md](DESIGN.md#24-全局物品价格)。

## 开发

需要 Node.js 20+。本地运行网页无需安装开发依赖：

```sh
node scripts/serve.mjs
```

打开 [本机页面](http://127.0.0.1:4173)。服务仅监听本机，可通过 `PORT` 环境变量修改端口；支持 `/combat`、`/gather`、`/enhance`、`/mastery`、`/forecast` 和隐藏调试页 `/debug`。

运行测试：

```sh
node --test tests/*.test.mjs
```

重新提取原始计算代码时，安装开发依赖后执行：

```sh
pnpm install --frozen-lockfile
node scripts/extract.mjs
```

基础完整公开资源位于 `vendor/game-original.js`；战斗回仓函数的补充完整资源位于 `vendor/game-combat-update.js`。两份来源、摘要与局部替换的依赖绑定记录于 `vendor/manifest.json`。禁止手工修改生成文件 `src/upstream.js`；更新原始资源须遵循 [上游更新流程](DESIGN.md#64-上游更新流程)，完成映射审阅、重新提取及回归验证。

## 部署

使用 Cloudflare Pages 的已有项目 `dvi-lab`，通过 Wrangler Direct Upload 发布到生产分支 `main`。

将 `index.html`、`_redirects`、`src/`、`vendor/`、`DESIGN.md`、`README.md` 及文档引用的报告和截图复制到独立发布目录，再执行：

```sh
npx wrangler login
npx wrangler pages deploy <发布目录> --project-name dvi-lab --branch main
```

市场导入需要安装／更新角色 userscript 2.5.1（调试脚本为 1.0.1），然后刷新游戏与实验室。两个脚本通过 `https://*.dvi-lab.pages.dev/*` 支持该项目全部预览通道与部署地址。

发布预览通道时，将部署命令的分支改为 `--branch preview`；预览地址为 <https://preview.dvi-lab.pages.dev/>，生产不受影响。

授权过期时，可用 `npx wrangler login --scopes account:read user:read pages:write` 重新授权。发布后核验页面路由、公开资源、双语界面及普通战斗计算，完整要求见 [静态托管与发布](DESIGN.md#65-静态托管与发布)。
