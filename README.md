# Deep Vein Idle · Lab

玩家制作的非官方 Deep Vein Idle 实验室，提供战斗利润比较、采集与制造模拟、强化期望成本、精通点数规划、收藏性价比、热门加成预报及战斗公式查阅。支持简体中文和英文（公式页面仅中文），计算在浏览器本地执行，无需登录游戏；可手动配置，也可通过角色 userscript 导入配置；市场报价直接从官方公开 API 导入，无需安装脚本或在游戏中浏览市场。默认打开网站时后台导入价格，两次自动导入尝试至少间隔 5 分钟，可在“物品价格 → 市场价格导入”取消“打开或聚焦时自动导入”；完成后右上角提示。

[打开线上实验室](https://dvi-lab.pages.dev/) · [功能与设计](DESIGN.md) · [当前版本与待发布变更](docs/status.md)

## 快速启动

需要 Node.js 20+。运行网页无需安装开发依赖：

```sh
node scripts/serve.mjs
```

打开 [本机页面](http://127.0.0.1:4173)。1.8.1 已发布：同步游戏 1.0.1204 的纯净煤矿及固定普通品质规则，精通最优分配默认使用“重置后分配”。完整验收与证据见[1.8.1 发布报告](reports/v1.8.1-release-2026-10-28.md)。安装依赖、测试、原始代码提取与本机服务边界见 [本地开发](docs/development.md)。

精通页 `/mastery` 提供“计算最优分配方案”：读取战斗页配装，在精通页设置总点数、目标怪物和计算模式，完成后自动应用最佳目标等级，也可应用备选。默认“重置后分配”，另有“分配剩余点数”；两种模式均保留当前等级，只修改目标，不改写其他页面。卡片显示目标加成、增减级数、累计成本差与点数缺口，允许保存目标低于当前的重置比较方案。

搜索提供快速／标准／深入／全面四档，上限 60／120／360／720 个配置，默认标准。目前仅支持战斗总收入；仅此目标在生成候选时忽略升级的间接收益，实际模拟仍包含升级。搜索不保证全局最优；规则见[精通页面](docs/pages/mastery.md#计算最优分配方案)。已发布到[生产精通页](https://dvi-lab.pages.dev/mastery)，对应版本生产验收已通过；本地待发布变更、部署与证据见[当前状态](docs/status.md)。

隐藏收藏性价比页 `/collection`，只通过 URL 进入，不列入菜单。支持导入未完成收藏，比较获取精通点的动作耗时与材料成本；范围见[收藏页面设计](docs/pages/collection.md)。支持按采集／制造独立筛选和分页、批量加入执行计划、调整目标、汇总材料，以及读取游戏仓库与背包抵扣采购需求。角色配置和库存自动更新可分别设置，材料可按全局价格、官方报价或商人价估算。生产状态见[当前状态](docs/status.md)。

“公式”页入口为 `/formulas`，支持章节目录和链接定位。正文维护于 [中文 Markdown](src/content/formulas/combat.zh.md)，浏览器使用随站点发布的 markdown-it 渲染；页面范围与验收见 [公式页面设计](docs/pages/formulas.md)。

发布使用 `release:check`、`release:package`、`release:verify` 三个入口，完整日志落盘、终端只返回摘要；依赖安装、参数和部署步骤见 [发布流程](docs/release.md)。
