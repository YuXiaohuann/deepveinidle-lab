# Deep Vein Idle · Lab

测试版 0.11.5，玩家制作的非官方实验室，提供战斗收益比较、强化成功率与期望成本、热门加成预报。支持简体中文和英文，计算在浏览器本地执行，无需登录游戏，不进行角色操作或交易。

[打开线上实验室](https://dvi-lab.pages.dev/)

## 本地运行

需要 Node.js 20+，运行网页无需安装依赖：

```sh
node scripts/serve.mjs
```

打开 [本机页面](http://127.0.0.1:4173)。服务仅监听本机，可通过 `PORT` 环境变量修改端口。

## 使用

页头提供战斗（`/combat`）、强化（`/enhance`）、预报（`/forecast`），首页默认进入战斗。网址支持直接打开、刷新及前进后退。切换页面或语言保留当前配置与结果；角色配置自动保存在当前浏览器，本机与线上域名之间不自动同步。配置菜单默认折叠，点击标题展开。

### 战斗

1. 首次打开使用 85 级远程示例。选择风格，配置技能、装备与坐骑、食物、药水、家园、精通和天赋，也可按下文导入角色。切换风格保留等级及通用装备，清除不匹配装备；无效装备会显示原因。精通填写实际加成百分比。
2. 在“食物”设置进食策略、品质上限、每趟携带量和阈值。选择食物用于预览，需点击“应用所选食物的增益”才启用初始增益。指定食物可超过自动进食品质上限，其他食物优先策略仍受该上限限制。
3. 在“其它”设置公会经验、世界增益、祝福、初始仓库和铁人模式。仓库可自动逐敌人选择最近位置，或指定仓库 1/2。世界增益经验按已核验每周目标计入；游戏内置预测未计入此项。
4. 在“模拟配置”选择敌人范围（默认全部，可选某个具体敌人），仅计算并展示所选敌人；选择会自动保存，角色配置导入恢复全部。模拟时间可选择 1 小时、24 小时（默认）或自定义小时数，支持小数，最短 1 分钟、精度 1 分钟。热门加成默认“沿用游戏设置”；“按照当前时间”应用并显示窗口内的现实日程，“不计入”排除热门加成。
5. 在“敌人”面板查看所选范围的击杀、经验、金币、掉落和食物消耗，默认按等级降序排列，可搜索并点击数值表头切换升降序。点击收益明细查看分技能经验、物品数量或移动与补给统计，点击等级展开生命、双方最大伤害和双方命中率；实际模拟仓库位于击杀展开明细中。

收益默认每小时，始终可选总量；仅模拟时长达到 24 小时时可选每天，缩短至不足 24 小时会从每天切回每小时：每小时为实际总量除以所选小时数，每天为小时平均值乘以 24。非 24 小时窗口的每天值只是折算估算。死亡后不自动复活，提前结束仍按所选时长换算。

导入的公会名称为 `SakuraSpring` 且标签为 `SAKI` 时，战斗配置末尾显示“一起蛐蛐撒库拉”菜单，提供“按商人价格计算掉落价值”。该开关默认关闭，开启后两类掉落显示价值并增加总收入，明细仍保留数量。总收入为金币加掉落价值，不扣食物成本；品质和强化不加价，不可出售物品价值为 0。关闭时若正在按总收入排序，会恢复等级降序。仅菜单隐藏时保留已有估价偏好，角色配置导入会关闭估价。估价、收益单位、排序及语言切换均不重新模拟；修改计算配置会重新计算。

### 强化

1. 左侧填写强化技能等级、已放置的符文书台等级和强化精通实际加成，也可导入游戏角色。
2. 右侧用中英文名称搜索装备或工具，点击候选或用方向键与 Enter 确认；Escape 或离开选择框恢复已选名称。设置品质、当前及目标强化值（+0–+100），目标不得低于当前。
3. 按需启用保护卷轴并设置起始等级（最低 +2）。无保护失败回 +0；保护生效时失败降一级，仅失败消耗卷轴。
4. 在“材料与底装估价”填写碎片、卷轴单价及底装购置费。空价表示未定价，所需价格不全时不输出完整金币估价；已有底装可填 0。

结果先显示逐级成功率和单次费用，再依次汇总包含失败重做的期望金币、碎片、保护卷轴、金币（含3%市场税）、强化次数及强化耗时。含税金币为（强化金币＋碎片估价＋卷轴估价＋底装购置费）×1.03；所需材料或底装未定价时显示“未完整定价”，已有底装填 0。下方“金币估价”按强化金币、碎片费用、卷轴费用、底装购置费、税前合计、市场税、含税总投入七步展示具体计算。强化配置独立保存，不覆盖战斗配置；导入的装备候选仅本页保留，刷新后需重新导入。

### 预报

查看当前热门、切换倒计时及后续日程。默认列出未来 24 小时内开始的 48 个时段；组合选择技能与加成类型后，显示未来 10 次匹配时段，可跨多日。不可能的组合会明确提示。

时间使用浏览器本地时区；筛选在页面和语言切换后保留，刷新恢复全部。

### 调试（仅网址进入）

打开 `/debug`，菜单不显示此页。页面依次提供三个面板：“从游戏导入”（并列提供脚本安装和战斗快照导入）、“导出为文件”和“从文件导入”。“导出角色配置”可直接下载最近读取的角色数据，无需打开战斗预测；文件可用于战斗或强化导入配置。“导出角色快照”包含完整预测输入：在此页点击“安装 / 更新调试 userscript”安装独立调试脚本 **1.0**，刷新游戏和调试页，先在游戏打开战斗预测列表并等待“预测快照已读取”，再点击“导出角色快照”，下载完整角色与预测数据的 JSON 文件。

选择快照文件后，可分别导入战斗配置、战斗快照或强化配置，配置导入效果与对应页面一致，完整战斗快照仅由调试页文件导入，无需连接 userscript。配置自动保存；战斗快照仅当前页面有效，刷新后丢失。文件无效或不兼容时保留原配置并显示错误。

## 从游戏导入角色

战斗导入配置会先恢复默认值，再覆盖成功导入的字段：敌人恢复全部、模拟时间 24 小时、热门沿用游戏设置、商人估价关闭。食物相关字段导入不了时保留原值；其他缺失或无效字段恢复默认并提示。失败提示按分类汇总，食物单独一行，其他分类在下一行提示手动配置。完整快照和强化导入不受影响，整体导入失败保留原配置。

当前 userscript 版本为 **2.4**。所属公会的名称与标签随角色导入，作为隐藏配置保存，不影响计算；退出公会后再次导入会清空该信息。

1. 安装支持 GM 本地存储的脚本管理器（如 Tampermonkey），允许其在相关站点运行。在模拟器“导入游戏角色”中点击“安装 / 更新 userscript”，或打开[本机安装脚本](http://127.0.0.1:4173/src/character-import.user.js)。更新时覆盖原角色脚本，不要同时启用两份角色脚本。旧用户须更新至 2.4；需要完整快照时，再从 `/debug` 安装调试脚本，两个不同用途的脚本可同时启用。
2. 刷新 [Deep Vein Idle](https://deepveinidle.com/)，等待左下角“角色配置已读取”提示。脚本默认仅捕获角色配置，不提示打开战斗预测。完整快照捕获已迁移至独立调试脚本，普通脚本不再捕获预测。成功提示会自动隐藏，数据仍可导入。
3. 在同一浏览器和脚本管理器环境下刷新模拟器，展开“导入游戏角色”并选择对应操作。

| 操作 | 数据与保存方式 |
| --- | --- |
| 战斗：导入配置 | 恢复默认配置后覆盖成功导入的字段，可编辑并自动保存；无法映射的食物字段保留原值，其余恢复默认并提示。敌人全部、时长 1 小时、热门沿用游戏设置、估价关闭，计算仍遵循手动假设 |
| 调试页：导入战斗快照文件 | 保留内置预测实际读取的精确经验、真实库存、增益期限等输入。仅本页有效，刷新丢失并恢复已保存配置；不自动重新导入 |
| 强化：导入配置 | 导入强化技能、书台和精通，并将已穿戴/库存物品列为快捷候选，选择后带入品质和当前 +值；无需打开战斗预测 |

快照默认 1 小时、沿用游戏设置，不叠加手动热门或世界增益；角色配置只读，可改敌人范围、时长、收益单位和估价。下方仅是配置预览，部分无法映射的显示值可能沿用旧配置，实际计算使用完整快照。导入配置或清空配置可退出快照。

调试脚本通过已核验资源位置表识别预测调用，不依赖压缩函数名，也不下载或解析游戏源码。游戏资源更新后若无法匹配，调试页导出或导入快照文件会提示“未适配游戏版本”；此时配置导入仍可使用。当前已核验并支持 `index-C3S-5Yeu.js`（1.0.1181），旧资源快照不用于新版计算。

无游戏提示时检查脚本启用状态和站点权限；旧脚本、未捕获预测、缺字段或未核验游戏版本会明确报错，原配置保留。更新脚本后须刷新游戏和模拟器。角色脚本和调试脚本分别在管理器独立存储中保存最近角色配置与预测输入，不发送游戏指令，不保存认证信息或聊天。捕获与兼容规则见 [导入协议](DESIGN.md#61-角色导入组件与-userscript-协议)。

## 重要限制

- 手动战斗从仓库附近满血出发，级内经验为 0，所选食物充足、仓库无限，手动启用增益永久生效；模拟中仍会移动、补给、进食、升级和死亡。不包含任务队列、并行强化或农田作业，结果可能与账号预测不同。完整快照也不复现服务端秘密随机序列。
- 普通怪物最大伤害相同是原始代码行为；罕见掉落在单次模拟中可能为零。
- 强化按固定技能等级、材料与卷轴充足计算，期望不是保底预算；不模拟期间升级、有限预算或巨像核心。每次耗时 2.4 秒，不含操作等待。
- 预报来自已核验公开代码，尚未与实时游戏核对，设备时钟或上游规则变化可能影响结果。
- 导入已通过合成数据及桥接验证，当前脚本真实账号/Tampermonkey 安装后的端到端运行尚未验证。完整验证记录见 [DESIGN.md](DESIGN.md#7-验证状态)。

## 开发与部署

### 测试及上游更新

```sh
node --test tests/*.test.mjs
# 仅重新提取时需要开发依赖
pnpm install --frozen-lockfile
node scripts/extract.mjs
```

完整公开资源位于 `vendor/game-original.js`，来源及摘要记录于 `vendor/manifest.json`。不要手工修改生成文件 `src/upstream.js`；更新前按 [上游更新流程](DESIGN.md#64-上游更新流程) 审阅快照、映射与签名，再提取并回归验证。

### 发布到 Cloudflare Pages

使用已有项目 `dvi-lab`，通过 Wrangler Direct Upload 发布到生产分支 `main`。将 `index.html`、`_redirects`、`src/`、`vendor/`、`DESIGN.md`、`README.md` 及对应报告和截图复制到独立发布目录，再运行：

```sh
npx wrangler login
npx wrangler pages deploy <发布目录> --project-name dvi-lab --branch main
```

授权过期时可用 `npx wrangler login --scopes account:read user:read pages:write` 重新授权。路由、资源与发布核验要求见 [静态托管与发布](DESIGN.md#65-静态托管与发布)。
