# Deep Vein Idle · Lab

测试版 0.7，独立网页，用于模拟战斗数值、比较全部敌人的收益，以及计算强化成功率与期望成本。当前支持普通怪物的击杀、经验、金币、掉落和食物消耗比较，以及每小时／每天／总量展示。普通怪物直接调用游戏原始函数；世界 Boss 目前仅提供标记为估算的战斗数值，完整收益暂不支持。

## 0.7 更新

战斗模拟新增“按商人价格计算掉落价值”选项，默认关闭。开启后显示两类掉落价值与总收入，明细保留数量；总收入高亮，击杀取消高亮，模拟仓库移到最后一列。切换估价保留已有模拟结果。

## 0.6 更新

0.6 新增“强化”板块：支持全部可强化装备与工具、角色导入、保护策略，以及计入失败重做的期望金币、碎片、卷轴、次数和耗时；材料单价与底装购置费可手动估价。固定强化技能等级，不模拟过程中升级。

战斗支持配置模拟时间，默认未来 1 小时，提供 1 小时、24 小时、自定义时长（按小时输入，支持小数，计算精度为 1 分钟）；默认每小时为窗口总量除以所选小时数，每天为小时平均值乘以 24，总量为实际累计值，非 24 小时时属于折算估算。热门加成提供“沿用游戏设置、按照当前时间、不计入”，默认沿用游戏内置预测规则；按照当前时间时展示并应用所选时长内的战斗加成。配置子菜单默认折叠，“天赋”紧接“精通”，公会、祝福和补给归入“其它”，区域最下方的“模拟配置”包含模拟时间、热门加成与“按商人价格计算掉落价值”选项。表头不高亮，数值右对齐；经验、金币、掉落价值及总收入显示整数，击杀、食物和掉落明细数量固定一位小数。掉落明细紧凑显示且数量右对齐，击杀明细按四行显示模拟时间、移动时间、移动占比和取食次数。完成后的状态及每天模式额外提示已移除。角色导入脚本升级为 2.0，提供导入配置与临时完整快照。

## 运行

需要 Node.js 20+。运行网页不需要安装依赖：

```sh
node scripts/serve.mjs
```

打开 http://127.0.0.1:4173 。只能从本机访问。可通过 PORT 环境变量修改端口。

## 发布到 Cloudflare Pages

线上地址：<https://dvi-lab.pages.dev/>。

使用 Wrangler Direct Upload，生产分支选择 `main`。将 `index.html`、`_redirects`、`src/`、`vendor/`、`PLAN.md`、`README.md` 复制到独立发布目录，再运行：

```sh
npx wrangler login
npx wrangler pages deploy <发布目录> --project-name dvi-lab --branch main
```

Pages 项目已创建。网页在访问者浏览器中完成模拟，无需后端；本机与线上域名的配置分别保存在各自的浏览器存储中。授权过期时可使用 `npx wrangler login --scopes account:read user:read pages:write` 仅申请账号读取与 Pages 发布相关权限。

## 从游戏导入角色

1. 浏览器安装支持 GM 本地存储的脚本管理器（如 Tampermonkey，来自浏览器扩展商店），按其提示允许用户脚本运行。模拟器的“导入游戏角色”区域点击“安装 / 更新 userscript”，在脚本管理器中安装。也可直接打开本机 `http://127.0.0.1:4173/src/character-import.user.js`。
2. 安装后刷新游戏 <https://deepveinidle.com/>。左下角先持续显示“等待游戏数据 / Waiting for game data”；角色读取成功后提示打开战斗预测；捕获实际预测输入后显示“预测快照已读取 / Predictor snapshot captured”，15 秒后自动消失，数据仍可导入；脚本读取正常收到的角色和内置预测实际使用的输入，不发送游戏指令。安装后如没有提示，检查脚本管理器是否已启用脚本和站点权限。
3. 刷新模拟器，在同一浏览器、同一脚本管理器内使用。展开“导入游戏角色”，选择“导入配置”或“导入快照”，没有分类勾选。

“导入配置”一次覆盖全部受支持的配置并自动保存，之后可手动修改。精确经验转换为技能等级；未指定食物品种等无法映射的数据保留原值并提示。模拟时间与热门默认与游戏内置预测一致：1 小时、沿用游戏设置；已有明确选择保留。此路径继续使用零级内经验、单种充足食物及永久启用增益等手动假设。

“导入快照”需要先在游戏打开战斗预测列表，等待“预测快照已读取”。脚本读取内置预测实际使用的完整角色对象、welcome seed 和世界增益窗口，保留精确经验、真实库存、增益期限及施工状态。模拟器使用原始预测初始化，默认 1 小时、沿用游戏设置，不叠加手动热门或世界增益。快照生效时下方为只读配置预览，并非完整快照；无法映射的显示值可能沿用原配置，实际计算仍使用完整快照。可改模拟时长和收益展示；导入配置或清空配置退出快照。快照仅在页面内存中，刷新后丢失并恢复原先保存的配置，不写入模拟器浏览器存储。

userscript 为跨域传递，在脚本管理器本地保存最近角色及预测输入；它不会在模拟器刷新时自动重新导入。脚本不发送游戏指令，不保存认证信息、聊天或完整网络消息。当前快照计算仅接受已核验构建 `index-DwK7yQ7O.js`；旧协议、未捕获预测、缺字段或未核验游戏版本会明确报错，已有配置保留。

当前脚本版本为 **2.0**。通过本机“安装 / 更新 userscript”入口覆盖已有脚本，保留同一脚本身份，不要同时启用两份；然后刷新游戏和模拟器。脚本的沙箱与页面通过共享 document 的 JSON 事件通信，最多等待 4 秒并重试。游戏等待提示持续到存储成功，成功后 15 秒隐藏；读取或存储失败明确显示。

已验证合成角色的实际原始预测捕获、DOM 桥接和异步存储，以及强化专用导入与独立存档；真实账号及 Tampermonkey 安装后的端到端运行尚未验证。

## 强化模拟器

打开页头“强化”或本机 `/enhance`。左侧“角色配置”沿用战斗页样式，提供角色导入及默认折叠的技能、家园、精通菜单，填写强化技能等级、已放置的“符文书台等级”与“强化精通实际加成”百分比。右侧“强化装备”提供“快捷选择角色物品”；在装备选择框输入中文或英文名称搜索全部可强化装备与工具，用鼠标或方向键与 Enter 确认。未确认的搜索不会改变当前计算，Escape 或离开选择框恢复已选名称。选择品质，填写当前与目标 +值，配置“使用保护卷轴”“保护卷轴起始等级”、材料和底装估价，下方先显示逐级成功率与单次费用表格，再显示期望强化成本与金币估价；可从当前 +2 或更高起使用保护卷轴。无保护失败回 +0；保护生效失败降一级，且仅失败消耗卷轴。

展开“导入游戏角色”，使用现有 2.0 userscript 读取最近角色配置，无需先打开战斗预测。导入强化技能、符文书台与精通；已穿戴和库存物品列入候选，选择后带入品质和当前 +值。配置独立自动保存，导入不覆盖战斗配装；物品候选仅本页保留，刷新后需重新导入。缺字段或读取失败明确提示，原配置保留。

强化技能每比1级高一级，成功率倍率增加0.2%（51级倍率为1.10）；书台和精通倍率相乘，最终成功率上限100%。结果为固定强化技能等级、材料与卷轴充足条件下的解析期望，包含失败后重做；期望不是保底预算。真实强化会获得经验并可能升级，本版不模拟动态等级或有限预算，不使用巨像核心。每次耗时按 2.4 秒计算，不含界面等待。

展开“材料与底装估价”可填写碎片、卷轴单价和底装购置费。空价表示未定价，所需材料价格不全时不输出完整金币估价；已有底装可填 0。底装费用单列，避免与强化费用混淆。极大期望值使用科学计数法显示。所有计算在浏览器本地执行，不进行游戏强化或交易。

## 使用说明

- 页头内“战斗 / 强化 / 预报”为同级板块，分别使用 `/combat`、`/enhance` 和 `/forecast`，首页 `/` 默认打开战斗；可复制网址、直接打开和刷新，支持浏览器前进／后退。现有配置和收益比较全部位于战斗；预报展示当前热门加成与切换倒计时，默认展示未来 24 小时日程；技能与加成使用平铺按钮组合筛选，PC 端两组并排且加成靠右，窄屏分行显示，筛选后展示未来 10 次匹配时段（可跨多日）。技能名高亮，加成类型使用普通样式。时间按 `10/06 11:30-12:00` 显示，跨日补充结束日期，使用浏览器本地时区；无稀有热门的技能会明确提示。预报基于游戏 1.0.1173 公开规则，尚未与实时游戏核对，战斗模块默认沿用游戏内置预测热门规则，也可选择按照当前时间应用预测热门加成或不计入。切换板块保留配置、筛选、折叠状态与计算结果，切换语言保留当前板块；刷新按当前网址打开对应板块，筛选恢复默认。
- 首次打开提供 85 级远程示例配置；风格按钮高亮当前选择，切换时保留等级与通用装备、清除不匹配装备。远程／魔法未装备武器时自动选择基础武器。
- 五项技能等级均可编辑，当前风格对应的攻击技能高亮。装备下拉默认只显示当前风格及通用装备，可开启全部装备。
- 角色配置的所有子菜单首次打开或刷新时默认折叠，可独立展开，操作与语言切换后保留本页折叠状态；“技能”“食物”“家园”“精通”“天赋”独立显示，“天赋”紧接“精通”。配置保存在本机浏览器。
- 装备包含坐骑，可选择马的品质和强化，显示其移动速度加成；默认不装备。当前快照的其他工具和天赋不提供移动速度加成。
- 等级不足的装备不计入结果，并显示提示；双手大剑使副手无效。界面限制为当前风格装备，底层仍保留原游戏混穿计算规则。
- “食物”菜单依次显示选择食物、增益、策略、品质、每趟携带、进食阈值。进食阈值仅提供 25%、50%、75%；每趟携带仅提供 5、10、20、留一格、满包。旧自定义值不在选项内时分别恢复 50% 和满包。食物选择用于预览回血与增益持续时间，点击“应用所选食物的增益”启用对应增益。选中食物不代表每次攻击前都进食。指定食物策略允许所选食物超过自动进食品质上限；优先好食物／优先差食物仍遵循该上限。
- 药水清单从原游戏定义筛选影响战斗的 7 种，按制造等级升序排列，名称旁不显示等级；经验、寻宝、金币药水参与小时收益，疾行药剂影响地图移动。
- 所有表头均不高亮；敌人、击杀、经验、金币四列的数据内容高亮。敌人名称不排序，其余列点击表头可切换升降序；默认等级升序，缺失值置于组末，世界 Boss 始终在普通怪物之后。
- 三种 Boss 使用公开基础数据估算，不包含服务端动态缩放和未验证的最终取整；不输出虚假的固定实战 HP。
- 普通怪物没有逐目标护甲扣伤，最大单次伤害相同属于当前原始代码行为。
- 本版使用原始完整模拟流程，可通过 userscript 读取角色配置；不包含登录、交易或角色操作。

## 精通与小时收益

精通输入显示实际有效加成，百分比步进为 0.5 个百分点，内部仍保存原始等级，因此旧配置保持原有效果。战斗板块不显示无影响的采集、制作、离线及强化精通；强化精通在强化板块单独配置，旧存档字段保留。

敌人表格显示击杀、经验、金币、普通掉落、稀有掉落及食物消耗；勾选商人估价时两类掉落显示价值，并增加总收入列。默认折算每小时，可切换每天、总量；每小时为实际累计值除以所选小时数，每天为小时平均值乘以 24，总量为模拟期间实际累计值。非 24 小时的每天数据为折算估算，经验与掉落明细同步换算，计算不另行小时取整。显示时经验、金币、掉落价值和总收入四舍五入至个位，击杀、掉落明细数量和食物固定一位小数（包括 .0）；明细使用相同格式，排序使用未舍入数值。死亡状态与单次运行时长不放大。点击数量可查看技能、物品品质及模拟明细；击杀明细按四行显示模拟分钟、移动分钟、移动占比和取食次数。移动占比按实际模拟时长计算，不随每小时／每天切换。

每种普通怪物在 Worker 中独立运行原游戏初始化及所选时长的连续逐刻流程：原始预测入口初始化，原始逐刻入口执行地图寻路、移动、战斗、进食、回库补给、泉水恢复和死亡处理。与原始预测／离线入口的计算结果进行回归对比，测试不依赖收益用户脚本；不再冻结等级，经验积累可升级。配置变更取消旧计算。

页面支持手动配置、userscript 导入配置及临时完整快照；配置导入后可修改，快照角色设置只读。除等级、装备、坐骑、药水、家园与精通外，“其它”合并公会与祝福、补给设置；最下面的“模拟配置”设置模拟时间和热门加成。折叠区域可配置：

- 五项战斗技能等级；初始级内经验进度固定为 0，模拟中仍正常获得经验与升级。
- 公会经验、每周目标（全服）经验加成、矿脉祝福；手动启用的药水、祝福与初始食物增益永久生效。
- “天赋”菜单配置口袋、休息及丰盛餐食等级；“食物”菜单配置食物优先级、品质上限、每趟携带量。
- “其它”菜单中的补给配置中的模拟初始仓库位置（自动、仓库 1、仓库 2）和铁人模式；家园设施等级（按所填等级生效，默认未在升级中）。

配置自动保存。所选食物固定充足，仓库容量无限；“其它”菜单中的补给配置可自动逐敌人选择最近仓库，或指定仓库 1/2，列表最后一列显示实际模拟仓库，不提供库存设置。角色从该仓库附近满血出发，耗尽食物后返回补给。“模拟配置”中的“热门加成”提供“沿用游戏设置、按照当前时间、不计入”，默认沿用游戏内置预测时钟与热门规则。按照当前时间时，应用本次计算开始起所选模拟时间内的战斗经验／稀有热门加成，下方显示本地时区、区间及相关时段（包含当前部分）；不计入则抵消热门加成。首次、清空和没有明确旧选择的配置默认沿用游戏设置；旧明确启用／禁用分别迁移为按照当前时间／不计入，已保存的新选择保留。所有敌人使用同一起点；修改配置重新计算，语言、收益单位、排序和板块切换保留该区间。默认模拟未来 1 小时，模拟时间可选 1 小时、24 小时、自定义时长并自动保存；旧配置缺字段默认 1，角色导入保留此项。死亡提前结束时仍按所选时长口径换算，不自动复活。“世界增益经验”沿用已核验的每周目标来源，游戏内置模拟未计入此项，本模拟器计入。该项可由角色导入或手动输入百分比，步进 1%，全程生效；与公会经验、矿脉祝福按原游戏加法叠加，不增加稀有掉落加成。

模拟范围为独立目标战斗，不包含任务队列、并行强化和农田作业。原始预测重置位置与血量，因此不提供这两个输入。不再提供内部复现参数输入；手动模式固定角色编号 1、seed 0 和原始预测刻，忽略旧手动存档的覆盖值。默认 secretAt=()=>0，与客户端预测一致。坐骑、疾行药剂和移动精通实际影响寻路耗时。死亡或路线结束按原始 100 刻检查间隔停止，不自动复活。

经验合计攻击、防御和生命，金币不包含售卖；普通、稀有掉落列默认显示数量（一位小数），不显示总收入。在左侧“模拟配置”勾选“按商人价格计算掉落价值”后，两类掉落按游戏商人收购价显示金币价值，并显示总收入列；展开列表始终保留各品质的掉落数量。选项自动保存，旧配置默认不勾选，切换不重新模拟，临时快照也可切换。关闭时若正在按总收入排序，会恢复等级升序。品质及强化不提高收购价，不可出售物品折算为 0。普通掉落包含全部品质，稀有掉落统计额外物品（含宠物、坐骑、碎片）。稀有掉落右侧的总收入为金币加两类掉落价值，不扣食物成本，可排序且随收益周期换算。罕见物品可能在单次预测中为零，Boss 完整模拟暂不支持。

完整角色快照为本页临时导入，不提供文件或粘贴导入。导入配置只将受支持字段转换成手动配置。旧手动存档中的库存、容量、活动、旧热门模式与计时、经验进度、增益倒计时、家园放置与升级设置均不再生效。

参数核验与移除依据见 [设置参数核验](reports/settings-audit.md)。历史报告中的模式与配置可能已移除，以当前需求文档为准。
