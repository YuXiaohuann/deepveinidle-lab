# Deep Vein Idle · Combat Lab

测试版 0.2，独立网页，主要用于模拟战斗数值、比较全部敌人的收益。当前支持普通怪物的击杀、经验、金币、掉落和食物消耗比较，以及每小时／每天展示。普通怪物直接调用游戏原始函数；世界 Boss 目前仅提供标记为估算的战斗数值，完整收益暂不支持。

## 运行

需要 Node.js 20+。运行网页不需要安装依赖：

```sh
node scripts/serve.mjs
```

打开 http://127.0.0.1:4173 。只能从本机访问。可通过 PORT 环境变量修改端口。

## 发布到 Cloudflare Pages

线上地址：<https://dvi-lab.pages.dev/>。

使用 Wrangler Direct Upload，生产分支选择 `main`。将 `index.html`、`src/`、`vendor/`、`PLAN.md`、`README.md` 复制到独立发布目录，再运行：

```sh
npx wrangler login
npx wrangler pages deploy <发布目录> --project-name dvi-lab --branch main
```

Pages 项目已创建。网页在访问者浏览器中完成模拟，无需后端；本机与线上域名的配置分别保存在各自的浏览器存储中。授权过期时可使用 `npx wrangler login --scopes account:read user:read pages:write` 仅申请账号读取与 Pages 发布相关权限。

## 从游戏导入角色

1. 浏览器安装支持 GM 本地存储的脚本管理器（如 Tampermonkey，来自浏览器扩展商店），按其提示允许用户脚本运行。模拟器的“导入游戏角色”区域点击“安装 userscript”，在脚本管理器中安装。也可直接打开本机 `http://127.0.0.1:4173/src/character-import.user.js`。
2. 安装后刷新游戏 <https://deepveinidle.com/>。左下角先持续显示“等待游戏数据 / Waiting for game data”；读取并保存成功后显示“角色配置已读取 / Character configuration captured”，15 秒后自动消失，数据仍可导入；脚本只读取游戏正常收到的角色快照，不发送游戏指令。安装后如没有提示，检查脚本管理器是否已启用脚本和站点权限。
3. 刷新模拟器，同一浏览器、同一脚本管理器内使用。展开默认折叠且高亮的“导入游戏角色”菜单，勾选要导入的菜单类型（首次默认九类全选），点击“一键导入”。导入自动保存并重新计算；取消勾选的类型、缺失或不支持的字段保留原值，页面显示读取时间与提示。

脚本匹配游戏、线上 `https://dvi-lab.pages.dev/` 和本机 localhost/127.0.0.1 的 HTTP 预览地址。其他域名需自行增加对应 `@match`。配置通过脚本管理器的本地存储传递，不上传到模拟器服务器。安装后要刷新游戏及模拟器；不要将 `.user.js` 下载后的普通文本页面当作已安装成功。也可使用本机预览安装和导入。

可导入技能、装备（含风格/坐骑/品质/强化）、食物及策略、当前有效药水、已放置家园、精通、公会与祝福、补给、天赋。读取的是最近服务端角色快照，操作后的配置以收到新快照为准。每周目标随“公会与祝福”从当前有效的“世界增益”来源导入，按战斗公式加法叠加（两项各 10% 导入 20%，面板相乘显示 21%）；旧脚本缺失或无法读取时保留原值并提示；未指定食物品种时也保留模拟器所选品种。游戏关闭自动进食会导入为仅泉水策略。药水/祝福及食物增益导入后按永久生效处理，技能级内经验仍为 0，食物供应充足、固定随机参数等模拟假设保持不变，结果不保证与游戏账号预测逐数一致。

脚本只保存战斗配置白名单和读取时间，不保存认证信息、聊天、真实库存或完整角色消息。当前已通过合成角色、独立上下文 DOM 通信和异步存储桥接验证，真实账号与脚本管理器端到端运行尚未验证。

### 更新已安装的脚本

当前脚本版本为 **1.0**。已安装旧实现的用户需从线上或本机安装入口覆盖已有脚本，或将新文件内容覆盖到已有脚本并保存，不要同时启用两份。版本号降为 1.0，管理器可能不会自动更新；此时手动覆盖脚本内容并保存。随后刷新游戏及模拟器。`@name` 与 `@namespace` 保持原来的脚本身份，新增 `@name:en` / `@name:zh-cn` 供管理器按语言显示名称。

当前 1.0 使用共享 document 上的 JSON 字符串 DOM 事件通信，修复脚本沙箱与网页窗口身份不同导致的连接问题；探测与读取最多等待 4 秒并重试。游戏页先持续显示“等待游戏数据 / Waiting for game data”，收到有效数据并保存成功后显示“角色配置已读取 / Character configuration captured”，15 秒后自动隐藏，后续快照继续保存但不反复弹出；显示期间被重绘移除会恢复，隐藏后不会恢复。读取失败提示保持显示；支持异步存储 API，并等待保存成功后才显示“角色配置已读取”。如模拟器仍提示未连接，确认该模拟器地址匹配脚本 `@match`、管理器在当前页面启用了此脚本，并且两页使用同一管理器中的同一份脚本。

## 使用说明

- 首次打开提供 85 级远程示例配置；风格按钮高亮当前选择，切换时保留等级与通用装备、清除不匹配装备。远程／魔法未装备武器时自动选择基础武器。
- 五项技能等级均可编辑，当前风格对应的攻击技能高亮。装备下拉默认只显示当前风格及通用装备，可开启全部装备。
- 角色配置的所有子菜单均可折叠，操作与语言切换后保留本页折叠状态；“技能”“食物”“家园”“精通”“天赋”独立显示。配置保存在本机浏览器。
- 装备包含坐骑，可选择马的品质和强化，显示其移动速度加成；默认不装备。当前快照的其他工具和天赋不提供移动速度加成。
- 等级不足的装备不计入结果，并显示提示；双手大剑使副手无效。界面限制为当前风格装备，底层仍保留原游戏混穿计算规则。
- “食物”菜单依次显示选择食物、增益、策略、品质、每趟携带、进食阈值。进食阈值仅提供 25%、50%、75%；每趟携带仅提供 5、10、20、留一格、满包。旧自定义值不在选项内时分别恢复 50% 和满包。食物选择用于预览回血与增益持续时间，点击“应用所选食物的增益”启用对应增益。选中食物不代表每次攻击前都进食。指定食物策略允许所选食物超过自动进食品质上限；优先好食物／优先差食物仍遵循该上限。
- 药水清单从原游戏定义筛选影响战斗的 7 种，按制造等级升序排列，名称旁不显示等级；经验、寻宝、金币药水参与小时收益，疾行药剂影响地图移动。
- 敌人、击杀、经验、金币四列高亮。敌人名称不排序，其余列点击表头可切换升降序；默认等级升序，缺失值置于组末，世界 Boss 始终在普通怪物之后。
- 三种 Boss 使用公开基础数据估算，不包含服务端动态缩放和未验证的最终取整；不输出虚假的固定实战 HP。
- 普通怪物没有逐目标护甲扣伤，最大单次伤害相同属于当前原始代码行为。
- 本版使用原始完整模拟流程，可通过 userscript 读取角色配置；不包含登录、交易或角色操作。

## 精通与小时收益

精通输入显示实际有效加成，百分比步进为 0.5 个百分点，内部仍保存原始等级，因此旧配置保持原有效果。无影响的采集、制作、离线及强化精通不再显示，旧存档字段保留。

敌人表格显示击杀、经验、金币、普通掉落、稀有掉落、食物消耗。默认每小时，可切换每天；每天按小时结果 ×24 换算（经验先遵循游戏原始小时取整），并非连续 24 小时模拟。死亡状态与单次运行时长不放大。点击数量可查看技能、物品品质、移动时间和取食次数。

每种普通怪物在 Worker 中独立运行原游戏完整的一小时预测流程：原始预测入口初始化，原始逐刻入口执行地图寻路、移动、战斗、进食、回库补给、泉水恢复和死亡处理。与原始预测／离线入口的计算结果进行回归对比，测试不依赖收益用户脚本；不再冻结等级，经验积累可升级。配置变更取消旧计算。

页面支持手动配置及 userscript 按菜单导入；导入后仍可手动修改。除等级、装备、坐骑、药水、家园与精通外，折叠区域可配置：

- 五项战斗技能等级；初始级内经验进度固定为 0，模拟中仍正常获得经验与升级。
- 公会经验、每周目标（全服）经验加成、矿脉祝福；手动启用的药水、祝福与初始食物增益永久生效。
- “天赋”菜单配置口袋、休息及丰盛餐食等级；“食物”菜单配置食物优先级、品质上限、每趟携带量。
- 补给菜单中的模拟初始仓库位置（自动、仓库 1、仓库 2）和铁人模式；家园设施等级（按所填等级生效，默认未在升级中）。

配置自动保存。所选食物固定充足，仓库容量无限；补给菜单可自动逐敌人选择最近仓库，或指定仓库 1/2，列表显示实际模拟仓库，不提供库存设置。角色从该仓库附近满血出发，耗尽食物后返回补给。手动模拟全程无热门加成。每周目标（全服）经验可由角色导入或手动输入百分比，步进 1%，全程生效；与公会经验、矿脉祝福按原游戏加法叠加，不增加稀有掉落加成。

模拟范围为独立目标战斗，不包含任务队列、并行强化和农田作业。原始预测重置位置与血量，因此不提供这两个输入。不再提供内部复现参数输入；手动模式固定角色编号 1、seed 0 和原始预测刻，忽略旧手动存档的覆盖值。默认 secretAt=()=>0，与客户端预测一致。坐骑、疾行药剂和移动精通实际影响寻路耗时。死亡或路线结束按原始 100 刻检查间隔停止，不自动复活。

经验合计攻击、防御和生命，金币不包含售卖；普通掉落包含全部品质，稀有掉落统计额外物品（含宠物、坐骑、碎片）。罕见物品可能在单次预测中为零，Boss 完整模拟暂不支持。

完整角色快照模式及文件/粘贴导入已移除；userscript 只将可支持的角色字段转换成当前配置。旧手动存档中的库存、容量、活动、热门加成、经验进度、增益倒计时、家园放置与升级设置均不再生效。

参数核验与移除依据见 [设置参数核验](reports/settings-audit.md)。历史报告中的模式与配置可能已移除，以当前需求文档为准。
